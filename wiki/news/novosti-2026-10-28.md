# Новости ИИ — 2026-10-28

Шестнадцатый прогон рутины 1 под конфигурацией двух ярусов. Прошлая сводка — [[novosti-2026-10-25]] (25.10.2026). Окно этого прогона — 25.10–28.10.2026.

## Что изменилось

1. **TOCTOU-уязвимость в Edit-инструменте Claude Code — CVE-2026-88968 (GHSA-5xjx-9qx6-jcrv), CVSS v4 7.7, High (раскрыта 26.10.2026).** До версии 2.1.251 Claude Code проверял путь и символическую ссылку для цели `Edit` в момент проверки, но не привязывал проверку к inode/файловому дескриптору — классическое окно time-of-check-to-time-of-use. На macOS процесс внутри Bash-песочницы мог атомарно подменить родительскую директорию внутри workspace на симлинк сразу после проверки, и несэндбоксированная реализация `Edit` перезаписывала произвольный доступный на запись файл за пределами workspace. Эксплуатация требует выполнения кода атакующего внутри песочницы (например, через вредоносный репозиторий или скрипт зависимости) — предпосылка гонки отражена в метрике `AT:P`. Пропатчено в 2.1.251; текущая серия релизов (2.1.312) идёт далеко впереди патча, так что обычные обновлённые инсталляции уже защищены, раскрытие просто документирует задним числом уже закрытую дыру. **Влияние:** ещё один (четвёртый по счёту в этой вики) независимо найденный симлинк/TOCTOU-баг в Claude Code — подтверждает, что класс риска «подмена пути между проверкой и использованием» в sandboxed Edit/Bash остаётся системным, не единичным случаем; у кого обновления идут вручную — повод проверить, что версия давно выше 2.1.251. Первоисточник — `github.com/anthropics/claude-code/security/advisories/GHSA-5xjx-9qx6-jcrv`, прочитан напрямую.
2. **OpenAI Codex CLI 0.165.0 (27.10.2026).** Стабильный релиз: встроенный провайдер Google Cloud Vertex AI (`model_provider = "gcp"`), фильтр по репозиторию в выборе сессии, экспериментальные ветвления (forks) прикреплённого треда в app-server API, смена уровня `reasoning effort` по умолчанию возможна прямо в ходе разговора, memory v2 включена по умолчанию для новых профилей. Из багфиксов — свежие TUI-сессии теперь соблюдают серверного ревьюера подтверждений по умолчанию, отменённые запросы к удалённым MCP-инструментам корректно снимаются, закрыта дыра в проверке URL маркетплейса. Отдельно в каталоге моделей появилась запись `GPT-6.1 Terra` — **не подтверждена официально OpenAI**: ни анонса, ни страницы модели у OpenAI нет, это имя всплывало ранее в конфиге сторонней evaluation-утилиты как плейсхолдер, инсайдерские пересказы (The Information) говорят о модели, которая должна превзойти GPT-6.1 Sol по более низкой цене, с возможным сдвигом на ноябрь — в сводку как факт релиза не берётся, только как встретившееся в changelog имя. **Влияние:** командам на Codex CLI доступен нативный путь на Vertex AI без обходных прокси и управление reasoning effort без перезапуска сессии; появление нерелизнутого имени модели в каталоге — не повод менять конфигурацию, ждать официального анонса OpenAI. Первоисточник — `github.com/openai/codex/releases`, прочитан напрямую.
3. **Claude Code 2.1.311–2.1.312 (26–27.10.2026) — продолжение серии, без критических фиксов этот раз.** В отличие от батчей последних недель (sandbox/permission-bypass), здесь только инфраструктурные изменения: OIDC-опция идентификации пользователя по произвольному claim вместо `sub`, флаги `--hold-idle-file`/`--max-hold-min` для `self-hosted-runner`, переименование сообщений о лимите использования («5-hour limit» вместо «session limit»), фикс сессий с полным контекстом 1M, падавших с ошибкой вместо сжатия контекста. **Влияние:** минимальное — ни одного нового permission/sandbox-фикса в этом окне, обновление по обычному графику, не срочное. Первоисточник — `github.com/anthropics/claude-code/releases` и `CHANGELOG.md`, прочитаны напрямую.
