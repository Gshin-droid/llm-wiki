# Новости ИИ — 2026-11-10

Прогон рутины 1 под конфигурацией двух ярусов. Прошлая сводка — [[novosti-2026-11-07]], закрыла окно 04.11–07.11.2026. Окно этого прогона — **07.11–10.11.2026**.

## Что изменилось

1. **Claude Fable 5.2 и Claude Mythos 5.2 (09.11.2026) — новое поколение самой дорогой модели семейства Fable, дешевле предыдущей, плюс крупный пакет изменений Claude Code 2.1.321–2.1.322.** Anthropic выпустила Claude Fable 5.2 (`claude-fable-5-2`) — модель "для требовательных задач на рассуждение и длинной автономной агентской работы", ставшую дефолтом семейства Fable вместо Fable 5.1 (сохранённые выборы модели переносятся автоматически на тарифах Pro/Max, на Team/Enterprise — после решения организации; вернуться на старую можно командой `/model claude-fable-5-1`). Одновременно вышла Claude Mythos 5.2 — та же модель с тем же контекстом/ценой, доступная только организациям, прошедшим верификационные программы Anthropic (например, Cyber Verification Program). Контекст 1M токенов, максимум на выход 128K, thinking — adaptive, всегда включён (как у Fable 5.1), эффорт по умолчанию `high`. **Цена снижена относительно Fable 5.1**: $8/$40 за MTok против прежних $10/$50 — кэш-чтение по той же отдельной сниженной ставке 2,5% от входной цены (0,025×), что и у Fable/Mythos 5.1. Обе модели требуют 30-дневного хранения данных (data retention) и enforce'ят "prefix check" для всех аккаунтов без исключений, принимают только новый инструмент компьютерного доступа `computer_toolset_20260801` (старый `computer_20251124` возвращает 400 на всех платформах кроме Amazon Bedrock), а executor на Fable/Mythos 5.2 принимает советчиком (advisor) только модель того же поколения. Синхронно вышедшая Claude Code 2.1.321 несёт отдельный пакет изменений: исправлена утечка секретов MCP OAuth (refresh-токены уходили на чужой хост при редиректе сервера) и очередной, одиннадцатый узел серии фиксов обхода прав (чтение-только Bash-команда выполнялась мимо песочницы без запроса разрешения) — продолжение серии, которую вики ведёт с 10-04; но тем же релизом Anthropic **ослабила** проверку для модов (mods, расширения Claude Code, которые Claude пишет сам): они включаются без вопроса в auto/bypass режимах даже при управляемых запретах `allowUnsandboxedCommands: false` и `allowManagedDomainsOnly`, а их собственные вызовы инструментов не вызывают запрос разрешения даже при собственных правилах `ask` пользователя. Релиз 2.1.322 (10.11) добавил fast mode на Vertex AI с откатом на обычную скорость, если Vertex его не даёт. **Влияние:** у кого Claude Code уже указывает на Fable как модель для тяжёлых задач — модель сменилась автоматически и стала дешевле; у кого есть собственные моды — они стали менее стеснены правилами, которые должны бы их ограничивать, в т.ч. в режимах, которые раньше считались более строгими. Первоисточники — официальный changelog `code.claude.com/docs/en/changelog`, страница модели `platform.claude.com/docs/en/models/fable-5-2/overview` и `release-notes/api`, прочитаны напрямую через WebFetch.
