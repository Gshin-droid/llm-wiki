# Новости ИИ — 2026-10-19

Тринадцатый прогон рутины 1 под конфигурацией двух ярусов. Окно — со времени прошлой сводки [[novosti-2026-10-16]] (16.10–19.10.2026).

## Что изменилось

1. **Критическая уязвимость в Claude Agent SDK: впрыск аргументов командной строки через `resume` (CVE-2026-96620, зарегистрирована в базе 16.10.2026)**. SDK передавал значение опции `resume` (а также `session_id`) в CLI Claude Code без проверки; значение, начинающееся с дефиса, CLI читал как отдельный флаг. Злоумышленник, контролирующий это значение (например, через ID сессии, пришедший от пользователя приложения), мог впрыснуть флаг `--mcp-config` и определить вредоносный stdio MCP-сервер — тот выполнял произвольные команды уже при старте CLI, минуя permission-контроль самого SDK. Затронуты версии pip-пакета `claude-agent-sdk` младше **0.2.121** (патч — она же); CVSS v4 9.2 (Critical), CWE-78/CWE-88 (OS command injection / argument injection). **Влияние:** у всех, кто встраивает Claude Agent SDK в своё приложение и передаёт в `resume`/`session_id` что-то, пришедшее снаружи (ID сессии из URL, от пользователя, из БД) — обновиться до 0.2.121+ и не передавать непроверенные значения в эти опции независимо от версии. Полный разбор — [[claude-agent-sdk-resume-argument-injection]]. Первоисточник — GitHub Advisory Database (`GHSA-h4mw-j7qp-8mwm`), страница прочитана напрямую.
2. **Официально подтверждена версия фикса Plugin4Shell в Claude Code — и это не новое событие, а исправление собственной ошибки вики.** Уязвимость обхода SHA-пиннинга плагинов (обход закрепления плагина за git-коммитом через одноимённую git-ветку), взятая в вики 17.09.2026 как [[plugin4shell-vulnerability]], 09.10.2026 получила от самой Anthropic официальную запись в GitHub Advisory Database — **CVE-2026-86063 / `GHSA-pq7j-f95f-qfcv`**, CVSS v4 7.5 (High), добавлена в базу 15.10.2026. Официальный источник подтверждает версию фикса **2.1.179** — ровно то число, которое страница [[plugin4shell-vulnerability]] в сентябре отвергла как опечатку вторичного пересказа (рассуждение: число ниже уже подтверждённой на тот момент 2.1.271, значит на дату раскрытия было бы релизом почти двухмесячной давности). Рассуждение было логичным, но факт оказался другим: баг действительно исправлен значительно раньше раскрытия находки исследователями, просто официальная регистрация CVE и правильная трактовка changelog запоздали. Страница и связанный раздел [[ai-security-by-design]] исправлены — не переписаны молча, старое рассуждение помечено как ошибочное с указанием даты и причины. **Влияние:** для тех, кто уже обновился после 09-17 (как рекомендовала прошлая находка) — действий не требуется, риск был закрыт раньше, чем казалось. Первоисточник — GitHub Advisory Database (`GHSA-pq7j-f95f-qfcv`), страница прочитана напрямую.
