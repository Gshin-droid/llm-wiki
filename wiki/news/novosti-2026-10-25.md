# Новости ИИ — 2026-10-25

Пятнадцатый прогон рутины 1 под конфигурацией двух ярусов. Прошлая сводка — [[novosti-2026-10-19]] (19.10.2026); прогон 22.10.2026 был тихим и довёл проверку до 22.10 включительно (запись в `wiki/log.md`). Окно этого прогона — 22.10–25.10.2026.

## Что изменилось

1. **Claude Skills переданы в Agentic AI Foundation (22.10.2026).** Anthropic передала открытый стандарт Agent Skills — имя и лого, GitHub-организацию и домен `agentskills.io` — в Agentic AI Foundation (AAIF) при Linux Foundation, тот же фонд, куда ранее был передан MCP (Anthropic — один из соучредителей AAIF вместе с Block и OpenAI). Стандарт становится «открытым, управляемым сообществом, вендор-нейтральным»: планируются версионированные релизы, формальный процесс предложений и security guidance для тех, кто пишет и устанавливает скиллы; сопровождают инженеры Anthropic, Google, OpenAI и других компаний как частные лица, ведущие мейнтейнеры — David Soria Parra и Mahesh Murag (соавтор Skills, уже известный вики по [[claude-skills]]). **Влияние:** формат `SKILL.md` перестаёт быть односторонне контролируемым Anthropic — тем, кто пишет скиллы (включая эту вики, где `wiki-ingest`/`wiki-lint` оформлены как скиллы), стоит ждать версионированной спецификации и будущих требований к безопасности скилла, а не только изменений на стороне Claude Code. Первоисточник — `anthropic.com/news`, страница прочитана напрямую. Полный разбор — ярусом 2.
2. **Claude Code 2.1.305–310 (20–23.10.2026) — новый батч фиксов sandbox/permission.** Продолжение уже известной вики серии: обход песочницы через shell-стартовые файлы на запуске каждой команды (macOS/Linux), изменение MCP-конфига из-под sandbox и auto-accept правок, обход macOS `denyWrite`-паттернов через symlink, недостаточная проверка некоторых составных Bash-команд перед git. Отдельно — `claude ultrareview` теперь требует подтверждения доверия к workspace, а Enterprise custom roles получили отдельный контроль доступа к Cloud sessions/Remote Control. **Влияние:** тем, кто полагается на sandbox/permission-контроль в автономных и CI-прогонах (этот же класс риска несёт и сама эта вики), — обновиться до 2.1.310+. Бюджет полного разбора в этот прогон занят пунктом 1; страница-кандидат для рутины хвостов (допроверка [[claude-code]]). Первоисточник — `github.com/anthropics/claude-code` (CHANGELOG.md + страница релизов), прочитан напрямую.
3. **OpenAI Codex CLI 0.164.0 (23.10.2026).** Стабильный релиз после серии альф: enterprise-авторизация MCP (включая OAuth-клиенты с секретами), маскирование credential'ов в удалённых bash/zsh-сессиях, усиленные проверки sandbox на macOS и для symlink-исполняемых файлов, Bedrock setup wizard по умолчанию, inline-аргументы `/model` и `/permissions`. **Влияние:** командам на Codex CLI доступна enterprise-авторизация MCP, а класс обхода sandbox через symlink закрыт тем же способом, что и в недавних фиксах Claude Code — независимое подтверждение, что агентские CLI сходятся к одному и тому же набору security-проблем. Первоисточник — `github.com/openai/codex/releases`, прочитан напрямую.
