# Новости ИИ — 2026-11-22

Прогон рутины 1 «новости» (раз в 3 дня, 21:00 Алматы). Прошлая сводка — [[novosti-2026-11-19]], закрыла окно 16.11–19.11.2026. Окно этого прогона — **19.11–22.11.2026**.

## Что изменилось

1. **Claude Code 2.1.329–2.1.330 (19 и 20.11.2026) — scheduled tasks и `/loop` теперь живут до 30 дней вместо 7, и это прямо касается рутин этой вики.** Два релиза следом за уже разобранным 2.1.328 (см. [[novosti-2026-11-19]]). Главное для нас: recurring scheduled tasks и `/loop` теперь продолжаются до **30 дней** вместо 7, пока их сессия не завершена (2.1.330) — три автономные рутины этой вики (`jarvis-wiki-news`, `jarvis-wiki-practical-scout`, `jarvis-wiki-gaps-backlog`) работают именно через scheduled tasks/Cloud Routines, так что это прямое изменение горизонта их работы, а не абстрактная платформенная деталь; та же версия предупреждает, что **задачи, сохранённые до этого релиза, всё равно заканчиваются на 7 дне** — не автоматический бонус для уже существующих расписаний. Отдельно 2.1.329: Code Mode больше не отказывает в вызове тула скрипта, если PreToolUse-хук упал с ошибкой (раньше — блокировал, теперь пропускает по умолчанию, если на хуке явно не стоит `"onFailure": "block"`) — ослабление защиты, тема [[ai-security-by-design]]; и ужесточение в другую сторону — больше `rm`-команд, направленных на корень, домашнюю папку, верхнеуровневые папки или саму рабочую папку, теперь спрашивают подтверждение, а где спросить некого (автономная сессия) — отказывают. Также 2.1.330: вход в организации Enterprise Admin Console, встроенный мод Easel (автоматические графики по MCP-метрикам), подтверждение auto mode общим правилом для Opus/Sonnet 4.6 у сторонних провайдеров (Bedrock/Google Cloud Agent Platform/Microsoft Foundry). **Первоисточник**, `code.claude.com/docs/en/changelog` прочитан напрямую. Полный разбор — ярусом 2, [[claude-code-changelog-snapshot-2026-11-22]].
