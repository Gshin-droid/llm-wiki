# Новости ИИ — 2026-09-25

Пятый прогон рутины 1 под конфигурацией двух ярусов. Окно — со времени прошлой сводки [[novosti-2026-09-22]] (три дня, 22–25.09.2026).

## Что изменилось

1. **OpenAI выпустила GPT-6 Sol и GPT-6 Luna — вдвое дешевле поколения 5.6 при заявленном снижении числа ошибок** (22.09.2026). Sol — модель для повседневных сложных задач ($2/$10 за MTok вход/выход), Luna — для быстрых высокообъёмных задач ($0.10/$0.50 за MTok); обе с контекстным окном 1,05M токенов. По словам OpenAI, обучены методами, близкими к Astra, с улучшениями в фактологии, коде, computer use; Sol делает «примерно вдвое меньше ошибок», чем GPT-5.6 Sol. Доступны сразу в ChatGPT Work, Codex и OpenAI API. Влияние: у того, кто выбирает модель для агентного кодинга или высокообъёмных задач через API/Codex, появилась более дешёвая пара опций от OpenAI — прямое изменение доступного выбора и цены. Официальные `openai.com` и `github.blog` не открылись из этого окружения — по пересказам (techcrunch.com, macrumors.com, datanorth.ai), совпадающим в ценах и дате.

2. **Anthropic выпустила Claude Opus 5.5 — новую модель Opus по умолчанию** (22.09.2026, версия Claude Code 2.1.280). $4/$20 за MTok (было $5/$25 у Opus 5), кэш-чтение снижено с $0.50 до $0.20; на тарифах Pro и Team Standard модель по умолчанию сменилась с Sonnet на Opus. Уже разобрана полностью — [[claude-opus-5-5-launch]] (ингест 24.09.2026), эта строка сводки закрывает пробел: страница появилась раньше, чем новостной слой её зафиксировал. Влияние: тот, кто работает с Claude Code/API на дефолтных настройках, получил более дешёвую и более "думающую по умолчанию" модель без изменений в коде — но effort и thinking у 5.5 ведут себя иначе, чем у Opus 5 (подробности на странице модели).

3. **Claude Code 2.1.281 — межаккаунтный доступ к AWS Bedrock и новые ключи политики безопасности десктоп-приложения** (23.09.2026, первоисточник — официальный `CHANGELOG.md` `anthropics/claude-code`). `assume_role` на Bedrock-апстримах шлюза даёт кросс-аккаунтный вызов Bedrock через STS, `guardrail: {id, version}` навешивает готовый Amazon Bedrock guardrail на все запросы через апстрим; в `desktop`-блоке политики появились `blockReadsOutsideWorkingDirectories` и `disableBypassPermissionsMode`. Тем же релизом — заметная связка фиксов надёжности возобновления долгих сессий (см. полный разбор ниже) и новая настройка `"attribution": false`, полностью отключающая атрибуцию коммитов/PR. Влияние: у команд с self-hosted/Bedrock-инфраструктурой Claude Code появился штатный способ ограничить десктоп-сессию рабочей директорией и запретить обход approval-режима — до этого приходилось полагаться на org-политику без такой гранулярности. Полный разбор — [[claude-code-changelog-snapshot-2026-09-25]] (ярус 2 этого прогона).

4. **Cursor выпустил двух ботов для стадии деплоя — Rollouts и Security Review** (23.09.2026, доступны на тарифах Teams и Enterprise). Rollouts отслеживает каждый деплой изменения и репортит здоровье по окружениям; Security Review проверяет каждый pull request на эксплуатируемые баги. Влияние: у команд на Cursor Teams/Enterprise появляется встроенная проверка безопасности PR и мониторинг деплоя без сторонних интеграций — расширение того, что можно делать без выхода из IDE. Официальный `cursor.com/changelog` не открылся из этого окружения — по пересказам (forum.cursor.com), деталей конфигурации не проверялось.
