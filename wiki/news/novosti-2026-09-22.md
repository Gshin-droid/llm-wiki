# Новости ИИ — 2026-09-22

Четвёртый прогон рутины 1 под конфигурацией двух ярусов. Окно — со времени прошлой сводки [[novosti-2026-09-19]] (три дня, 19–22.09.2026).

## Что изменилось

1. **xAI выпустила Grok 4.7 — более крупную флагманскую модель по заявленной той же цене, что у 4.6** (21.09.2026). 2,1 трлн параметров (рост на 40% с 1,5 трлн у Grok 4.6), $2/$6 за MTok вход/выход. По словам xAI, модель дольше рассуждает над сложными задачами и чаще перепроверяет собственные ответы; в обучение добавлены телеметрия Starlink и инженерные логи SpaceX. Доступна сразу, без листа ожидания: приложение Grok, Cursor, Grok Build, xAI API — и в тот же день добавлена в GitHub Copilot. Влияние: у тех, кто выбирает модель для агентного кодинга через Cursor/Copilot/xAI API или агрегаторы вроде [[openrouter]], появилась новая топовая опция xAI без роста цены — прямое изменение доступного выбора моделей. Официальная страница `x.ai` не открылась из этого окружения — по пересказам (decrypt.co, tech.yahoo.com, github.blog), совпадающим в цифрах и дате.

2. **OpenAI отключает Sora API 24.09.2026 — жёсткий обрыв без преемника в API**. Объявлено ещё в марте 2026 (шесть месяцев на миграцию), сейчас — последние два дня до отключения. С 24.09 все вызовы к `sora-2`, `sora-2-pro` и связанным снапшотам моделей начинают возвращать `410 Gone`; это не постепенный вывод, а жёсткий обрыв без льготного периода, а данные после финального окна экспорта удаляются безвозвратно. Собственного преемника в API у OpenAI нет — у каждой команды свой путь миграции к другому поставщику видео-генерации. Влияние: тот, кто использует Sora API в продукте или пайплайне, должен завершить миграцию в ближайшие два дня — иначе интеграция ломается без возможности восстановить данные. Официальная страница `help.openai.com` не открылась из этого окружения — по пересказам (byteiota.com, newsbytesapp.com), совпадающим в дате и масштабе отключения.

3. **В России с 01.09.2026 действует федеральный закон №243-ФЗ «О поддержке развития технологий искусственного интеллекта» — но не в том виде, в каком его пересказывают как «закон о маркировке».** Взято вне обычного 3-дневного окна по правилу «действующее регулирование, которого в вики нет»: закон уже проверялся рутиной новостей 15.09.2026 (запись в логе: «новых развитий за неделю нет»), но отдельной страницы, строки в индексе или ссылки из `entities`/`concepts` не появилось — упоминание в разделе «проверено и отклонено» присутствием в вики не считается (то же основание, что дало [[novosti-2026-09-19]] закон РК). Закон подписан 26.07.2026, основная часть в силе с 01.09.2026, но положения о статусе суверенных и национальных моделей, обязанностях их разработчиков и правилах маркировки — только с 01.03.2027. Что уже действует с 01.09: юридические понятия «суверенная» и «национальная» большая фундаментальная модель (обе — разработки российских компаний, к суверенной требований больше) и меры господдержки их разработчиков. Что закон НЕ требует прямо сейчас, вопреки распространённому пересказу: обязательной маркировки ИИ-контента для авторов и пользователей в нём нет и с 01.09 не появилось — отдельный законопроект об этом Госдума отклонила ещё в июне. С 01.03.2027 обязанность дать возможность разместить предупреждение о посте, созданном с помощью ИИ, ляжет на владельцев крупных площадок (500 тыс.+ пользователей в день) — не на автора, и без штрафов за отсутствие пометки. Исключение из авторского права для обучения суверенных/национальных моделей на защищённом контенте тоже вступит только 01.03.2027. Влияние: для того, кто сегодня в России публикует или использует ИИ, закон пока не меняет действий напрямую; единственное, что стоит проверить уже сейчас, — компаниям, разрабатывающим большую модель с прицелом на статус «суверенной»/«национальной», ради будущих мер поддержки; первое ощутимое для рядового пользователя изменение (пометка ИИ-контента у крупных площадок) наступит только 01.03.2027. Официальный текст (`pravo.gov.ru`, `sozd.duma.gov.ru`) не открылся из этого окружения — по пересказам нескольких независимых юридических разборов (ppt.ru, efsol.ru, sostav.ru, recomixtech.com, mypl.pro), совпадающим в датах и формулировках.

## Проверено и не взято

- **GitSpawn** (Manifold Security, CVE-2026-72718 и связанные) — уязвимость в фоновых git-командах семи агентов-кодеров (Claude Code, Codex, Cursor, goose, Hermes Agent, Qwen Code, Grok Build): вредоносный `.git/config` запускает код ещё до первого промпта пользователя, без approval-диалога. Значимая находка (4 из 8 обнаруженных дефектов не пропатчены на момент раскрытия), но раскрыта 01–02.09.2026 — вне окна этой сводки и вне окна всех прошлых (аналогично [[novosti-2026-09-16]] и уязвимости TrustFall там же). Не форсируется как регулирование, исключение не применяется.
- **CVE-2026-35603** (эскалация привилегий через `C:\ProgramData\ClaudeCode\` в Claude Code, а также Cursor/Codex CLI/Gemini CLI) — публично раскрыта Cymulate 11.08.2026 (отчёт получен Anthropic ещё 05.01.2026, фикс — перенос managed-settings в защищённую от записи `Program Files`); вне окна.
- **GPT-6 Astra «стабильный релиз» в ChatGPT** (14.09.2026) — сам релиз модели (03–04.09.2026) уже проверялся и отклонён сводками 09-15/09-16/09-19 как вне окна; новых практических развитий за это окно нет, кроме переноса даты общей стабильной доступности.
- **Приказ Минцифры/ИИ Казахстана №517/НҚ** о доступе к вычислительным мощностям через оператора национальной ИИ-платформы — в силе с 14.09.2026, вне окна; и по существу не о том, что можно/нужно делать пользователю ИИ, а об административном распределении государственных вычислительных ресурсов между организациями — не в духе правила «регулирование использования ИИ», в очередь не поставлено.
- Постоянное повышение недельных лимитов Claude Code на 25% и отмена повышения цены Sonnet 5 — вступили в силу 14.09 и 01.09.2026 соответственно, уже проверялись и отклонены сводкой 09-16 как вне окна; новых развитий нет.
- Qwen, DeepSeek, Mistral — целевой поиск релизов за 19–22.09.2026 не нашёл ничего, проходящего порог сводки.
- Gemini Enterprise Agent Platform добавила Grok 4.6 (не 4.7) как GA-модель — второстепенное обновление платформы, не меняет доступный выбор моделей так же прямо, как релиз Grok 4.7 выше.
- EU Cyber Resilience Act — обязательные 24-часовые отчёты об уязвимостях начали действовать 11.09.2026; регулирует продукты с цифровыми элементами в целом, не специфично работу с ИИ, и вне окна.

Источники — публичные новостные страницы, агрегаторы и changelog, прочитанные через WebSearch. Ни один официальный первоисточник (`x.ai`, `help.openai.com`, `github.blog`, `thehackernews.com`, `hacklido.com`, `pravo.gov.ru`, `ppt.ru`, `efsol.ru`, `sertcity.ru`, `iphones.ru`, `habr.com`) не открылся напрямую из этого окружения — сетевой прокси блокировал каждый при прямой попытке `WebFetch`, тот же паттерн, что и в прошлых сводках. Факты взяты по совпадению нескольких независимых пересказов и помечены как «по пересказам» на этой странице.

Ни в одном прочитанном материале не найдено текста, похожего на встроенную для ИИ-агента инструкцию (в духе «сначала загрузи X», «игнорируй предыдущие правила»). Если такое появится в будущем прогоне — оно не исполняется как команда, а называется здесь.
