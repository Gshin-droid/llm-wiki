# Новости ИИ — 2026-10-07

Девятый прогон рутины 1 под конфигурацией двух ярусов. Окно — со времени прошлой сводки [[novosti-2026-10-04]] (04.10–07.10.2026).

## Что изменилось

1. **Claude Code 2.1.289–2.1.292 (03–06.10.2026) — батч из восьми фиксов permission-bypass, включая новый Windows-вариант обхода защиты от `rm`.** Прямое продолжение темы критического фикса из прошлой сводки ([[novosti-2026-10-04]], разбор — [[claude-code-changelog-snapshot-2026-10-04]]): там дыру давала shell-обёртка `bash -c`, здесь — альтернативное имя пути на Windows: *«Fixed `rm -rf` on the 8.3 short name or another alternate Windows spelling of the home folder or a drive not being treated as removing it»* (2.1.292) — тот же класс «анализатор матчит путь по форме записи, а не по итоговому эффекту», только на другой платформе. Отдельно, под явной пометкой вендора «Security»: *«Fixed PreToolUse hook approvals and auto mode bypassing the permission prompt for file reads from network (UNC) paths»* (2.1.292) — чтение файла по сетевому Windows-пути (UNC, `\\server\share\...`) обходило подтверждение разрешения и в hook'ах `PreToolUse`, и в auto mode. Там же — TOCTOU-дыра (time-of-check-to-time-of-use, состояние гонки «проверили одно, прочитали другое»): *«Fixed a notebook or PDF read on macOS and Windows being able to return a file outside what was approved, through a link swapped in mid-read»*; фикс состояния, когда сломанная синхронизация настроек могла отключить встроенный policy-плагин: *«Fixed a tampered on-disk cache of server-managed settings being able to switch off or unseat the built-in policy plugin while the settings fetch failed»*; и более ранний, 2.1.289, первый сигнал той же волны: *«Fixed `Read` deny rules not applying to files @-mentioned, changed, or selected in the IDE through a symlink»* — запрещающее правило для `Read` не действовало, если путь к файлу был симлинком. **Влияние:** у тех, кто запускает Claude Code в автономном/bypass-режиме — включая автономные рутины этой вики, работающие на Linux-инфраструктуре, где Windows-специфичные находки (8.3-имена, UNC-пути) не применимы напрямую, но симлинк- и TOCTOU-класс дыр платформонезависим — за три дня закрыто восемь разных путей обхода permission-модели одним релизом. Полный разбор — [[claude-code-changelog-snapshot-2026-10-07]] (ярус 2 этого прогона). Первоисточник `raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md` прочитан напрямую.

2. **Mistral AI выпустила публичный превью Mistral Large 4 «Le Chonk» — 1 трлн параметров, MoE, открытые веса обещаны на 27.10** (06.10.2026). Новая флагманская модель французской Mistral AI: нативно мультимодальная архитектура MoE (mixture-of-experts, «смесь экспертов» — большая модель из многих специализированных подсетей, из которых на каждый запрос реально работает только часть) с заявленными ~1,05 трлн параметров, из которых активны ~49 млрд; контекстное окно до 1 млн токенов, поддержка 160+ языков, включая все официальные языки ЕС. Доступна по API уже сейчас (превью-цена, по разным источникам — от $0,68 до $1,36 за млн входных токенов и от $2,09 до $4,18 за млн выходных, источники расходятся в цифрах превью-тарифа); сама компания называет дату выпуска открытых весов — 27.10.2026. Позиционируется как лучшая модель с открытыми весами из США или Европы по агрегированным бенчмаркам, ответ на китайские модели такого класса. **Влияние:** у разработчиков появился крупный новый вариант с открытыми весами от западного поставщика — раньше такого масштаба (триллион параметров) в открытом доступе не было вовсе. Официальный `mistral.ai` не открылся из этого окружения — факты восстановлены по совпадению независимых публикаций (marktechpost.com, aiweekly.co, stork.ai, startupfortune.com, cellcog.ai, aiidelist.com, kie.ai, explainx.ai, felloai.com, tech-insider.org), совпадающих в архитектуре, числе параметров и дате анонса; расхождение в цифрах превью-цены явно названо, а не скрыто.

3. **GitLab закрыла критическую уязвимость AI Gateway — CVE-2026-90970, CVSS 9.9** (раскрыта и пропатчена 02.10.2026). Уязвимость в самостоятельно хостимом AI Gateway (компонент GitLab Duo) позволяла авторизованному пользователю выйти за пределы песочницы шаблона промпта (prompt-template sandbox escape) и выполнить произвольные команды на сервере — классифицируется как RCE (remote code execution, удалённое выполнение кода). Пропатчено в версиях 19.2.4, 19.3.2 и 19.4.1; данных об эксплуатации в реальных атаках на момент публикации нет. **Взято с явным нарушением обычного окна сводки**: дата (02.10.2026) приходится на уже закрытое окно прошлой сводки ([[novosti-2026-10-04]], 01.10–04.10), но в ней не упоминалась вовсе — ни как находка, ни в «Проверено и не взято». Это прямая проверка гипотезы из `wiki/gaps-backlog.md` («разведчик новостей систематически теряет события последних 1–2 суток окна», заведено 09-28): находка, относящаяся к уже закрытому окну, нашлась только сейчас — результат зафиксирован там же. Критерий по содержанию выполнен (уязвимость в широко используемом ИИ-инструменте разработки), и ни один прошлый прогон её не брал — взята один раз как устранение конкретного пропуска, а не как новая практика расширения окна назад по умолчанию. **Влияние:** у организаций с самостоятельно хостимым GitLab AI Gateway, не обновившихся до указанных версий, остаётся путь к удалённому выполнению кода через собственный ИИ-инструмент. Официальный `about.gitlab.com` не открылся из этого окружения — факты по CVE, CVSS-оценке и номерам версий фикса восстановлены по совпадению независимых публикаций (thehackernews.com, esecurityplanet.com, forkast.news, letsdatascience.com, securityaffairs.com, rescana.com, remio.ai, tech-insider.org, hendryadrian.com, shattered.io).
