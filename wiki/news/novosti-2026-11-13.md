# Новости ИИ — 2026-11-13

Прогон рутины 1 «новости» (раз в 3 дня, 21:00 Алматы — фактический запуск 13.11 в 16:25 UTC). Прошлая сводка — [[novosti-2026-11-10]], закрыла окно 07.11–10.11.2026. Окно этого прогона — **10.11–13.11.2026**.

## Что изменилось

1. **Claude Code 2.1.323 (12.11.2026) — Code Mode, лимит сообщений сессии вырос в 5000 раз, дефолтное окно контекста для неизвестных моделей — 1M.** Прямым WebFetch официального `code.claude.com/docs/en/changelog` (не агрегаторы — они на дату прогона версию ещё не подхватили) подтверждён релиз 2.1.323. Главное: **Code Mode** — экспериментальный, включается отдельно: вместо обычных вызовов инструментов Claude пишет JavaScript, который сам вызывает инструменты (включается и выключается для организации отдельно). **Лимит сообщений между сессиями в рамках одной — с «около 20» до 100 000** (не путать с 5-часовым/недельным лимитом использования — это другой, внутренний предел). Для моделей с неизвестным ID харнес теперь по умолчанию считает окно контекста **1M токенов вместо 200K** (откат — `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`). `/security-review` теперь спрашивает подтверждение перед запуском. Bash-песочница стала игнорировать grant на запись через символическую ссылку, ведущую в другое место или в несуществующий путь (точечный фикс того же класса, что серия permission-bypass, которую вики ведёт с 10-04, но в этом релизе не пронумерован как узел серии — нет отдельного официального подтверждения этой классификации). Плюс: `claude plugin validate` теперь типизирует TypeScript-хуки модов и показывает, какие `$`-существительные мод добавляет/отбирает/заменяет; установка плагина/маркетплейса падает, если git-сабмодуль не на зафиксированном коммите; удалена настройка `subagentStatusLine`, плагинная настройка `agent` помечена deprecated. **Влияние:** у кого Claude Code работал подолгу в одной сессии — предел на количество сообщений больше не ограничивал практически никого, теперь тем более; у кого используется модель с нераспознанным ID (часто — сторонние шлюзы/самостоятельно подключённые модели) — харнес станет считать для неё контекст втрое большим, что может неверно обрезать историю, если модель на деле меньше. Полный разбор релиза с доведением до [[claude-code]] и смежных страниц — ярусом 2 этого прогона, после пуша этой сводки. Первоисточник — `code.claude.com/docs/en/changelog`, прочитан напрямую.
2. **OpenAI–Cursor: точная дата отключения прямого доступа к моделям OpenAI в Cursor всё ещё не подтверждена, но появились конкретные альтернативы.** Напоминание контекста: в августе 2026 OpenAI объявила о сворачивании контракта с Cursor после покупки Anysphere SpaceX, с «предложенным переходным периодом» до 12.11.2026 — пункт был оставлен прошлой сводкой на проверку этим прогоном. Официальная справка OpenAI (`help.openai.com`, статья «Using OpenAI models in Cursor» — прочитана не напрямую: WebFetch этого домена в этой сессии блокирован сетевыми настройками, текст восстановлен по кэшированному фрагменту выдачи поиска) по состоянию на 13.11 прямо пишет: «точную дату отключения мы сообщим, как только она будет согласована между компаниями» — то есть 12.11 остаётся предложенной датой, а не состоявшимся фактом, и ни один независимый источник подтверждения отключения не нашёлся. При этом страница уже документирует конкретный план на случай отключения: расширение **Codex прямо внутри Cursor** (вход по подписке ChatGPT или по ключу OpenAI API, тарификация отдельна от подписки ChatGPT) и собственный **BYOK** Cursor (свой ключ OpenAI API работает только для локальных Chat/Agent-запросов — не работает для Tab/автодополнения, авто-выбора модели, облачных и фоновых агентов, Automations, Cursor CLI и API/SDK самого Cursor). **Влияние:** у кого в Cursor настроен прямой доступ к моделям OpenAI — отключение в любой момент (включая уже прошедшее 12.11 без объявления) технически возможно, и единственный задокументированный путь продолжать пользоваться моделями OpenAI внутри Cursor для большинства режимов — это расширение Codex, а не старый BYOK-обходной путь. По пересказам (кэш поисковой выдачи официальной страницы, не прямое чтение).
