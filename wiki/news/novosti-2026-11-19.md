# Новости ИИ — 2026-11-19

Прогон рутины 1 «новости» (раз в 3 дня, 21:00 Алматы). Прошлая сводка — [[novosti-2026-11-16]], закрыла окно 13.11–16.11.2026. Окно этого прогона — **16.11–19.11.2026**.

## Что изменилось

1. **OpenAI выпустила GPT-6.2 Astra и GPT-6.2 Sol (17.11.2026) — Astra дешевле на 20%.** Astra — флагманская модель для сложных задач, Sol — дешёвая модель для повседневных задач (по собственным данным OpenAI, Sol показывает результат в пределах 0,5 пункта от Astra на бенчмарке FrontierCode 2.0 при цене примерно в пять раз ниже на максимальном уровне мышления). Цена Astra снижена на 20% относительно GPT-6 Astra — ориентировочно $8/млн входных токенов, $0,40 за кэшированный вход, $40/млн выходных; у Sol цена не изменилась ($2/$10, кэш около $0,10). Обе модели доступны в ChatGPT (включая тариф Work) и Codex, а также в API под именами `gpt-6.2-astra` и `gpt-6.2-sol`; по заявлению OpenAI обе проходят по критическому порогу киберугроз Preparedness Framework — усиленные защитные меры с запуска. **По пересказам**: официальная страница анонса (`openai.com/index/introducing-gpt-6-2-astra-sol`) недостижима из этого облачного окружения (не резолвится), факт восстановлен по совпадению более десяти независимых изданий (MarkTechPost, 9to5Mac, TestingCatalog, Digital Trends, LetsDataScience, AIWeekly, Pulse2 и др.) о названии, дате и направлении цены; точные цифры тарифа и бенчмарка — собственные заявления OpenAI в пересказе, не проверены напрямую.
2. **Claude Code 2.1.326–328 (16, 17 и 19.11.2026) — auto mode становится дефолтным режимом разрешений, а не просто одним из вариантов.** Три релиза подряд меняют, какой режим разрешений получает сессия по умолчанию: интерактивные сессии терминала и VS Code без явно заданного режима теперь стартуют в auto mode (сервер сам решает по каждому вызову инструмента), а не в Manual — сначала для организаций с конфигурацией Claude Code + Cowork HIPAA (2.1.326), затем в общем случае, когда политика организации ещё не загрузилась (2.1.326) и для интерактивных сессий без заданного режима на провайдерах третьей стороны (Bedrock/Google Cloud Agent Platform/Microsoft Foundry/шлюз приложений Claude) на Opus/Sonnet 4.6 (2.1.328); флаг `disableAutoMode` отключает это явно. Отдельно в тот же батч — `/status` теперь показывает сломанные файлы агентов/скиллов/команд, недоступный сэндбокс, игнорируемые настройки разрешений и хук-матчеры, которые никогда не срабатывают; ряд сужений auto mode и песочницы (запись в чувствительные папки домашней директории, длинные переменные окружения, обход через `cp`/`mv`, PowerShell). Для этой вики прямое следствие — тот же узел, что уже отмечен 11-16 ([[novosti-2026-11-16]]): скиллы с `allowed-tools` в автоматизации спрашивают разрешение без записи `Skill(имя)` в `permissions.allow`; эта сессия (автономный прогон, без пользователя) вызвала `Skill(wiki-ingest)` для ярусa 2 этой же сводки и **вопроса разрешения не возникло** — рабочая проверка гипотезы бэклога, подробности в записи лога этого прогона. Полный разбор обоих версий (2.1.326–328) — ярусом 2 этого прогона, [[claude-code-changelog-snapshot-2026-11-19]].

Больше новых подтверждённых фактов в критерий сводки за 16–19.11 не попало — см. «Проверено и не взято» ниже.
