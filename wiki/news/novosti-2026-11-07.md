# Новости ИИ — 2026-11-07

Прогон рутины 1 под конфигурацией двух ярусов. Прошлая сводка — [[novosti-2026-11-04]], закрыла окно 28.10–04.11.2026 целиком. Окно этого прогона — **04.11–07.11.2026**.

## Что изменилось

1. **Claude Code 2.1.319 (06.11.2026) — продолжение серии фиксов обхода прав плюс новая настройка «отказывать вместо того, чтобы спрашивать».** Закрыты три новых случая обхода проверки прав: побег из сэндбокса (sandbox, изолированная среда выполнения) при создании worktree (git-механизм параллельных рабочих копий); Bash-команда прятала часть себя от проверки прав через подставной префикс переменных окружения; команда `sed` могла проскочить проверку прав в режимах accept-edits и auto mode — продолжение давно отслеживаемой в этой вики серии bypass-фиксов на [[claude-code]]. Добавлена настройка `permissions.denyInsteadOfPrompting` (по умолчанию выключена): вызов, который иначе ждал бы разрешения пользователя в терминальных сессиях, субагентах и teammates, теперь сразу отказывается, а не блокирует выполнение ожиданием ответа. Отдельно изменено поведение auto mode («разрешать автоматически, если риск низкий») за корпоративными LLM-гейтвеями и на Bedrock/Vertex/Foundry с выключенными телеметрией или feature flags: вызовы, которые сервер не может проверить, теперь по умолчанию спрашиваются у пользователя или отказываются, а не откатываются на встроенный классификатор, как раньше (старое поведение можно вернуть переменной `CLAUDE_CODE_AUTO_MODE_SERVER=0`). **Влияние:** у кого Claude Code работает за корпоративным гейтвеем без доступа к фиче-флагам, auto mode станет строже без смены настроек; у всех закрыты три новых пути обхода разрешений агента. Первоисточник — официальный changelog `code.claude.com/docs/en/changelog`, прочитан напрямую.
