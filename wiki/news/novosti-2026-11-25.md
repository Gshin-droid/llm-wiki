# Новости ИИ — 2026-11-25

Прогон рутины 1 «новости» (раз в 3 дня, 21:00 Алматы). Прошлая сводка — [[novosti-2026-11-22]], закрыла окно 19.11–22.11.2026. Окно этого прогона — **22.11–25.11.2026**.

## Что изменилось

1. **Claude Code 2.1.331 (23.11.2026) и 2.1.332 (25.11.2026) — переименование «routine» → «cloud scheduled task», автообновление маркетплейсов плагинов с 30.11, новый хук контроля шелл-команд скиллов.** Два релиза следом за уже разобранным 2.1.330 (см. [[novosti-2026-11-22]]). Три момента прямо касаются того, как эта вика ведёт свои автономные рутины и устроена безопасность скиллов: (1) 2.1.332 — `/schedule`, запросы разрешения и предложение облачного запуска у `/loop` теперь говорят «cloud scheduled task» вместо «routine»/«cloud schedule» (команда `/routines` продолжает работать) — терминология платформы расходится с тем, как сам [[claude-code]] и эта вика называют три свои автономные рутины («Cloud Routines»); (2) 2.1.331 — маркетплейсы плагинов, подключённые через управляемый `extraKnownMarketplaces`, с релиза **30.11.2026** начинают автообновляться по умолчанию (отключить — `"autoUpdate": false` на конкретном маркетплейсе); у этой вики скиллы `wiki-ingest`/`wiki-lint` — локальные файлы проекта, а не маркетплейс-плагины, так что изменение не задевает их напрямую, но в целом ослабляет контроль над тем, какой код скилла выполняется, тема [[ai-security-by-design]]; (3) 2.1.332 добавил хук `PreSkillShellCommand` — может отказать инлайн шелл-командам скилла или команды при их загрузке (на 2.1.331 и старее настройка с этим именем в файле настроек просто открывала диалог при старте), встречное усиление контроля к тому же релизу. Прочее по тем же двум релизам: скиллы от MCP-серверов (бета, вид `server:skill` в меню `/`); Code Mode добавлен в терминальные сессии на Bedrock, Google Cloud Agent Platform, Microsoft Foundry и Claude Platform на AWS; auto mode как дефолтный режим разрешений для сессий на Sonnet 5/5.5 расширен на Bedrock Mantle, Agent Platform и Foundry (продолжение тренда из [[novosti-2026-11-19]]); computer use на macOS переведён на более строгие правила безопасности (часть действий отказывается, набор текста может быть медленнее). **Первоисточник**, `code.claude.com/docs/en/changelog` прочитан напрямую. Полного разбора ярусом 2 в этот прогон нет: ни один из пунктов не меняет содержательно существующие страницы вики настолько, чтобы оправдать отдельную страницу источника — терминологическая правка и настройка автообновления, не касающаяся локальных скиллов этой вики, достаточно отражены пунктом сводки.
