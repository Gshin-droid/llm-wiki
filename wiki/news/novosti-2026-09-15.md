# Новости ИИ — 2026-09-15

Первая сводка рутины 1 после расширения на два яруса (решение 2026-09-15, `CLAUDE.md` → «Рутина 1 — новости: два яруса»). Прошлой сводки не было, окно — последние 7 дней (2026-09-08…2026-09-15).

## Что изменилось

1. **Anthropic раскрыла и заблокировала промышленный «дистилляционный» сбор данных с Claude семью лабораториями из Китая** (10.09.2026). Компания сообщила, что Alibaba, Moonshot, DeepSeek, Z.ai (Zhipu) и MiniMax системно прогоняли через API Claude миллионы диалогов (у Alibaba — свыше 151 млн обменов, до ≈3 млн/день с 3500+ поддельных аккаунтов), чтобы «дистиллировать» его возможности в свои модели (в частности Qwen у Alibaba); аккаунты заблокированы. Влияние: показывает, что часть заявленного прогресса открытых китайских моделей может опираться на скрытое использование Claude через API в обход условий использования, и что у Anthropic есть работающий механизм детекции такой накрутки — это меняет доверие к независимости бенчмарков этих моделей и риск-профиль для тех, кто сравнивает их с Claude. Официальный пост Anthropic (`anthropic.com/news/detecting-and-preventing-distillation-attacks`) недоступен из этого окружения (сетевой прокси блокирует `anthropic.com`) — по пересказам (The Hacker News, Rappler, Free Malaysia Today, независимо подтверждают одни и те же цифры).

2. **OpenAI открыла публичную бету Agents API** (10.09.2026) — харнес Codex (тот же, что использует Codex CLI/облачные агенты) выставлен как управляемый API: OpenAI держит цикл агента на своей инфраструктуре, разработчик подключает свои инструменты и среду исполнения и платит за токены и вызовы инструментов. Влияние: агентский харнес уровня Codex становится доступен без необходимости писать собственный agent loop — прямой конкурент подходу Claude Managed Agents (`[[claude-managed-agents]]`), у которой ровно такая же модель управления. Официальная страница (`openai.com/index/introducing-the-agents-api`) недоступна из этого окружения — по пересказам (MarkTechPost, XNews, независимо подтверждают дату и модель ценообразования).

3. **DeepSeek выпустила V4.1 Flash и на ходу перевела флагман V4 Pro на неё же по цене Flash** (10.09 и 14.09.2026). V4.1 Flash — первая модель на новой архитектуре Causal Encoder-Decoder (552B параметров, 8B/16B активных на вход/выход), с нативным пониманием изображений; цена $0.15/$0.60 за млн токенов вход/выход не в пик, вдвое дороже в пик ($0.30/$1.20). Старые `deepseek-v4-flash` и экспериментальная vision-версия сняты и маршрутизируются на V4.1 Flash. С 04:00 UTC 14.09.2026 запросы к `deepseek-v4-pro` тоже обслуживаются V4.1 Flash по цене Flash — до выхода V4.1 Pro. Влияние: те, кто вызывал `deepseek-v4-pro` по API, сейчас негласно получают более слабую и дешёвую модель под старым именем — стоит проверить код интеграций, если такой вызов есть. Официальная страница обновлений (`api-docs.deepseek.com`) недоступна из этого окружения — по пересказам (eesel AI, Yotta Labs, BigGo Finance, OpenRouter — сведения о ценах и дате совпадают).

4. **Claude Code 2.1.271** (14.09.2026, первоисточник — официальный changelog). Из практически значимого: **per-command `allowed_domains`** — сэндбокс теперь проверяет и открывает хосты по каждой команде отдельно в Bash/PowerShell/Monitor (сужает разрешения точнее, чем раньше); **`omitClaudeMd`** во фронтматтере агента — сторонний/плагинный субагент может явно отказаться от чтения `CLAUDE.md`/пользовательских правил вместо того, чтобы неявно их наследовать; **fast mode в Remote-сессиях** (облачные и self-hosted раннеры); Markdown-артефакты теперь публикуются как оформленные страницы документов. Влияние: прямо касается инструмента, которым ведётся эта вики — `omitClaudeMd` полезен, если понадобится подключать чужой скилл/субагента, не желающий видеть правила этого репозитория.

5. **Sakana AI выпустила Fugu Max и Fugu Ultra v2 — модели-оркестраторы, недоступные в ЕС/ЕЭЗ** (11.09.2026). Fugu — не единая модель, а обученный роутер, который распределяет подзадачи по пулу открытых и специализированных моделей и рекурсивно вызывает сам себя; заявлен обгон Claude Fable 5/5.1 и GPT-6 Astra на части бенчмарков при том, что сами эти модели не входят в пул роутинга. Открытых весов нет — только хостинг по API. По данным условий использования, сервис явно исключает ЕЭЗ на время работы над соответствием GDPR. Влияние: пример модели, конкурирующей на бенчмарках через оркестрацию чужих моделей, а не собственный вес, и ещё один сервис, недоступный из ЕС по регуляторным причинам, а не техническим. Официальная страница (`sakana.ai/fugu-max-release/`) недоступна из этого окружения — по пересказам (MarkTechPost, DataNorth, TheRoboticsMedia — данные о дате, ценах и ограничении ЕЭЗ совпадают у нескольких независимых источников).
