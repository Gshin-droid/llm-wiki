## Что изменилось

1. **Claude Code 2.1.313–2.1.318 (28.10–04.11.2026) — батч без критических уязвимостей, но с новыми ограничениями по умолчанию.** Самое практичное: **Fast mode для Opus 4.8 объявлен устаревшим 30.10.2026 и будет снят 30.11.2026** — после этого запросы в fast mode станут возвращать ошибку вместо отката на обычный режим, миграция на Opus 5.5 сохраняет ускорение. Остальное — новые ограждения по умолчанию: `permissions.blockWritesOutsideWorkingDirectories` запрещает Write/Edit/NotebookEdit писать за пределы рабочих директорий в любом permission-режиме, не только в auto mode; появилась проверка перед вызовом веб- или shell-инструмента, которая предупреждает, если вызов отправит email аккаунта в сеть; диалоги свыше 200K токенов, оставленные без дела в VS Code/Claude Desktop Code-вкладке, теперь сжимаются сами (idle-компакция). **Влияние:** у кого настроен Fast mode на Opus 4.8 — месяц на переход, иначе ускорение просто пропадёт; новые ограждения сужают то, что агент делает без прямого разрешения, независимо от режима. Первоисточник — официальный changelog `code.claude.com/docs/en/changelog` и `CHANGELOG.md` репозитория `anthropics/claude-code`, прочитаны напрямую.

2. **OpenAI выпустила GPT-6.1 Terra (26.10.2026) — исправление собственной оценки прошлой сводки.** Сводка [[novosti-2026-10-28]] видела это имя в каталоге моделей Codex CLI и explicitly отказалась брать его как факт релиза — официального подтверждения на тот момент не нашлось. За прошедшую неделю независимо совпали несколько изданий и карточка модели на агрегаторе бенчмарков vals.ai (даёт реальный доступ к модели через API, не просто пересказ анонса): GPT-6.1 Terra — средний по цене/мощности преемник GPT-5.6 Terra, заточен под работу с компьютером (computer use), визуальное рассуждение и код; доступен в ChatGPT (Plus/Pro/Business/Enterprise/Edu), в Codex и через API как `gpt-6.1-terra`; цена по большинству пересказов $1/$5 за млн входных/выходных токенов (один источник называет $2/$10 — цифра не сошлась, точная цена не подтверждена); по заявлению OpenAI проходит критический порог кибербезопасности их Preparedness Framework. Официальные страницы `openai.com/*/index/introducing-gpt-6-1-terra/` найдены в поиске, но сам домен `openai.com` недоступен из этого окружения — прочитать напрямую не удалось. **Влияние:** в Codex и ChatGPT появилась более дешёвая модель среднего уровня с заметно ниже заявленной частотой ошибок на сложных подсказках, чем у предыдущего поколения. Источник — по пересказам (независимое совпадение нескольких изданий + карточка vals.ai), первоисточник Anthropic-уровня доверия недоступен из этого окружения.

3. **Mistral выложила открытые веса Mistral Large 4 «Le Chonk» (29.10.2026).** Публичный превью вышел ещё 06.10, веса придерживали; теперь модель (~1 трлн параметров, MoE, по разным пересказам 49–52 млрд активных — цифра расходится) свободно скачивается с Hugging Face под модифицированной лицензией MIT, без подтверждения доступа. Для запуска нужны датацентровые видеокарты уровня Nvidia. Сайт Mistral и карточка репозитория Hugging Face в этом прогоне напрямую не проверялись — опирается на совпадение нескольких независимых изданий. **Влияние:** фронтирная модель с открытыми весами стала доступна для самостоятельного запуска, но порог входа по железу делает это практическим вопросом только для тех, у кого уже есть датацентровые GPU. Источник — по пересказам.

4. **Google меняет условия тарифа Gemini AI Plus с 13.11.2026.** Подписчики самого дешёвого платного тарифа ($4.99/мес) теряют ручной выбор модели Pro в приложении Gemini и в AI Mode Поиска — вручную останутся доступны только более лёгкие Flash/Flash-Lite; лимиты теперь считаются не количеством запросов, а сложностью подсказки, длиной диалога и используемыми функциями, а при исчерпании квоты запросы автоматически уходят на Gemini 3.5 Flash вместо отказа. Тем же изменением верхний тариф AI Ultra подешевел с $250 до $200/мес при увеличенных лимитах. **Влияние:** с 13.11 подписчикам дешёвого тарифа Gemini придётся подстраиваться под автоматический выбор модели вместо явного переключения на Pro. Источник — по пересказам (несколько независимых изданий, включая отраслевые по Android/Google).
