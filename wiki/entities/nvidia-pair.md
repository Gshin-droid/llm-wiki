# NVIDIA PAIR (Personal AI Router)

Бесплатная открытая программа NVIDIA, раздающая запросы к локальным моделям между машинами одной сети. Попала в вики как первый инструмент, делающий локальный вывод **сетевым ресурсом**, а не свойством одной машины.

**Тип:** инструмент (маршрутизатор локального инференса)
**Актуально на:** 2026-09-22
**Версия:** публичная бета v0.1.1 (анонс 03.09.2026 на IFA)
**Репозиторий:** `github.com/NVIDIA/Personal-AI-Router` · **Лицензия:** Apache 2.0

## Маршрутизатор, а не кластер

Каждый запрос исполняется **целиком на одном узле**. PAIR не делит запрос между видеокартами и не объединяет их видеопамять — формулировка технического блога NVIDIA дословна: *«PAIR does not split requests across multiple GPUs or merge VRAM»*. Потолок размера модели задаёт самая мощная одиночная карта в сети, и второй машиной он не поднимается. Выигрыш — параллельность задач: пока один агент занял одну машину, следующий уходит на свободную.

Сам вывод PAIR не делает: модели исполняют **Ollama** или **LM Studio**, PAIR обнаруживает узлы, следит за готовностью, ставит задачи и возвращает ответы.

## Как выбирает узел

Готовность узла → наличие на нём движка вывода → **наличие запрошенной модели именно на этом узле** → текущая загрузка GPU. Одинаковый набор моделей на всех машинах не нужен, но запрос уйдёт только туда, где модель уже скачана.

## Подключение

Выдаёт **Ollama-совместимую и LM Studio-совместимую** точку входа: в приложении меняется только базовый URL, нового API нет. Узлы — Windows с GeForce RTX (серия 20+), DGX Spark/GB10, Mac M4+, Linux с RTX. От 8 ГБ ОЗУ, 20+ ГБ на диске. Интернет нужен только для скачивания моделей.

Безопасность: обнаружение по mDNS, спаривание подтверждается человеком, трафик между узлами шифруется mTLS и не покидает локальную сеть.

## Границы применимости

- **Только одна локальная сеть** — обнаружение идёт по mDNS, машины в разных сетях PAIR не объединит.
- Строго последовательные задачи и один длинный запрос выигрыша почти не дают — признано авторами.
- Не увеличивает доступную видеопамять.
- Бета «специфична к конфигурации»: набор проверенных сочетаний железа и ОС ограничен.
