# Whiteboard (dev.fast)

Настольное приложение, в котором агент для программирования рисует схемы собственной работы — диаграммы, смысловой дифф, журнал принятых им решений — со ссылками в код. Попало в вики как инструмент против «когнитивного долга» при ревью кода, написанного ИИ.

**Тип:** инструмент (ревью работы агента)
**Актуально на:** 2026-09-29
**Репозиторий:** `github.com/devdotfast/whiteboard`, MIT, TypeScript + Rust; форк Code OSS

## Статус

v0.1.5 от 28.09.2026, ранняя стадия, релизы по несколько в неделю. 2,1 тыс. звёзд. Работает с Claude Code, Codex и другими агентами; сборки под macOS, Windows, Linux.

## Что уходит наружу

- Анонимная телеметрия включена по умолчанию; выключается в настройках или переменной `DO_NOT_TRACK=1`.
- Вход через GitHub запрашивает право `repo` (полный доступ к репозиториям).
- Облачное хранилище трасс выключено по умолчанию; при включении полные расшифровки сессий хранятся у dev.fast, и dev.fast может их расшифровать.

## Решение

Не ставим (29.09.2026): ценен тому, кто читает код, а главное полезное — журнал решений агента и схемы в отчёте — переносится без установки. Подробно — [[whiteboard-devfast-agent-review-canvas]].
