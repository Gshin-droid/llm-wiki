# Bohomolov Lab

Автор YouTube-канала и Telegram-канала про инструменты ИИ для не-разработчиков. Ведёт серию **Inside Claude** — разборы механики Claude изнутри (MCP, скиллы, диктовка голосом).

**Тип:** автор контента (YouTube + Telegram).
**Актуально на:** 2026-07-29.

## Что даёт

- Архитектурный разбор скилла: как из однофайловой инструкции собрать многофайловую структуру (ресурсы / логика / правила / связи с внешним миром) — см. [[bohomolov-skill-architecture]].
- Приём, которого не было в вики явно: при выносе части инструкции в отдельный файл надо **явно запретить модели дублировать вынесенное обратно** в SKILL.md, иначе она скопирует «на всякий случай».
- Метапромтинг как способ заказать то, в чём не разбираешься: попросить Claude составить промпт, затем отдать результат в новый чат.

## Качество материала (по одному источнику)

Аудитория — не-разработчики, кода почти нет. Архитектурная часть проверена по официальной документации и подтвердилась; инженерной части (тестирование скилла, eval-цикл, description как триггер) нет вовсе. Одно центральное утверждение — «файл в существующий скилл из чата не дописать, нужно пересобирать целиком» — за два месяца устарело.

Вывод для будущих ingest: брать как иллюстрацию принципов, факты о UI проверять по справке — они протухают быстрее всего. Промо-нагрузка высокая (Ko-fi, PayPal, партнёрские ссылки), обещанные шаблоны раздаются через закрытый Telegram-канал.
