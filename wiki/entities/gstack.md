# gstack

Набор Гарри Тана (Y Combinator) для Claude Code и других агентов: около 50 скиллов-ролей «команды стартапа» — директор, дизайнер, инженерный менеджер, тестировщик, специалист по безопасности, выпуск и выкладка, технический писатель, отдельный блок для iOS. Не ставим — разобран как каталог механизмов.

## Цена установки и обслуживания (по README)

- Нужны Bun 1.4.2+, на Windows ещё Node.js; браузер Chromium через Playwright. На Windows — только через Git Bash или WSL, часть функций недоступна.
- Пишет в `~/.claude/skills/`, `~/.gstack`; в глобальный `settings.json` — хуки при завершении сессии (включён по умолчанию), при старте и вокруг вопросов пользователю; каждый `./setup` правит `settings.json`.
- Установщик предлагает агенту дописать раздел в `CLAUDE.md` и запретить другие браузерные инструменты; режим `--team` коммитит `.claude/` и `CLAUDE.md` в репозиторий.
- Удаление — скрипт или семь ручных шагов; разделы в `CLAUDE.md` убираются руками.

## Сеть и телеметрия (по README)

- Статистика использования выключена по умолчанию.
- Проверка обновлений включена по умолчанию.
- **Внешние проверки включены по умолчанию**: планы, правки и код уходят второй модели (Codex под Claude Code) под логином пользователя; выключаются `gstack-config set codex_reviews disabled`.
- Каждая исходящая отправка пишется строкой в `~/.gstack/security/egress.jsonl`.

## Почему не ставим

Дублирует уже стоящие [[superpowers]] и [[mattpocock-skills]] (планирование, проверка кода, тестирование), дорог в обслуживании, отправляет код наружу без отдельного решения пользователя, ставится по схеме «вставь в агента, он сделает остальное» — то есть исполняется до того, как установку успели прочитать.

## Что берём логикой

- **Журнал исходящих отправок** — строка на каждую отправку наружу: кому, что, когда. Кандидат для шлюза дешёвых моделей вместе с маскировкой личных данных.
- Не разобраны, но стоят внимания: `/careful`, `/freeze`, `/guard` — режимы «осторожно» и «заморозить файлы».
