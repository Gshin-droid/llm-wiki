# Material 3 Expressive

Расширение дизайн-системы Google Material Design 3: обновлённые темы, компоненты, движение и типографика. Попало в вики как словарь, в котором [[m3e-canvas]] формулирует задание агенту, — и как пример того, что словарь референса привязан к стеку.

**Тип:** дизайн-система
**Актуально на:** 2026-11-21
**Документация:** `m3.material.io`

## Что это

Обновление Material Design 3, вышедшее официально вместе с **Android 16**. Google называет его самым проверенным своим дизайнерским обновлением: 46 циклов исследований, 18 тысяч участников; заявленная цель — сделать интерфейс менее казённым.

Практическая часть — **15 новых и обновлённых компонентов**, в которые встроены три основы системы: акцентная типографика, физика движения и перетекание форм (shape morphing).

## Где реализовано

- **Jetpack Compose — полная поддержка.** Компоненты живут в библиотеке Material 3; часть до сих пор требует явного согласия на экспериментальный API (`@OptIn(ExperimentalMaterial3ExpressiveApi::class)`), хотя отдельные, например списковые элементы, из экспериментальных уже выведены.
- **React Native (`react-native-paper`) — фундамент вышел в alpha, видимые компоненты всё ещё открытыми пул-реквестами.** Допроверка 2026-10-01 разобрала это на два слоя, а не одну метку «в работе»:
  - **Вышло в `6.0.0-alpha.0` (15.06.2026), сама версия — пререлиз, не стабильный релиз:** токены темы (`theme.shapes`/`cornersToStyle`, `theme.state` opacity-токены, таблица цветовых ролей, `DynamicTheme`), токены движения (spring/easing/duration), эмфатическая типографика (emphasized typescale), токены возвышения (elevation), редизайн **FAB** (ломающее изменение — удалены `mode`/`small`/`color`), модернизация Checkbox и Switch.
  - **Всё ещё открытые пул-реквесты, не вышли даже в alpha:** Carousel, Card, Button (дважды — модернизация под MD3 Expressive и отдельно API `label`/`iconPosition`), Appbar, Menu (попытка #5037 закрыта, актуальная #5073 открыта), Navigation Bar, Bottom Navigation, Progress Indicators, Searchbar, Icon Button.

Отсюда практическое следствие для любого макета, собранного в этом словаре: **вне Jetpack Compose почти все видимые компоненты придётся заменять аналогами** — в React Native готов только низкоуровневый фундамент (токены) и FAB, причём в пререлизной ветке. Подробнее — [[maket-kak-tz-dlya-agenta]], раздел «Границы приёма».

## Допроверка 2026-11-21: Button вышел в alpha.2, Appbar смёрджен в main (ждёт 6.0.0-beta.0)

Ежедневный процесс закрытия пробелов (субботний обычный порядок). Вторая по давности просроченная «Актуально на» среди продуктовых страниц после [[letta]] (сверена этим же прогоном). Прочитаны напрямую страница релизов `github.com/callstack/react-native-paper/releases`, PR #5218 и changelog-страницы `v6.0.0-alpha.1`/`v6.0.0-alpha.3` — не только заголовки, как уже предостерегала запись от 10-01.

**С 6.0.0-alpha.0 (15.06) вышло три новых пререлиза**, две видимые Expressive-компоненты продвинулись из «открытый PR» дальше:
- **Button (#5097, merged) — вошёл в 6.0.0-alpha.2 (09.11)** с явной пометкой «Button moves to Material 3 Expressive»: `contained`/`contained-tonal` переименованы в `filled`/`tonal`, дефолтный режим стал `filled`, добавлены `size`, `shape`, `selected`, `iconPosition` — ломающие изменения.
- **Appbar (#5218, merged в `main` 19.11) — пока не в тегированном релизе**: milestone указывает на предстоящий **6.0.0-beta.0** (не следующий alpha). Контекст вместо клонирования детей, новые режимы `medium-flexible`/`large-flexible`, новые пропсы `Appbar.Action` (`variant`, `width`), `isScrolled`; старая нижняя панель помечена устаревшей до появления Toolbar. Более ранний PR #5173 (альтернативная реализация) закрыт без мержа — путь к Expressive Appbar пошёл через #5218, не через него.
- **Card (#5116) остаётся открытым PR**, как и Carousel/Menu/Navigation Bar/Bottom Navigation/Progress Indicators/Searchbar/Icon Button — без изменений статуса с 10-01.

Побочно: стабильная ветка v5 продолжает выпускаться параллельно с альфами v6 (5.15.5 — 16.11, та же дата, что alpha.3) — значит, Expressive-ветка v6 не замена текущему стабильному релизу, а отдельная параллельная линия, которую надо явно выбирать. Breaking changes в alpha.1/alpha.3 многочисленны (ARIA-пропсы вместо `accessibility*`, Reanimated-стили вместо `style` на фон/радиус, удаление `ToggleButton`) — для переноса макета из этого словаря в React Native цена входа в сам v6-трек выросла, не только список готовых компонентов.

Деталь не проверена: вошли ли изменения Button (#5097) именно в тег alpha.2 целиком или частично — страница релиза alpha.2 отдельно не перечитывалась, вывод сделан по единственной явной строке её changelog.

Безопасность: прочитанные файлы — официальные страницы репозитория GitHub (релизы, PR), инструкций агенту не найдено. Ничего не устанавливалось.
