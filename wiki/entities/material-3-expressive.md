# Material 3 Expressive

Расширение дизайн-системы Google Material Design 3: обновлённые темы, компоненты, движение и типографика. Попало в вики как словарь, в котором [[m3e-canvas]] формулирует задание агенту, — и как пример того, что словарь референса привязан к стеку.

**Тип:** дизайн-система
**Актуально на:** 2026-10-01
**Документация:** `m3.material.io`

## Что это

Обновление Material Design 3, вышедшее официально вместе с **Android 16**. Google называет его самым проверенным своим дизайнерским обновлением: 46 циклов исследований, 18 тысяч участников; заявленная цель — сделать интерфейс менее казённым.

Практическая часть — **15 новых и обновлённых компонентов**, в которые встроены три основы системы: акцентная типографика, физика движения и перетекание форм (shape morphing).

## Где реализовано

- **Jetpack Compose — полная поддержка.** Компоненты живут в библиотеке Material 3; часть до сих пор требует явного согласия на экспериментальный API (`@OptIn(ExperimentalMaterial3ExpressiveApi::class)`), хотя отдельные, например списковые элементы, из экспериментальных уже выведены.
- **React Native (`react-native-paper`) — фундамент вышел в alpha, видимые компоненты всё ещё открытыми пул-реквестами.** Допроверка 2026-10-01 разобрала это на два слоя, а не одну метку «в работе»:
  - **Вышло в `6.0.0-alpha.0` (15.06.2026), сама версия — пререлиз, не стабильный релиз:** токены темы (`theme.shapes`/`cornersToStyle`, `theme.state` opacity-токены, таблица цветовых ролей, `DynamicTheme`), токены движения (spring/easing/duration), эмфатическая типографика (emphasized typescale), токены возвышения (elevation), редизайн **FAB** (ломающее изменение — удалены `mode`/`small`/`color`), модернизация Checkbox и Switch.
  - **Всё ещё открытые пул-реквесты, не вышли даже в alpha:** Carousel, Card, Button (дважды — модернизация под MD3 Expressive и отдельно API `label`/`iconPosition`), Appbar, Menu (попытка #5037 закрыта, актуальная #5073 открыта), Navigation Bar, Bottom Navigation, Progress Indicators, Searchbar, Icon Button.

Отсюда практическое следствие для любого макета, собранного в этом словаре: **вне Jetpack Compose почти все видимые компоненты придётся заменять аналогами** — в React Native готов только низкоуровневый фундамент (токены) и FAB, причём в пререлизной ветке. Подробнее — [[maket-kak-tz-dlya-agenta]], раздел «Границы приёма».

## Допроверка 2026-10-01

Прежняя запись («в работе, не готово») была собрана по заголовкам без чтения PR и релизов — это не расхождение, а недостающая детализация. Прочитаны напрямую: список пул-реквестов `callstack/react-native-paper` по тегу «expressive» и официальная страница релизов (`github.com/callstack/react-native-paper/releases`). Открытых PR по видимым компонентам — минимум десять, ни один не смёржен; фундамент (токены, FAB, Checkbox/Switch) смёржен и вошёл в единственный существующий пререлиз 6.0.0-alpha.0, стабильного релиза с Material 3 Expressive ещё нет. Не проверено: точные даты мёржа отдельных «фундаментных» PR относительно тега alpha (нумерация PR не даёт точных timestamps), и есть ли более новый пререлиз после 6.0.0-alpha.0 — `releases` не показал ничего после 15.06.2026.
