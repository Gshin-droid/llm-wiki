# shunt (Spotify)

Плагин Claude Code от Spotify: хук запрещает читать целиком файлы длиннее порога (по умолчанию 350 строк) и отправляет их дешёвой модели за выжимкой; типовой код пишет дешёвая модель сразу на диск. Работает только через внутреннюю платформу Spotify Portal. Не ставим.

**Тип:** инструмент (плагин Claude Code, Apache-2.0)
**Автор:** Spotify
**Актуально на:** 2026-10-19 (репозиторий `spotify/portal-ai-plugins`, обновлён 2026-10-12, ~2 500 звёзд — по GitHub)
**Ссылка:** https://github.com/spotify/portal-ai-plugins
