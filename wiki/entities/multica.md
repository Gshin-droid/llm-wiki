## Продукт Multica — допроверка 2026-08-17
Ежедневный процесс закрытия пробелов. Прежний открытый вопрос ("собственно продукт не изучен отдельно") закрыт: официальный `github.com/multica-ai` доступен напрямую (домен `multica.ai` не проверялся). Основной репозиторий `multica-ai/multica` (46.2k звёзд, 5.9k форков, Go-бэкенд + Next.js фронтенд + Electron-десктоп + CLI) — open-source, self-hostable платформа для делегирования задач нескольким coding-агентам как «тиммейтам»: единая доска, назначение issue агенту, логи выполнения с таймстампами и токенами, git-интеграция (GitHub/GitLab/Gitea/Forgejo), self-hosting через Docker Compose/Helm либо облачная версия на `multica.ai`/десктоп-приложение (macOS/Windows/Linux). Поддерживает 20 агентов, включая Claude Code, Codex, Cursor Agent, GitHub Copilot CLI, OpenCode, Grok, Kimi и другие. Подтверждено двумя независимыми фетчами страницы репозитория (совпадающие цифры и формулировки).

Побочно подтверждён рост исходного репозитория гайдлайнов: `andrej-karpathy-skills` — 203k+ звёзд на 08-17 (188.8k на 07-07), но это не первичная проверка, а попутное наблюдение из того же фетча организации — при отдельной сверке [[karpathy-skills-claude-md]] стоит подтвердить цифру напрямую.

## Допроверка 2026-10-08 (ежедневный процесс закрытия пробелов)

Повторное истечение порога (08-17 → сейчас, 52 дн.). `raw.githubusercontent.com/multica-ai/multica/main/README.md` и `LICENSE`, плюс страница репозитория — прочитаны напрямую.

**Рост, не расхождение:** звёзды **46.2k → 52.1k**, форки **5.9k → 6.8k**; число поддерживаемых агентов выросло **20 → 26** (добавились Qwen Code, Trae CLI и другие). Новое, чего страница не знала: отдельный **мобильный клиент (Expo / React Native)** помимо web/Electron-десктоп/CLI; бэкенд на PostgreSQL 17 (`pgcrypto` + `pg_trgm`) не был указан.

**Уточнение, меняющее формулировку «open-source, self-hostable»:** лицензия — не чистый Apache 2.0, а собственная **Multica License** (полный текст Apache 2.0 + дополнительные условия, Part I поверх Part II). Ключевое ограничение: без отдельной коммерческой лицензии **нельзя предоставлять Multica как хостинг-сервис третьим лицам** — дословно «you may not use the Multica source code to provide a hosted service to third parties», причём бесплатность не освобождает от этого правила. Самостоятельный self-hosting внутри одной организации (в том числе с несколькими workspace) коммерческой лицензии не требует — сценарий со страницы («self-hosting через Docker Compose/Helm») под это ограничение не попадает. Отдельно — запрет менять логотип/название/копирайт в UI без письменного branding waiver (не касается запуска без UI — только backend/daemon/CLI). Формулировка «open-source» выше не удаляется, но нуждается в этой оговорке: это source-available с ограничением на перепродажу хостинга, не permissive-лицензия.
