## Продукт Multica — допроверка 2026-08-17
Ежедневный процесс закрытия пробелов. Прежний открытый вопрос ("собственно продукт не изучен отдельно") закрыт: официальный `github.com/multica-ai` доступен напрямую (домен `multica.ai` не проверялся). Основной репозиторий `multica-ai/multica` (46.2k звёзд, 5.9k форков, Go-бэкенд + Next.js фронтенд + Electron-десктоп + CLI) — open-source, self-hostable платформа для делегирования задач нескольким coding-агентам как «тиммейтам»: единая доска, назначение issue агенту, логи выполнения с таймстампами и токенами, git-интеграция (GitHub/GitLab/Gitea/Forgejo), self-hosting через Docker Compose/Helm либо облачная версия на `multica.ai`/десктоп-приложение (macOS/Windows/Linux). Поддерживает 20 агентов, включая Claude Code, Codex, Cursor Agent, GitHub Copilot CLI, OpenCode, Grok, Kimi и другие. Подтверждено двумя независимыми фетчами страницы репозитория (совпадающие цифры и формулировки).

Побочно подтверждён рост исходного репозитория гайдлайнов: `andrej-karpathy-skills` — 203k+ звёзд на 08-17 (188.8k на 07-07), но это не первичная проверка, а попутное наблюдение из того же фетча организации — при отдельной сверке [[karpathy-skills-claude-md]] стоит подтвердить цифру напрямую.
