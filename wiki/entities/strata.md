# Strata

Открытый (MIT) инференс-движок, запускающий Qwen3.8-Flash-Next (MoE, 24 576 экспертов) на одной игровой видеокарте потребительского класса через offloading в RAM/SSD; даёт OpenAI- и Anthropic-совместимый API на `127.0.0.1`. Не ставим (нет подтверждённого железа 12 ГБ+ VRAM/32–64 ГБ RAM), оценён по README.

**Тип:** инструмент (локальный инференс-движок)
**Актуально на:** 2026-11-02
**Версия/статус:** не указан явно README (preview/stable неизвестен); демо-ссылка называет v0.1.10; 532 коммита, 188 звёзд, 20 форков на момент чтения
**Репозиторий:** `github.com/mach10x/strata` (форк `Niko1221/Strata`) · **Лицензия:** MIT (модели и часть компонентов — свои лицензии)

## Назначение

Модели класса Qwen3.8-Flash-Next обычно требуют серверных GPU с сотнями ГБ видеопамяти. Strata распределяет вычисление по всему ПК: часто спрашиваемые эксперты — на видеокарте, остальные — в RAM, таблица поиска — на SSD; speculative decoding (маленький помощник угадывает слова, большая модель проверяет все сразу) даёт 1.6–1.8× ускорения.

## Требования

GPU NVIDIA RTX 20/30/40/50 или AMD RX 6800/6900/7700 XT+/9060 XT/9070/R9700, от 12 ГБ VRAM; от 32 ГБ RAM (64 ГБ — все размеры модели); ~80 ГБ диска (желательно SSD); Windows 10/11 или Linux.

## Интеграция

- OpenAI-совместимое приложение: base URL `http://127.0.0.1:8080/v1`, любой ключ/имя модели.
- Anthropic-совместимое приложение / Claude Code: `http://127.0.0.1:8080/v1/messages`, для Claude Code — `ANTHROPIC_BASE_URL=http://127.0.0.1:8080`.
- Удалённый доступ (телефон/другой ПК): только с явным `--host 0.0.0.0 --api-key <secret>`.
- Агенты могут ставить, запускать и останавливать Strata сами через её собственный MCP-сервер — README прямо приводит готовый текст-рецепт для вставки в ассистента.
