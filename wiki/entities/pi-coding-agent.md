# Pi (pi-coding-agent)

Открытый терминальный агент-харнес от Earendil Works: маленькое ядро плюс расширения на TypeScript. Попал в вики как платформа, поверх которой NVlabs построила [[sol-pi]] — без Pi тот не работает.

**Тип:** инструмент (агентный харнес)
**Актуально на:** 2026-09-28
**Репозиторий:** `github.com/earendil-works/pi` · npm: `@earendil-works/pi-coding-agent`
**Сайт:** pi.dev
**Лицензия:** MIT
**Версия:** 0.87.1 (22.09.2026)

## Устройство

Заявленная позиция — **минимальный харнес, который подстраивают под себя, а не наоборот**: не превращать каждую возможность в фиксированную кнопку, а дать расширять. Настраивается расширениями на TypeScript, скиллами, шаблонами промптов, темами и пакетами. Работает в четырёх режимах: интерактивный, печать/JSON, RPC для встраивания в чужой процесс и SDK для встраивания в своё приложение.

Разница с [[claude-code]] по замыслу: тот идёт от готовых возможностей и продуктовых решений, Pi — от сменных частей. Ближайший сосед в вики по этой оси — [[deepseek-harness]], с той же ставкой на сменность и тем же следствием: экосистему расширений придётся собирать самому.

## История

Создан разработчиком Mario Zechner, распространялся из репозитория `pi-mono` под его аккаунтом `badlogic`. В мае 2026 проект передан Earendil Works, репозиторий переехал в организацию `earendil-works`, пакеты npm переименованы в пространство `@earendil-works`.

## Допроверка 2026-09-28

`npmjs.com` (веб-страница пакета) по-прежнему недоступен — 403 сохраняется. Но два запасных первоисточника оказались достаточны и без него: `registry.npmjs.org` (API реестра, а не веб-страница) и сам репозиторий `github.com/earendil-works/pi` (README, `LICENSE`, страница релизов) — все три прочитаны напрямую.

**Лицензия — MIT**, подтверждена дважды независимо: файлом `LICENSE` в репозитории (дословно «MIT License / Copyright (c) 2025 Mario Zechner») и полем `license` в ответе `registry.npmjs.org`. Копирайт остался на имени первоначального автора даже после передачи проекта Earendil Works (05.2026) — сама передача организации это не отменяет.

**Версия — 0.87.1**, опубликована 22.09.2026 (страница релизов репозитория подтверждает дважды: список версий и дата тега). Восемь релизов с 07.08 по 22.09 — активная разработка. Побочно полезное для [[nvidia-sol-pi-harness]]: версия, под которую заявлена совместимость SoL-Pi (0.85.1), вышла 05.09.2026 — с тех пор Pi ушёл на две минорных версии вперёд (0.86.0, 0.86.1, 0.87.0, 0.87.1), совместимость SoL-Pi с текущей версией не переподтверждена ни одним источником.

**Список провайдеров моделей** (пакет `packages/ai`, README прочитан напрямую) — больше, чем ожидалось по каталогу из двух моделей ([[sol-pi]] тестировался только на GPT-5.6 Sol/Opus 5): OpenAI, Anthropic (включая подписку Claude Pro/Max), Google/Vertex AI, DeepSeek, Mistral, Groq, Cerebras, xAI, OpenRouter, Amazon Bedrock, Together AI, Hugging Face, GitHub Copilot (по подписке), Moonshot AI, и ещё около полутора десятков более нишевых — плюс явная поддержка любого OpenAI-совместимого эндпоинта («Ollama, vLLM, LM Studio, etc.») и собственных прокси.

**Монетизация — у самого Pi её нет.** Инструмент MIT и бесплатен; платность приходит только со стороны выбранного провайдера модели (например, обязательная подписка ChatGPT Plus/Pro для доступа через OpenAI Codex, или Copilot-подписка для GitHub Copilot) — это плата провайдеру, не Pi.

**Не установлено (мелкий нюанс, не заводится отдельным пунктом):** точная дата публикации версии 0.87.1 в самом npm-реестре — `registry.npmjs.org` не отдал объект `time` в прочитанном фрагменте; дата взята со страницы релизов GitHub, это тот же тег, но не тот же файл.
