# Inspo

MCP-сервер с архивом реальных сайтов (2 320 страниц с 832 сайтов, DESIGN.md каждого снят с кода, 68 образцовых блоков), которые агент изучает перед вёрсткой интерфейса. Кандидат в источник якоря стиля; не подключён, пробы назначены.

**Тип:** инструмент (MCP-сервер, MIT)
**Автор:** Hassan El Mghari и соавторы, Together AI
**Актуально на:** 2026-11-26 (допроверка по первоисточнику)
**Ссылка:** https://github.com/Nutlope/inspo

## Как подключать

Вручную и только в проект: `claude mcp add --transport http inspo https://inspomcp.dev/api/mcp`. Установщик `npx inspo-mcp install` не использовать — сам правит настройки всех найденных агентов. Выключение: `claude mcp remove inspo`.

## Допроверка 2026-11-26

Первая содержательная сверка по первоисточнику с момента разбора (10-19 → сейчас, 38 дн.) — пункт из пяти никогда не допроверявшихся страниц воскресного механического прохода 11-22 (вместе с `spotify-shunt-plugin`, остальные три уже закрыты). README `github.com/Nutlope/inspo` и `apps/mcp/README.md` прочитаны напрямую через `WebFetch` (`raw.githubusercontent.com`), плюс `registry.npmjs.org/inspo-mcp` и страница репозитория.

Рост: версия пакета **0.1.16 → 0.2.0** (28.10.2026) — первый минорный скачок (0.1.x → 0.2.0), содержание изменений не установлено: ни `CHANGELOG.md`, ни GitHub Releases в репозитории нет. Звёзды ~900 → **1,1k**, форки — **76** (не были известны).

**Находка — облегчённый профиль инструментов.** Полный профиль (15 тулов) не единственный: переменная `INSPO_PROFILE=lite` включает укороченный список из **9** инструментов (`recommend`, `search_screens`, `get_screen`, `get_design_system`, `find_examples_for_macrostructure`, `find_reference_components`, `get_reference_jsx`, `get_site_pages`, `get_filters`) — без `compare`/`find_by_color`/`find_similar`/`find_components`/`list_collections`/`get_collection`. Та же идея снижения токенного налога, что у tool profiles [[memora]] (допроверка 09-14) — независимое второе подтверждение приёма у другого MCP-сервера.

**Закрыты два открытых вопроса страницы-источника.** (1) Ограничения `get_design_system(live:true)` подтверждены дословно README: разрешены только публичные именованные хосты (не IP), порты 80/443, тело ответа ограничено по размеру, JavaScript не исполняется, каждый URL и каждый редирект проходят SSRF-защиту. (2) Заявление «хостед-сервер не логирует IP и текст запроса» — README прямо формулирует это как факт (не пересказ источника вики), логируются только имя тула, успех и длительность вызова; независимой проверки кода всё равно нет — доверие к слову поставщика остаётся тем же, но раньше формулировка не была сверена с первоисточником напрямую.

Деталь не проверена: похожий `notsointresting/frontend-inspo-mcp` всё ещё не разбирался.
