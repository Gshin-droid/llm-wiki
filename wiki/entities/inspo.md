# Inspo

MCP-сервер с архивом реальных сайтов (2 320 страниц с 832 сайтов, DESIGN.md каждого снят с кода, 68 образцовых блоков), которые агент изучает перед вёрсткой интерфейса. Кандидат в источник якоря стиля; не подключён, пробы назначены.

**Тип:** инструмент (MCP-сервер, MIT)
**Автор:** Hassan El Mghari и соавторы, Together AI
**Актуально на:** 2026-10-19 (пакет `inspo-mcp` 0.1.16, репозиторий `Nutlope/inspo` обновлён 2026-10-01 — сверено по npm и GitHub)
**Ссылка:** https://github.com/Nutlope/inspo

## Как подключать

Вручную и только в проект: `claude mcp add --transport http inspo https://inspomcp.dev/api/mcp`. Установщик `npx inspo-mcp install` не использовать — сам правит настройки всех найденных агентов. Выключение: `claude mcp remove inspo`.
