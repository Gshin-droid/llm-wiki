# Superpowers

**Тип:** инструмент (open source набор скиллов для агентской разработки, TDD-ориентированный)
**Актуально на:** 2026-08-12

## Что это
Набор скиллов на разные этапы разработки (идея → спека → план → сборка (TDD) → проверка → финиш), устанавливаемый как plugin в Claude Code, Codex CLI, Gemini, OpenCode, Cursor. Легче и менее токен-затратный, чем [[gsd-get-shit-done]] — под небольшие/некорпоративные проекты.

Ключевой скилл — **`using superpowers`**: диспетчер, сам определяющий, какой скилл из набора нужен на текущем этапе (brainstorming для спеки, writing plans для декомпозиции, TDD для сборки, verification-before-complete, finish-development-branch). При исполнении плана может выбрать **subagent-driven execution** — самостоятельно создаёт именованных субагентов с явной ролью под конкретные подзадачи, работающих параллельно волнами; также автоматически подключает сторонние обнаруженные скиллы (пример: `frontend-design`, `deploy-to-vercel`), то есть работает как рамочная система с автообнаружением инструментов, а не жёсткий фреймворк.

## Допроверка 2026-08-12 (ежедневный процесс закрытия пробелов): автор и масштаб

Официальный репозиторий `github.com/obra/superpowers` прочитан напрямую (первоисточник, ранее на странице не читался). Уточнено то, чего страница не называла:

- **Автор** — Jesse Vincent (`obra`) и команда Prime Radiant. На странице до этой сверки автор не был указан вообще.
- **Масштаб** — 270.8k звёзд на GitHub на момент проверки (WebSearch до прямого чтения репозитория давал более старую и заниженную цифру ~174k — расхождение снято чтением самого репозитория, а не поиска).
- **Список хостов расширился за пределы известных пяти** (Claude Code, Codex CLI, Gemini, OpenCode, Cursor): подтверждено ещё шесть — Antigravity, Codex App (отдельно от Codex CLI), Factory Droid, GitHub Copilot CLI, Kimi Code, Pi. У каждого — свой способ установки (например, официальный маркетплейс Claude Code: `/plugin install superpowers@claude-plugins-official`; Gemini CLI: `gemini extensions install https://github.com/obra/superpowers`).
- **Subagent-driven-development** (упомянутый на странице как одна из способностей диспетчера) устроен как двухступенчатое ревью: сначала проверка соответствия спеке, затем проверка качества кода — детали, которых на странице раньше не было.

Сетевой прокси окружения сегодня блокировал почти все домены, кроме `github.com` (arxiv.org, huggingface.co, researchgate.net, semanticscholar.org, blog.getzep.com, web.archive.org, en.wikipedia.org — все вернули `EGRESS_BLOCKED` в этом прогоне), поэтому проверка велась только по официальному репозиторию, без стороннего подтверждения.
