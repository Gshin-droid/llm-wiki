# VoiceStudio

Открытая (AGPL-3.0) локальная студия синтеза и распознавания речи: клонирование голоса, дизайн голоса, дубляж видео, транскрибация, аудиокниги; ~98.8k звёзд на GitHub. Не ставим (нет собственной задачи сейчас), оценена по README и `docs/speech-platform.md`.

**Тип:** инструмент (локальная TTS/ASR-студия)
**Актуально на:** 2026-11-02
**Репозиторий:** `github.com/debpalash/VoiceStudio` (ранее — OmniVoice Studio) · **Лицензия:** AGPL-3.0 (приложение) + коммерческая лицензия для закрытого использования; веса моделей и голоса — свои лицензии для каждой модели

## Возможности

Клонирование голоса по короткой эталонной записи; дизайн голоса по текстовому описанию; озвучка и дубляж видео с таймингом под оригинал; диктовка и транскрибация (плавающий виджет); аудиокниги и пакетная генерация с очередями задач. Движок по умолчанию — на базе `k2-fsa/OmniVoice`, плюс десятки дополнительных engine в Model Manager (среди них `whisper.cpp` для ASR, CosyVoice GGUF для TTS). 646 языков.

## Интеграция

- Локальный API: `POST 127.0.0.1:3900/v1/audio/transcriptions` (OpenAI-совместимый эндпоинт распознавания, порт — `OMNIVOICE_PORT`), WebSocket-стриминг на том же порту.
- MCP-сервер: Streamable HTTP (`:3900/mcp/`) и stdio — даёт агенту инструменты транскрибации файлов и речи, но **намеренно не позволяет** удалённо включить микрофон десктоп-приложения («No interface can turn on the desktop app's microphone remotely»).
- Статус платформ: stable — macOS (Apple Silicon), Windows 10/11 (x64), Linux (x64), Docker; preview — Android/iOS; experimental — Windows ARM.
