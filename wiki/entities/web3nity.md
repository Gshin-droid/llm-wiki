# Web3nity

Автор YouTube-видео и Telegram-канала про практическое применение ИИ. В вики попал через разбор методологии создания презентаций с помощью ИИ-агента.

**Тип:** автор контента (YouTube + Telegram).
**Актуально на:** 2026-07-29.

## Что даёт
- Пошаговая методология «презентация через ИИ-агента»: смысл → визуал → сборка (см. [[ai-presentation-workflow]]).
- Рамка отбора задач для вайбкодинга и каталог типовых инструментов для не-разработчика (см. [[vibecoding-task-selection]]).
- 4 авторских скилла для агента (Story Architect / Style Interpreter / Visual Identity DNA / Presentation Builder) — раздаются только через приватный Telegram-канал, публично не выложены.
- Практическая лестница подключения нового сервиса по MCP и предупреждение «каталог — это витрина» (см. [[mcp-model-context-protocol]]).

## Качество материала (по четырём источникам)
Формат — обзорно-объяснительный, для не-разработчиков; глубина ниже уровня этой вики, полезны отдельные практические блоки. Но **фактических ошибок в проверенных утверждениях не найдено ни разу**, границы применимости автор оговаривает явно. Это выгодно отличает её от [[neiroprosveshchenie]], где проверка вскрыла искажения статистики и путаницу skills/MCP. Вывод для будущих ingest: материал брать выборочно, но перепроверять можно без презумпции ошибки.

**Дополнение 2026-08-31.** Четвёртый материал ([[web3nity-gpt56-fable5-cases]]) заметно слабее первых трёх по плотности проверяемой техники — большинство кейсов пересказаны с чужих слов без ссылок, промо-нагрузка (реферальные ссылки на Abacus, контент за подпиской на Telegram) выше обычного. Презумпция «фактических ошибок не найдено» не опровергнута, но и не подтверждена заново — почти нет проверяемых утверждений, кроме описанных методов (не измеримых фактов).
