# Hindsight

Открытая система долговременной памяти для агентов от Vectorize. Отличается от соседей тем, что не только хранит, но и сводит факты в выводы, которые пересобираются при новых данных.

**Тип:** инструмент
**Актуально на:** 2026-10-12 (сверено с репозиторием `vectorize-io/hindsight`: 48,6k★, MIT, v0.10.3 от 2026-10-08)

## Что это

Четыре вида памяти (по README):

- **World facts** — факты о внешнем мире;
- **Experiences** — собственные прошлые взаимодействия агента;
- **Observations** — «сведённые, подкреплённые доказательствами убеждения, собранные из многих воспоминаний»; у наблюдения цитаты-доказательства и счётчик подтверждений;
- **Mental models** — устоявшееся понимание мира агента, синтезированное из наблюдений и фактов.

Три операции: **retain** (модель извлекает факты, время, сущности, связи), **recall** (четыре поиска параллельно: по смыслу, по словам, по графу связей, по времени), **reflect** (анализ накопленного).

Хранение: PostgreSQL с pgvector у себя, встроенный режим на Python, либо облако Hindsight Cloud. Для извлечения фактов нужна модель: OpenAI, Anthropic, Gemini, Groq, Ollama, `openai-codex`, `claude-code`.

## Плагин для Claude Code

По README `hindsight-integrations/claude-code`:

| Хук | Что делает |
|---|---|
| `SessionStart` | проверяет, что сервер памяти отвечает |
| `UserPromptSubmit` | на **каждое** сообщение ищет память и подкладывает её как `additionalContext` — Claude видит, пользователь нет |
| `Stop` (асинхронно) | после ответа отправляет переписку на извлечение фактов (каждые N ходов, скользящим окном) |
| `SessionEnd` | гасит запущенный им сервер |

Плюс MCP-сервер с инструментами `agent_knowledge_*`. Настройки — `~/.hindsight/claude-code.json`, локальный сервер на порту 9077, ставится через `uvx` (по умолчанию версия `latest`). Память по умолчанию одна на все проекты; `HINDSIGHT_DYNAMIC_BANK_ID=true` разводит по проектам. Режим `claude-code` — «только для личного использования», по словам авторов.

## Решение для нашей среды

Не ставим — причины на [[hindsight-agentnaya-pamyat]]: пишет без проверки, тратит лимит подписки на каждом ответе (кроме режима `ollama`), тянет непроверенную версию. Логика «наблюдение с доказательствами и счётчиком подтверждений» — перенесена в общие правила 2026-10-12: пометка «подтверждено: даты» у правил, выросших из случая.
