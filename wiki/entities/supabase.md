# Supabase

**Тип:** инструмент (Backend-as-a-Service)
**Актуально на:** 2026-10-16

## Что это
Готовый бэкенд: база данных (PostgreSQL), авторизация, файловое хранилище (buckets), serverless-функции (Edge Functions) и секреты — из коробки, без необходимости писать свой сервер. В вайбкодинге закрывает всю бэкенд-часть, пока разработчик описывает логику естественным языком через Claude/ИИ-агента.

## Роль в вайбкодинг-воркфлоу
См. [[vibecoding-full-workflow]] — Supabase хранит схему БД (SQL-миграции), файлы (buckets), секретные ключи (Edge Function secrets, чтобы не светить их на фронтенде).

## Допроверка 2026-08-14
Ежедневный процесс закрытия пробелов. Официальный `github.com/supabase/supabase` (README, прочитан напрямую — прокси окружения сегодня блокировал `supabase.com` и почти все домены кроме `github.com`) подтвердил компоненты, уже известные вики (Postgres, авторизация через GoTrue, storage, Edge Functions), без расхождений. Уточнение, которого страница раньше не называла: авто-генерируемые REST (PostgREST) и GraphQL (`pg_graphql`) API поверх той же базы, встроенный AI-toolkit (векторные embeddings) и официальные клиентские библиотеки для JS/Python/Flutter/Swift (плюс community — Go/Rust/Kotlin/C#). Архитектурный принцип: продукт собран из существующих open-source инструментов с MIT/Apache 2 лицензиями, а не написан с нуля.
