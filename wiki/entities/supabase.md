# Supabase

**Тип:** инструмент (Backend-as-a-Service)
**Актуально на:** 2026-11-28

## Что это
Готовый бэкенд: база данных (PostgreSQL), авторизация, файловое хранилище (buckets), serverless-функции (Edge Functions) и секреты — из коробки, без необходимости писать свой сервер. В вайбкодинге закрывает всю бэкенд-часть, пока разработчик описывает логику естественным языком через Claude/ИИ-агента.

## Роль в вайбкодинг-воркфлоу
См. [[vibecoding-full-workflow]] — Supabase хранит схему БД (SQL-миграции), файлы (buckets), секретные ключи (Edge Function secrets, чтобы не светить их на фронтенде).

**Главная находка — AI/Vector toolkit раскрыт.** Прошлые две допроверки (08-14, 10-16) фиксировали только факт существования пункта «AI + Vector/Embeddings Toolkit» в README без деталей. В `apps/docs/content/guides/ai/` — отдельная секция документации с полным описанием: механизм — [pgvector](https://github.com/pgvector/pgvector/), обычное расширение Postgres (`create extension vector`), а не отдельный сервис; гайды по векторным колонкам, индексам, гибридному/семантическому/keyword-поиску, автоматическим эмбеддингам, RAG с учётом прав доступа. Эмбеддинги через открытую модель `gte-small` (384 измерения) как референсный пример.

**Self-hosting — впервые разобран по существу, раньше страница об этом вообще не писала.** `apps/docs/content/guides/self-hosting/docker.mdx`: Docker Compose — основной путь (<15 минут), два варианта установки — автоматический скрипт (`curl -fsSL https://supabase.link/setup.sh | sh`, только Linux) или ручной клон репозитория на любой ОС. Требования к ресурсам: минимум 4 ГБ ОЗУ/2 ядра/40 ГБ SSD, рекомендовано 8 ГБ+/4 ядра+/80 ГБ+ SSD — можно уменьшить, отключив ненужные сервисы (Realtime/Storage/imgproxy/Edge Runtime) из `docker-compose.yml`. Логи и аналитика (Logflare/Vector/Log Explorer) по умолчанию выключены — отдельный оверрайд-файл, увеличивает требования к ресурсам.

**Без изменений:** лицензия — Apache 2.0 (файл `LICENSE`, копирайт 2024, не сдвинулся с 10-16). **Не закрыто:** тарифы и цены (`supabase.com/pricing` недостижим из автономного прогона, запасного первоисточника с цифрами в репозитории нет — тот же паттерн, что у [[pinecone]]/[[claude-agent-sdk]] ранее); версия/дата крупного релиза в README по-прежнему не указана.
