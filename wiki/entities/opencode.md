# OpenCode

**Тип:** инструмент (open-source CLI-агент для кодинга)
**Актуально на:** 2026-10-31

## Что это
Open-source (MIT, SST) агент для кодинга, альтернатива [[claude-code]]. Ключевое отличие — мультипровайдерность (~75–100 провайдеров моделей по разным источникам, включая локальные Ollama/LM Studio/Hugging Face, тогда как Claude Code работает только с моделями Claude) и три интерфейса запуска (терминал, десктоп, веб на localhost).

Поддерживает ту же структуру Skills/MCP и файл-инструкцию `AGENTS.md` (аналог `CLAUDE.md`), встроенные режимы Plan/Build. Конфиг проекта — `opencode.json`, рекомендуется явно включить `ask` на редактирование файлов и bash-команды.

## Оплата: подписка Anthropic не работает (уточнено 2026-07-29)
Ранее здесь и в [[zproger-opencode-review]] OpenCode описывался как «бесплатная альтернатива Claude Code» — формулировка требует поправки.

В **феврале 2026** Anthropic обновила Terms of Service и явно запретила использование subscription-OAuth-токенов (Pro/Max/Team) в сторонних инструментах, включая Agent SDK. В тот же день OpenCode удалил из кодовой базы весь Claude-OAuth код; к марту исчезли встроенный auth-плагин и подсказки провайдера в UI логина. Итог: **модели Claude в OpenCode доступны только по API-ключу, с оплатой по токенам** — подписка не переносится.

Сторонние плагины, возвращающие OAuth-логин через подписку, существуют, но делают ровно то, что запрещено ToS — риск блокировки аккаунта.

Бесплатен, таким образом, сам инструмент, а не работа модели; по-настоящему бесплатным сценарий становится только на локальных моделях.

**Уточнение 2026-10-31:** с провайдером `claude-agent` (см. «Допроверка 2026-10-31» ниже) подписка Anthropic в OpenCode снова доступна — но не как возврат старой схемы, а другим путём. Вывод этого раздела не отменяется, только перестаёт быть полным без этой оговорки.

## Допроверка 2026-09-09 (ежедневный процесс закрытия пробелов)

Первая содержательная сверка с момента ingest (07-29 → сейчас, 42 дня) — не переустановка даты. Официальный `opencode.ai` заблокирован сетевым прокси окружения (`EGRESS_BLOCKED`), но репозиторий `github.com/sst/opencode` — первоисточник сам по себе, документация лежит внутри него (`packages/web/src/content/docs/*.mdx`), прочитана напрямую через `raw.githubusercontent.com`.

Все прежние факты подтвердились без расхождений: мультипровайдерность (официально «75+ LLM providers через AI SDK и Models.dev», согласуется с диапазоном «~75–100» вики), три интерфейса (CLI, десктоп — уточнение: официально помечен **BETA** для macOS/Windows/Linux, веб), режимы **build**/**plan** (у plan — read-only по умолчанию, запрашивает разрешение на bash), `opencode.json`/`opencode.jsonc` как конфиг (плюс отдельный `tui.json` для темы/keybinds, раньше не знали), запрет Anthropic на использование Pro/Max-подписки в сторонних инструментах.

**Уточнение, которого не было на странице.** Официальная документация называет точную версию, с которой встроенные OAuth-плагины подписки Claude исчезли — **1.3.0** («Previous versions of OpenCode came bundled with these plugins but that is no longer the case as of 1.3.0») — раньше вики знала только «в тот же день [февраль 2026]», без номера версии. Тем же абзацем документация проводит контраст, которого страница не отражала: запрет — решение именно Anthropic, не принцип OpenCode — конкурирующие провайдеры (ChatGPT Plus, GitHub Copilot, GitLab Duo) подключаются подпиской «с нулевой настройкой» прямо из коробки.

**Ещё одна деталь, которой не было:** `AGENTS.md` — не просто «аналог» `CLAUDE.md`, как знала страница, а официально задокументированный fallback: при отсутствии `AGENTS.md` харнес ищет `CLAUDE.md` напрямую ради совместимости при миграции с Claude Code (`rules.mdx`, порядок обхода директорий вверх + глобальный `~/.config/opencode/AGENTS.md`).

Не проверено отдельно: число звёзд репозитория (обзор GitHub-страницы дал 206k, но это не было целью сверки и не зафиксировано как факт версии); точная дата релиза 1.3.0 документацией не названа.

## Допроверка 2026-10-31 (ежедневный процесс закрытия пробелов)

Вторая содержательная сверка с момента ingest (09-09 → сейчас, 52 дня), fallback-приоритет №2 порядка хвостов (допроверка флагнутой страницы по первоисточнику, кулдаун 3 дня не нарушен). Официальный `opencode.ai` снова `EGRESS_BLOCKED`; первоисточником взят сам репозиторий — `github.com/sst/opencode`, прямой `git clone` (без прокси, сработал), плюс страница релизов GitHub через `WebFetch`.

**Версия выросла далеко за пределы простой переустановки даты.** На 09-09 вики знала только версию 1.3.0 (снятие встроенных OAuth-плагинов подписки). Сейчас весь монорепозиторий (`package.json` во всех пакетах `packages/*`, проверено прямым `grep`) — **2.2.5**. Рядом в выдаче релизов GitHub отдельно висит тег `v1.19.5`, помеченный «Latest», с комментарием, что `dev`-ветка впереди на 5 906 коммитов — страница релизов не объясняет связь двух линий версий (отдельный пакет под старым именем, легаси-ветка или что-то третье), первоисточник на этот вопрос не отвечает, не придумываем объяснение.

**Главная находка — новый провайдер `claude-agent` (добавлен в v2.2.3, 30.10.2026), который возвращает подписку.** Официальная документация в репозитории (`specs/v2/claude-agent-provider.md`, `services/www/src/docs/content/claude-agent.mdx`) описывает принципиально другую схему, не возврат снятых в начале 2026 OAuth-плагинов: OpenCode запускает **установленный у пользователя бинарник `claude`** (путь — `PATH` или `OPENCODE_CLAUDE_PATH`) через публичный Claude Agent SDK и никогда не читает и не трогает сохранённый логин Claude Code — пользователь логинится сам, обычным `claude auth login`, любым способом (подписка, API-ключ, cloud-аккаунт). Дословно из спеки: *«It only uses the public SDK. It never sits between Claude Code and Anthropic or changes Claude Code's requests»*. OpenCode при этом подменяет Claude Code все инструменты на свои (встроенные тулы Claude выключены), ведёт свою историю сессии, добавляет собственный системный промпт поверх промпта Claude Code — то есть Claude Code используется как исполнитель вызовов модели, а не как агент целиком.

Стоимость показывается по тому, как залогинен сам `claude`: подписка — **$0** («your plan covers it», дословно из `claude-agent.mdx`), API-ключ/Cloud — цена Anthropic/Bedrock/Vertex/Foundry по `models.dev`, свой `baseURL` — тоже $0 (шлюз считает сам). Названные ограничения первоисточником: Claude Code должен стоять на той же машине, что сервер OpenCode (в облачных воркспейсах провайдер недоступен), не поддерживаются `temperature`/`top-p`/`top-k`/`seed`/стоп-последовательности, нужен Claude Code **2.1.248+**.

Этот путь не противоречит запрету Anthropic из ToS февраля 2026 (раздел «Оплата» выше) в том виде, как он был зафиксирован на 09-09: тогда запрет читался как «подписочный OAuth-токен нельзя использовать внутри стороннего инструмента» — здесь токен никуда не передаётся, работает ровно официальный `claude` под своим обычным логином, OpenCode — только интерфейс и инструменты вокруг него. Независимая юридическая оценка такого разграничения у Anthropic не проверялась (первоисточника на этот частный случай нет) — помечено как находка, а не как решённый вопрос.

Остальные факты страницы (мультипровайдерность, три интерфейса, режимы Plan/Build, `AGENTS.md` как fallback на `CLAUDE.md`) подтверждений/расхождений в прочитанных релизах 2.2.0–2.2.5 не нашли — тема попросту не поднималась, не формальная переустановка.
