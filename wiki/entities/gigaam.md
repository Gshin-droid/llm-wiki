# GigaAM

Семейство открытых акустических моделей Sber для распознавания русской речи (плюс multilingual-линейка на 70+ языков). ASR-движок, стоящий в проекте пользователя [[dictum-golosovaya-diktovka]] (через `onnx-asr`); закрывающая наводку инбокса страница — [[gigaam-whisperx-repo-review]].

**Тип:** инструмент (семейство моделей + Python-пакет)
**Автор:** salute-developers / GigaChat Team (Sber)
**Лицензия:** MIT
**Репозиторий:** https://github.com/salute-developers/GigaAM
**Актуально на:** 2026-10-27

## Семейство

Conformer-based модель (220M–600M параметров), четыре линейки: `v1`/`v2`/`v3` — только русский (CTC/RNNT-декодеры поверх HuBERT–CTC предобучения), `multilingual` — 70+ языков (включая казахский, киргизский, узбекский). `v3_e2e_ctc`/`v3_e2e_rnnt` — end-to-end, с пунктуацией и нормализацией текста «из коробки».

## WER на русском (официальная таблица, `evaluation.md`)

Средний WER по 10 валидационным наборам: **v3 CTC — 9.1%**, **v3 RNNT — 8.3%**, против эталона Whisper (large, с постобработкой) — **21.0%** — на каждом отдельном наборе без исключения GigaAM ниже. SBS-сравнение `e2e`-моделей против Whisper через LLM-as-a-Judge — победа 70:30.

## Диаризация — нет

Разделения по говорящим GigaAM **не делает** — ни по README, ни по коду (прямая проверка `grep` по дереву репозитория, допроверка 2026-10-27). Единственное использование `pyannote.audio` внутри GigaAM — модель `pyannote/segmentation-3.0` для **VAD** (детекция речи/паузы) в режиме `transcribe_longform`, не для разметки говорящих. Для расшифровки с разделением по голосам нужна отдельная модель диаризации (например, та, что использует [[whisperx]]) поверх транскрипции GigaAM.

## В проекте пользователя

[[dictum-golosovaya-diktovka]] использует GigaAM напрямую через `onnx-asr` (не через этот репозиторий), с собственным замером: русская модель против многоязычной — 5,93% против 7,11% ошибок на словах. Официальная таблица WER выше — независимое подтверждение того же направления (русская версия GigaAM точнее multilingual-линейки) другим, собственным замером автора модели.
