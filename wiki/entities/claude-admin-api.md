# Claude Admin API

Программный доступ к администрированию организации Claude Console: пользователи, воркспейсы, API-ключи, сервис-аккаунты, лимиты — без похода в веб-консоль руками.

**Тип:** функция платформы (Claude Console / Claude Developer Platform, часть Claude API)
**Актуально на:** 2026-09-21

## Что это

`client.beta.organization.*` в официальном Python SDK (`anthropic>=1.1.0`) — эндпоинты уровня организации, отдельные от обычных вызовов Messages API. Доступны только с ролью admin в организации Claude Console; для индивидуальных аккаунтов недоступны. Аутентификация — либо OAuth-профиль со scope `org:admin` (`ant auth login --profile admin --scope org:admin`, рекомендован для сервис-аккаунтов), либо отдельный Admin API key.

## Возможности

- **Пользователи** — приглашения по email (`invites.create`, срок жизни 21 день, в части организаций ограничены доменом), список (`users.list`), смена роли — developer/user/billing (`users.update`), офбординг (`users.remove`).
- **Воркспейсы** — создание с метаданными-тегами (`workspaces.create`), правка названия/цвета/тегов (`workspaces.update`), явные участники (`workspaces.members.add`/`.list`).
- **Аудит API-ключей** — `api_keys.list` (возраст, срок действия, воркспейс, признаки использования), `api_keys.update` — деактивация (обратима, запросы падают немедленно) или архивация (**необратима**).
- **Сервис-аккаунты** — `service_accounts.create` + `service_accounts.workspaces.add`; принимают только OAuth-креды, Admin API key здесь отклоняется. У новых объектов возможна задержка согласованности (кратковременный 404 сразу после создания) — официальный notebook оборачивает такие вызовы в retry.
- **Лимиты** — `rate_limits.list` отдельно на уровне организации и на уровне воркспейса.

## Ограничения, названные первоисточником

- Роль admin выдаётся только через веб-консоль — через API не назначается.
- Сами API-ключи тоже создаются только через консоль, не программно.
- Архивация воркспейса необратима и разом отзывает все ключи в нём.

## Почему это не топ-находка этой вики

Весь механизм рассчитан на организацию с несколькими участниками — приглашения, роли, воркспейсы под команду. У пользователя этой вики Claude Console используется соло, без второго участника или отдельных воркспейсов. Материал зафиксирован как часть ландшафта платформы: закрывает пробел (факт «Admin API user-management вышла из беты» лежал на [[claude-code-changelog-snapshot-2026-08-22]] с 08-19 без единого практического примера), но без применения к текущим проектам пользователя — поэтому без ⭐.
