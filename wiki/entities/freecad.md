# FreeCAD

Открытый (LGPL) параметрический CAD-редактор, используется как площадка для практического кейса «Claude как CAD-инженер» через MCP.

**Тип:** инструмент (открытое ПО)
**Актуально на:** 2026-08-24

## Что это
`freecad.org` — desktop-приложение для параметрического 3D-моделирования (детали, чертежи, инженерные расчёты), популярно у мейкеров и в 3D-печати.

## FreeCAD MCP (`neka-nat/freecad-mcp`)
Сторонний (не от Anthropic и не от разработчиков FreeCAD) MCP-сервер на GitHub, устанавливается как add-on внутрь FreeCAD и связывает его с [[claude-code|Claude Desktop]] через `UVX`. Разобран практически по [[makeform-freecad-mcp-tutorial]] — полный пошаговый сетап и работающий цикл «промпт → код Python API FreeCAD → скриншот вьюпорта обратно модели» подтверждены, не только заявлены автором.
