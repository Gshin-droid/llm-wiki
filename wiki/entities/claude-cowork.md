# Claude Cowork

**Тип:** функция продукта (Claude Desktop, с 2026-08 также web/mobile)
**Актуально на:** 2026-08-15

## Что это
Режим Claude Desktop, в котором модель получает доступ к реальным папкам/файлам на компьютере пользователя (не просто к тексту в чате) и может действовать как "сотрудник за компьютером": сортировать файлы, использовать Computer Use (взаимодействие с интерфейсами без готовой интеграции), запускать задачи по расписанию (scheduled/облачные рутины), принимать задачи с телефона (Dispatch).

Соответствует 3-5 уровням в [[five-levels-of-claude-mastery]]:
- Уровень 3: доступ к файловой системе, Computer Use, Skills, управление с телефона
- Уровень 5 (Архитектор): облачные рутины независимо от включённого компьютера, хуки (правила до/после действия агента), команды агентов, task budgets

## Пример из источников
Разбор 2300+ файлов в папке загрузок по типам за несколько минут (см. [[qaisar-claude-full-course]]); еженедельная автоматическая уборка по расписанию.

## Механика автоматизации (детальнее)
Сжатое описание запуска задач по расписанию в этой странице (пункт "запускать задачи по расписанию") дополнено подробным разбором в [[claude-desktop-automation-modes]]: четыре конкретных режима (Cowork Scheduler, Local Routines, Cloud Routines, `/loop`), лимиты по тарифу, catch-up-поведение, типы триггеров облачных рутин.

## Допроверка 2026-08-15: Cowork больше не только Desktop

Ежедневный процесс закрытия пробелов. Прямой фетч `claude.com`/`support.claude.com` заблокирован сетевым прокси окружения, но официальные **release notes Claude Platform** (`platform.claude.com/docs/en/release-notes/overview`, прочитаны напрямую) дают первоисточное подтверждение независимо от самой документации Cowork: запись **3 августа 2026** — Compliance API для Claude Enterprise различает два новых типа сессий по эндпоинтам, `/v1/compliance/apps/sessions/local` (сессии на машине пользователя) и `/v1/compliance/apps/sessions/remote` — прямая цитата: «Cowork sessions started on claude.ai web or mobile». То есть на эту дату Cowork-сессию можно начать не только в приложении Claude Desktop, но и в браузере на claude.ai и с мобильного приложения — тип продукта в шапке страницы был не полным.

Детали конкретных тарифов/сроков раскатки веб- и мобильной версии (SEO-пересказы называют конец беты для Max-подписчиков с 07.07.2026, дальше — остальные тарифы) первоисточником не подтверждены — `support.claude.com`, где должна быть сама статья про Cowork на web/desktop/mobile, недоступен при этом прогоне; в вики как факт не вносятся, только сам факт существования веб/мобайл-сессий, подтверждённый датированной записью в release notes.
