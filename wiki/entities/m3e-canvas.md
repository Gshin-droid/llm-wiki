# M3E Canvas

Браузерный редактор макетов на компонентах [[material-3-expressive]], выдающий на выходе **промпт для агента-кодера**, а не код. Попал в вики как рабочий пример приёма «референс вместо ТЗ прозой» — см. [[maket-kak-tz-dlya-agenta]].

**Тип:** инструмент (редактор макетов / генератор заданий)
**Актуально на:** 2026-09-22
**Репозиторий:** `github.com/lnkiai/m3e-canvas` · демо `lnkiai.github.io/m3e-canvas/` · **Лицензия:** MIT
**Автор:** `lnkiai` · стек Next.js 16 + React 19, 8 тыс.+ звёзд

## Что делает

Компоненты перетаскиванием, несколько экранов сразу, переходы по нажатию и смахиванию с анимацией — поток можно прокликать. Два холста: телефон 412×892 и десктоп 1280×800. Тема настраивается по канону M3 Expressive: цвет, форма, типографика, движение.

**Экспорт — текстовое описание** раскладки, размещения компонентов и поведения, вместе с заметками к дизайну. Целевая платформа на выбор: Android (по умолчанию) или Web. Язык промпта: японский, английский, китайский, корейский — **русского нет**.

## Две оговорки, которых нет в описании

- **Бэкенда нет, всё лежит в `localStorage`.** Работа живёт в одном браузере на одной машине и исчезает при чистке данных сайта. Макет, который жалко потерять, надо экспортировать.
- **Словарь компонентов тянет за собой Jetpack Compose.** Описание раскладки само по себе переносимо в любой стек, но имена компонентов взяты из M3 Expressive, полностью реализованного пока только там. В другом фреймворке часть придётся заменять аналогами — и промпт об этом не предупредит.
