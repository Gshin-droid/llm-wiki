# SoL-Pi

Открытое расширение к харнесу [[pi-coding-agent]] от NVlabs, сокращающее расход токенов агента на 44,7–49,0% без потери качества. Попало в вики как первый случай, когда механизмы обвязки не спроектированы человеком, а **найдены автоматическим перебором**, и первый, где экономия на обвязке измерена в долларах в час.

**Тип:** инструмент (расширение агентного харнеса)
**Актуально на:** 2026-10-29
**Репозиторий:** `github.com/NVlabs/SoL-Pi` · **Статья:** arXiv 2609.20519 (17.09.2026)
**Лицензия:** MIT

## Чем это не является

**Не мод к Claude Code и не к Codex.** Ставится только поверх Pi 0.85.1 (`pi install git:github.com/NVlabs/SoL-Pi`, Node.js 22.19+). Codex и Claude Code в замерах — база сравнения, а не объект улучшения. Оба поста-наводки, из которых материал пришёл, этого не сказали, и прочитываются наоборот — разбор в [[nvidia-sol-pi-harness]].

## Четыре механизма

- **Action Fusion** — правка файла запускает проверочную команду тем же вызовом инструмента.
- **ObservationPack** — большие повторяющиеся результаты заменяются устойчивыми дескрипторами с постраничным обращением.
- **Evidence-Preserving Reducer** — логи сжимаются в «квитанции», но каждая сохранённая цитата сверяется с архивом дословно.
- **Online Context Compact** — завершённые шаги плана отдаются штатному сжатию Pi, не дожидаясь переполнения окна.

Все четыре **выключены по умолчанию**, включаются файлом `sol-pi.json` в `.pi/` проекта или `~/.pi/agent/`. Осторожная конфигурация из README включает только первые два.

## Замер

EdgeBench, 51 задача, модели GPT-5.6 Sol и Opus 5. Качество — на уровне базовой обвязки; токенов −44,7…49,0%; расходы на API −33%; в час это $8,75–13,50 против штатных Codex и Claude Code и $4,36–5,71 против голого Pi.

## Ограничение, о котором нужно знать до включения

**Evidence-Preserving Reducer может отправлять логи на удалённую модель** — сказано самими авторами в разделе ограничений. Для проектов, где в логах есть чувствительное, механизм не включать.

## Допроверка 2026-10-29

Первая содержательная сверка с создания страницы (09-22 → сейчас, 37 дн.) — первоисточник `github.com/NVlabs/SoL-Pi` (README через `raw.githubusercontent.com`), не `arxiv.org` (тот по-прежнему вне доступа автономного прогона — отдельный пункт бэклога про три открытых вопроса статьи остаётся локальным, не трогался).

Рост, не формальная переустановка даты:

- **SoL-Pi Skill (2026-10-14)** — новый способ запуска: «use SoL-Pi as a skill from Claude Code (`/sol-pi`) or Codex (`$sol-pi`)». Задача передаётся SoL-Pi, выполняется в фоне, результат возвращается в сессию: «runs in the background, and its result is reported back to the session». Уточняет (не отменяет) раздел «Чем это не является» выше: SoL-Pi по-прежнему не мод, встроенный в сам харнес Claude Code/Codex, а отдельный процесс Pi, вызываемый из них как скилл/фоновая задача — Codex и Claude Code остаются вызывающей стороной, не объектом модификации.
- **SoL-Pi Visual (2026-10-13)** — пример для 3D-реконструкции сцен в Blender: «lowers the cost per scene by 37% compared with Codex, with 13% fewer model calls» — цифры автора, не вики, отдельная задача от основного замера EdgeBench.
- **Совместимость версий Pi уточнена и сузилась.** Минимальная поддерживаемая версия — «`@earendil-works/pi-coding-agent` 0.84.2 or newer», страница ранее знала только версию установки из README (0.85.1) как факт, не как минимум диапазона. Рекомендована и протестирована версия **1.3.0** (четыре релиза вперёд от известных вики версий Pi на дату ingest'а [[pi-coding-agent]], 09-28). Прямое предупреждение про более новые ветки Pi: «a fresh install of Pi 1.0.x or 1.1.0 now fails to start» — эти релизы не фиксируют свои внутренние пакеты.
- Звёзды репозитория на странице не публикуются числом — только график Star History без значения, в вики как факт не вносится.

Детали EdgeBench/четырёх механизмов/ограничения про Evidence-Preserving Reducer не изменились — подтверждены повторно без расхождений.
