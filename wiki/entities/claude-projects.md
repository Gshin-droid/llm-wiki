# Claude Projects

**Тип:** функция продукта (Claude.ai)
**Актуально на:** 2026-10-21

## Что это
Рабочие пространства внутри Claude.ai с постоянной памятью, отдельными инструкциями и загруженными файлами-контекстом — не смешиваются с обычными чатами. По сути "мини-сотрудник": задал роль и контекст один раз ("YouTube-сценарист", "генератор коммерческих предложений") — дальше не нужно объяснять заново в каждом новом чате внутри проекта.

Это второй уровень в [[five-levels-of-claude-mastery|модели 5 уровней владения Claude]] — переход от "поисковика без памяти" к инструменту с непрерывным контекстом.

## Допроверка 2026-10-21 (ежедневный процесс закрытия пробелов)

Первая содержательная сверка с ingest (07-07 → сейчас, 106 дней) — страница ни разу не проверялась по первоисточнику с создания, только пересказом двух видео. `support.claude.com/en/articles/9519177-projects` прочитан напрямую (домен из класса часто блокируемых, в этот заход открылся без затруднений, тот же нестабильный паттерн, что уже фиксировался у [[claude-cowork]] 10-17).

Находки, которых на странице не было вовсе — не формальное обновление даты:
- **Доступны всем, включая бесплатный тариф** — до 5 проектов на Free; страница знала Projects только как платную функцию.
- **У каждого проекта своя память**, отдельная от памяти вне проектов и от памяти других проектов; полная изоляция — через отключение «Use account memory» на странице проекта. Память по умолчанию включена на Free/Pro/Max, на Team/Enterprise — только если включил владелец организации.
- **Автоматический RAG-режим на платных тарифах**: при приближении базы знаний проекта к лимиту контекстного окна Claude сам переключается на поиск по знаниям вместо загрузки всего в контекст — механизм, который страница не описывала.
- **Контекст не переносится между чатами проекта**, если явно не добавлен в базу знаний проекта (дословно подтверждает первоисточник) — уточняет собственную формулировку страницы «не нужно объяснять заново», которая на деле верна только для того, что лежит в базе знаний, а не для истории предыдущих чатов.
- Claude не видит название и описание проекта; совместный доступ («Can view»/«Can edit») — только Team/Enterprise, с возможностью отключения администратором; архивные проекты нельзя удалить, не разархивировав.

Расхождений с прежним текстом страницы нет — новые разделы, а не исправление старых.
