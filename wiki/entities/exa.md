# Exa

**Тип:** компания / поисковой API + MCP-сервер, спроектированный под ИИ-агентов
**Статус:** не используется в этой вике (оценена по запросу из бэклога, не установлена)
**Актуально на:** 2026-08-05 (найден пропущенный тип поиска `instant`; тарифы остаются со снапшота 2026-07-28, не подтверждены первоисточником)

## Что это

Компания, основанная в 2021 году Уиллом Брайком (Will Bryk) и Джеффом Вангом (Jeff Wang, познакомились как соседи по комнате в Гарварде). Позиционируется как «neural search engine для ИИ-приложений» — поиск на эмбеддингах/семантике вместо классического keyword-матчинга поисковых движков. Хорошо профинансирована: Series C на $250M при оценке $2.2B (лидер раунда — a16z; среди инвесторов Sequoia, Benchmark, NVIDIA, Y Combinator) — не стартап-однодневка, инфраструктура компании масштаба.

Источники компании/фандинга и общей позиции продукта прочитаны не с первоисточника напрямую (`exa.ai` и `docs.exa.ai` отдают 403 на прямой фетч — похоже на защиту от ботов уровня Cloudflare, тот же паттерн, что уже фиксировался в вики для `support.claude.com`), а восстановлены по совпадению нескольких независимых вторичных источников (Bloomberg, Crunchbase, официальный блог Exa в пересказе поисковика). Единственный кусок, прочитанный напрямую с официального источника — README репозитория `exa-labs/exa-mcp-server` на GitHub (см. ниже), это и есть первоисточник для технической части MCP.

## MCP-сервер — официальный, подтверждено

`exa-labs/exa-mcp-server` — официальный репозиторий компании (не стороннее комьюнити-решение). Два способа подключения:

- **Remote HTTP** (рекомендуемый) — хостится Exa на `https://mcp.exa.ai/mcp`, подключается без локальной установки. Для Claude Desktop есть нативный Connector (Settings → Connectors), без конфигов и терминала.
- **Локальный npm-пакет** — для кастомных деплоев/офлайна, тоже требует API-ключ.

В обоих случаях нужен API-ключ Exa (`dashboard.exa.ai/api-keys`); опционально remote-эндпоинт поддерживает OAuth-логин для расшаренных сетапов.

Тулы:
- `web_search_exa` — обычный веб-поиск с уже очищенным контентом (включён по умолчанию)
- `web_fetch_exa` — забор полного содержимого известного URL (включён по умолчанию)
- `web_search_advanced_exa` — фильтры по доменам/датам/типам контента (опционально)
- `agent_tools` — многошаговый ресёрч и структурированный вывод через «Exa Agent» (опционально)

## Тарифы

| Позиция | Цена |
|---|---|
| Поиск с контентом (10 результатов, текст + highlights) | $7 за 1 000 запросов |
| Доп. результаты сверх 10 | $1 за 1 000 |
| Summaries (на поиске и на contents) | $1 за 1 000 |
| Exa Deep (research) | $12 за 1 000 |
| Exa Deep Reasoning | $15 за 1 000 |
| Бесплатный тариф | 1 000 запросов/месяц |

Цифры взяты из синопсиса поисковика по официальной странице `exa.ai/pricing` — сама страница не открылась напрямую (403), при появлении способа прочитать её напрямую стоит перепроверить точные условия (в частности, что именно считается «запросом» для составных вызовов вроде search+contents).

**Чем отличается от обычного поиска.** Заявленное УТП — «neural search»: индекс и ранжирование на эмбеддингах, фильтрация по смыслу запроса, а не по совпадению ключевых слов.

**Допроверено 2026-08-02** (ежедневный процесс закрытия пробелов, допроверка флагнутой страницы). Прямой фетч `docs.exa.ai/reference/search` и `docs.exa.ai/llms-full.txt` по-прежнему 403 — как и `exa.ai/pricing`. Но по тому же приёму, что закрыл GEO-пробел 08-01 (независимо повторяющаяся точная цитата официальной страницы в поисковой выдаче, сама страница `docs.exa.ai/reference/search` фигурирует источником) уточнена механика: параметр типа поиска — не тройка `neural`/`keyword`/`auto`, а как минимум шесть значений: `neural` (dense embeddings, полный семантический интент запроса), `auto` (дефолт — Exa сам комбинирует neural и другие методы), `keyword`, `fast` (облегчённые версии моделей поиска), `deep` (query expansion + расширенный контекст), и пропущенный на тот момент `instant` (sub-200ms, см. допроверку 08-05 ниже — существовал уже на 08-02, но не был найден). Побочный нюанс: relevance-score в ответе доступен только у `neural`; у `auto`/`keyword` score из ответа убран («deprecated due to architectural improvements» — собственная формулировка Exa). Раньше документированных вариантов `fast`/`deep`/`instant` на странице не было — это не противоречие старому факту, а его устаревание (более ранний снапшот документации знал только базовую тройку).

Тарифы (таблица выше) при этом же прогоне допроверкой не подтверждены: единственные найденные источники по числам — SEO-агрегаторы (`shipsquad.ai`, `hokai.io`, `toolchase.com`, `fastcrw.com`, `aisotools.com`, `aipedia.wiki`), которые CLAUDE.md прямо предписывает отбрасывать (тот же случай, что с тарифами Abacus, закрыт 2026-07-30 как «не подтверждено»). Косвенно они не противоречат текущей таблице (называют те же порядки цифр — $7/$12/$15 за 1000, отдельно упоминают tier «Agentic» $12/1000 и бандлинг контента первых 10 результатов с марта 2026), но как источник для правки таблицы не использованы. Официальная страница `exa.ai/pricing` остаётся непрочитанной напрямую — если появится способ её открыть, таблицу стоит свести с ней построчно.

**Допроверено 2026-08-05** (ежедневный процесс закрытия пробелов, вторая допроверка той же страницы после кулдауна 3 дня с 08-02). Прямой фетч `exa.ai`/`docs.exa.ai` (включая конкретные changelog-страницы) по-прежнему 403 на уровне шлюза — без изменений. Но найдена не новая перемена, а **пропуск в прошлой допроверке**: у параметра типа поиска есть шестое значение, `instant` (sub-200ms), которое уже существовало на момент проверки 08-02, но не попало на страницу. Хорошо подтверждено независимыми источниками: официальный блог Exa (`exa.ai/blog/exa-instant`, заголовок «Introducing Exa Instant: the fastest search engine in the world»), официальный аккаунт компании в X (`x.com/ExaAILabs`, тот же анонс дословно) и независимая техническая журналистика — MarkTechPost и UBOS.tech, оба независимо друг от друга описывают точную дату запуска **13 февраля 2026** и диапазон латентности 100–200мс, «faster than Google», архитектура — end-to-end нейросетевой стек без классического «обёрточного» подхода. Три независимых источника (компания + два независимых техно-издания) сходятся на одной и той же дате и цифрах — это сильнее, чем «повторяющаяся цитата одной и той же страницы в выдаче», применявшаяся раньше для 403-страниц.

Также при поиске всплыли смежные заявления (что `neural` — «легаси»-терминология, дополнительные значения `deep-lite`/`deep-reasoning`/`deep-max`, отдельный tariff «Answer endpoint» $5/1000, другая структура бесплатного тарифа — $20 при регистрации + $10/мес вместо 1000 запросов/мес) — **не добавлены на страницу**: единственный источник на каждое из этих заявлений — одиночные SEO/агрегаторские блоги (morphllm.com, tickerr.ai, fastcrw.com и т.п.) без независимого подтверждения официальным каналом, ровно тот случай, который CLAUDE.md предписывает отбрасывать. Если это реальные изменения, следующая допроверка (не раньше 2026-08-08, кулдаун 3 дня) может застать их уже подтверждёнными вторым независимым каналом.

## Оценка для этой вики

Задача из бэклога — понять, есть ли смысл заменить/дополнить обычный `WebSearch`, которым вики пользуется в Ingest/Query/еженедельном разведчике и ежедневном закрытии пробелов.

Аргументы за: официальный MCP, инфраструктура серьёзного масштаба, семантический поиск теоретически может находить более релевантные первоисточники по смысловым (не только ключевым) запросам — ровно то, чем занимается ежедневный процесс закрытия пробелов. Бесплатного тарифа (1 000 запросов/мес) с большим запасом хватает на объём этой вики (несколько поисковых запросов в день).

Аргументы против/открытые вопросы: платный сервис с отдельным API-ключом, который надо завести и хранить — новая точка настройки и новая поверхность (правило 12 в [[claude-code-practices]] про проверку пакетов/MCP перед установкой применимо и сюда). Прямого A/B-сравнения качества результатов Exa vs встроенный `WebSearch` не найдено — заявление о превосходстве в цитируемости пока не подтверждено, только маркетинг компании. Технические детали (что именно значит «нейронный» режим на уровне ранжирования) не проверены по первоисточнику из-за 403.

**Вывод:** установка не выполнена — заведение нового MCP-сервера с отдельным платным API-ключом выходит за рамки того, что можно решить автономно в рамках ежедневного процесса закрытия пробелов (это выбор пользователя, не факт для верификации). Факты по запросу бэклога проверены и задокументированы здесь; если пользователь решит попробовать — путь подключения понятен (remote `https://mcp.exa.ai/mcp` + ключ с `dashboard.exa.ai`, либо нативный Claude Desktop Connector).
