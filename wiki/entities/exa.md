# Exa

**Тип:** компания / поисковой API + MCP-сервер, спроектированный под ИИ-агентов
**Статус:** не используется в этой вике (оценена по запросу из бэклога, не установлена)
**Актуально на:** 2026-07-28

## Что это

Компания, основанная в 2021 году Уиллом Брайком (Will Bryk) и Джеффом Вангом (Jeff Wang, познакомились как соседи по комнате в Гарварде). Позиционируется как «neural search engine для ИИ-приложений» — поиск на эмбеддингах/семантике вместо классического keyword-матчинга поисковых движков. Хорошо профинансирована: Series C на $250M при оценке $2.2B (лидер раунда — a16z; среди инвесторов Sequoia, Benchmark, NVIDIA, Y Combinator) — не стартап-однодневка, инфраструктура компании масштаба.

Источники компании/фандинга и общей позиции продукта прочитаны не с первоисточника напрямую (`exa.ai` и `docs.exa.ai` отдают 403 на прямой фетч — похоже на защиту от ботов уровня Cloudflare, тот же паттерн, что уже фиксировался в вики для `support.claude.com`), а восстановлены по совпадению нескольких независимых вторичных источников (Bloomberg, Crunchbase, официальный блог Exa в пересказе поисковика). Единственный кусок, прочитанный напрямую с официального источника — README репозитория `exa-labs/exa-mcp-server` на GitHub (см. ниже), это и есть первоисточник для технической части MCP.

## MCP-сервер — официальный, подтверждено

`exa-labs/exa-mcp-server` — официальный репозиторий компании (не стороннее комьюнити-решение). Два способа подключения:

- **Remote HTTP** (рекомендуемый) — хостится Exa на `https://mcp.exa.ai/mcp`, подключается без локальной установки. Для Claude Desktop есть нативный Connector (Settings → Connectors), без конфигов и терминала.
- **Локальный npm-пакет** — для кастомных деплоев/офлайна, тоже требует API-ключ.

В обоих случаях нужен API-ключ Exa (`dashboard.exa.ai/api-keys`); опционально remote-эндпоинт поддерживает OAuth-логин для расшаренных сетапов.

Тулы:
- `web_search_exa` — обычный веб-поиск с уже очищенным контентом (включён по умолчанию)
- `web_fetch_exa` — забор полного содержимого известного URL (включён по умолчанию)
- `web_search_advanced_exa` — фильтры по доменам/датам/типам контента (опционально)
- `agent_tools` — многошаговый ресёрч и структурированный вывод через «Exa Agent» (опционально)

| Exa Deep Reasoning | $15 за 1 000 |
| Бесплатный тариф | 1 000 запросов/месяц |

Цифры взяты из синопсиса поисковика по официальной странице `exa.ai/pricing` — сама страница не открылась напрямую (403), при появлении способа прочитать её напрямую стоит перепроверить точные условия (в частности, что именно считается «запросом» для составных вызовов вроде search+contents).

**Чем отличается от обычного поиска.** Заявленное УТП — «neural search»: индекс и ранжирование на эмбеддингах, фильтрация по смыслу запроса, а не по совпадению ключевых слов; в API это параметр типа поиска (`neural`/`keyword`/`auto`). Точное описание механики не подтверждено напрямую по `docs.exa.ai/reference/search` (403 на фетч) — известно только из вторичного пересказа, требует допроверки, если понадобятся технические детали реализации.

## Оценка для этой вики

Задача из бэклога — понять, есть ли смысл заменить/дополнить обычный `WebSearch`, которым вики пользуется в Ingest/Query/еженедельном разведчике и ежедневном закрытии пробелов.

Аргументы за: официальный MCP, инфраструктура серьёзного масштаба, семантический поиск теоретически может находить более релевантные первоисточники по смысловым (не только ключевым) запросам — ровно то, чем занимается ежедневный процесс закрытия пробелов. Бесплатного тарифа (1 000 запросов/мес) с большим запасом хватает на объём этой вики (несколько поисковых запросов в день).

Аргументы против/открытые вопросы: платный сервис с отдельным API-ключом, который надо завести и хранить — новая точка настройки и новая поверхность (правило 12 в [[claude-code-practices]] про проверку пакетов/MCP перед установкой применимо и сюда). Прямого A/B-сравнения качества результатов Exa vs встроенный `WebSearch` не найдено — заявление о превосходстве в цитируемости пока не подтверждено, только маркетинг компании. Технические детали (что именно значит «нейронный» режим на уровне ранжирования) не проверены по первоисточнику из-за 403.

**Вывод:** установка не выполнена — заведение нового MCP-сервера с отдельным платным API-ключом выходит за рамки того, что можно решить автономно в рамках ежедневного процесса закрытия пробелов (это выбор пользователя, не факт для верификации). Факты по запросу бэклога проверены и задокументированы здесь; если пользователь решит попробовать — путь подключения понятен (remote `https://mcp.exa.ai/mcp` + ключ с `dashboard.exa.ai`, либо нативный Claude Desktop Connector).
