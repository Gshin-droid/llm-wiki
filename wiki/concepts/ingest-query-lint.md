# Ingest / Query / Lint (три операции вики)

## Определение
Три базовые операции, которыми LLM управляет персональной вики в рамках [[persistent-wiki-pattern]].

## Ingest (загрузка)
Пользователь даёт новый источник → LLM читает его, обсуждает ключевые выводы, пишет саммари в `wiki/sources/`, обновляет/создаёт страницы сущностей и концептов, обновляет индекс. Один источник может затронуть 10–15 страниц.

## Query (запрос)
Пользователь задаёт вопрос → LLM читает индекс, находит релевантные страницы, синтезирует ответ с цитатами на `[[файлы]]`. Ценные ответы сохраняются как отдельные страницы в `wiki/synthesis/`, чтобы не исчезать в истории чата.

Оригинальный гист Карпати (см. [[karpathy-llm-wiki-gist]]) не ограничивает форму ответа markdown-страницей: сравнительная таблица, слайд-дек (Marp), график (matplotlib), интерактивный canvas — Query может материализоваться в любом из этих форматов, если это лучше отвечает на вопрос. В этой вики пока реализована только markdown-форма (`wiki/synthesis/`) — недоиспользованная по первоисточнику возможность, а не расхождение с ним.

## Lint (очистка)
Периодическая проверка здоровья вики: противоречия между страницами, устаревшие утверждения, страницы-сироты без входящих ссылок, важные концепты без своей страницы, битые перекрёстные ссылки, пробелы в данных.

В этой вики Lint разделился на два ритма (решение 2026-07-28, см. `CLAUDE.md` → «Ежедневное закрытие пробелов»): механический проход (битые ссылки, сироты) — раз в неделю, он редко находит что-то новое; содержательное закрытие пробелов — ежедневно, через `wiki/gaps-backlog.md` и приоритетный fallback (пункт бэклога → допроверка флагнутых страниц по первоисточнику с кулдауном 3 дня → углубление старой concept-страницы), а не формальный чек-лист каждый день.

## Источник
[[karpathy-jarvis-personal-ai-memory]], [[karpathy-llm-wiki-gist]] (первоисточник, гист апрель 2026)

## Применение в этой вики
Реализовано как раздел "Операции" в [[CLAUDE.md]] этого vault'а. С момента первого ingest (2026-07-07) набор вырос с трёх операций до пяти: Ingest, Query, **Project** (см. [[jarvis-personal-wiki]] — ведение рабочих ИИ-проектов пользователя как живых страниц, а не разовых саммари) и **Practice** (свод действующих правил в `wiki/practices/`, обновляемый при новом опыте, а не переписываемый молча) добавлены как отдельные операции рядом с исходными Ingest/Query/Lint.
