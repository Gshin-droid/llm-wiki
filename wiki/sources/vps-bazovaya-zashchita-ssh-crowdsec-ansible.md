## Саммари

Пересказ чата: завести пользователя с ключом, закрыть вход под root и по паролю (`PermitRootLogin no`, `PasswordAuthentication no`, `KbdInteractiveAuthentication no`, `PubkeyAuthentication yes`); поставить CrowdSec с общей базой адресов сканеров, fail2ban (может забанить владельца при плохой связи), VPN вместо открытого порта SSH, настраивать сервер через Ansible, копии держать вне сервера.

Наводка без первоисточника, поэтому по правилу вики каждый пункт сверен с документацией, а итог записан концептом [[bazovaya-zashchita-servera]]. Пользователь решил разбирать полностью: защита сервера понадобится под свои веб-проекты.

## Что взято в вики

Всё — в [[bazovaya-zashchita-servera]]. Сверка пунктов наводки с первоисточниками:

| Пункт наводки | Первоисточник | Итог |
|---|---|---|
| четыре параметра `sshd_config` | man `sshd_config(5)` | верно; добавлено: `KbdInteractiveAuthentication` по умолчанию `yes`, `PermitRootLogin` по умолчанию уже `prohibit-password` |
| «консоль провайдера перестанет помогать» | устройство `sshd` | **неточно**: SSH-настройки консоль не трогают; помогать перестанет, если у пользователя нет пароля |
| fail2ban банит владельца | `jail.conf` | верно: `ignoreip` по умолчанию закомментирован |
| CrowdSec с общей базой | docs.crowdsec.net | верно, но неполно: без исполнителя («баунсера») ничего не блокируется; база — в обмен на свои сигналы |
| Ansible повторяет настройку | документация `lineinfile` | верно; добавлено `validate: sshd -t -f %s` |
| VPN вместо порта | — | не проверено, в бэклог |

**Чего в наводке нет и что оказалось главным:** правило «первое значение побеждает» в `sshd_config` и файл cloud-init, который на Ubuntu 24.04 открывает вход по паролю поверх основного файла (Launchpad #2088207). Отсюда — проверять `sshd -T`, а не содержимое файла.

## Берём инструмент или логику

- **Инструмент:** настройки SSH — обязательно при первом сервере; fail2ban или CrowdSec — один, по выбору при установке (CrowdSec отправляет сигналы наружу — это решение, а не мелочь); Ansible — когда серверов больше одного или сервер пересоздаётся. Сейчас не ставится ничего: сервера нет.
- **Логика:** «написано ≠ действует» — после любой настройки проверять действующее значение (`sshd -T`, попытка входа по паролю с отказом), а не файл и не зелёный прогон сценария. Тот же принцип, что [[invariant-vidno-znachit-zapisano]].

## Что не взято / лиды

- VPN-туннель вместо открытого SSH — первоисточник не читан, пункт в [[gaps-backlog]].
- Смена порта как защита — не защита, только меньше шума; оговорено в концепте.
