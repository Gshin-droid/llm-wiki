## Саммари

Официальный notebook Claude Cookbooks, добавлен 2026-09-18 — то есть после прошлого прогона разведчика практики (09-14, [[mcp-for-beginners-curriculum]]). Показывает `client.beta.organization.*` — часть официального Python SDK (`anthropic>=1.1.0`), которой в вики не было ни одного практического примера, хотя сам факт выхода Admin API из беты уже отмечен на [[claude-code-changelog-snapshot-2026-08-22]] (запись от 08-19, только как строка в списке «разом вышло из беты», без разбора). Этот notebook — первый разбор того, что реально делает Admin API и как им пользоваться из кода: приглашения и роли пользователей, воркспейсы и их участники, аудит и деактивация API-ключей, провижининг сервис-аккаунтов, чтение лимитов организации/воркспейса.

Требует роль admin в организации Claude Console — недоступно для индивидуальных аккаунтов. Полный прогон notebook'а сам CI Anthropic не выполняет (нужен admin-креденшл), что явно названо в самом файле.

## Что взято в вики

- Новая сущность [[claude-admin-api]] — Admin API как отдельная часть платформы, до сих пор упомянутая только фактом («вышла из беты», 08-19), без единого практического примера.
- Разделы функциональности по коду notebook'а: пользователи (`invites.create`/`users.list`/`users.update`/`users.remove`), воркспейсы (`workspaces.create`/`.update`/`.members.add`/`.members.list`), аудит ключей (`api_keys.list`/`.update` — деактивация обратима, архивация нет), сервис-аккаунты (`service_accounts.create` + `.workspaces.add`, только через OAuth-креды, retry на eventual consistency), лимиты (`rate_limits.list` на организацию и на воркспейс).
- Два способа аутентификации (OAuth-профиль со scope `org:admin` через `ant auth login`, либо отдельный Admin API key) и то, где они не взаимозаменяемы (сервис-аккаунты требуют именно OAuth).
- Явно названные необратимые операции (архивация воркспейса отзывает все ключи в нём разом) и ограничения, которые нельзя обойти через API (выдача роли admin и создание самих API-ключей — только через веб-консоль).

## Что не взято / лиды

- Usage and Cost API и Claude Code Analytics API упомянуты в notebook'е как соседние отчётные эндпоинты (токены/доллары по воркспейсу или ключу, активность по пользователю) — не разбирались подробно, не связаны напрямую с этим прогоном; если понадобятся детали — отдельный заход.
- Workload Identity Federation (keyless-аутентификация) упомянута ссылкой в notebook'е, не раскрыта — не проверялась по первоисточнику отдельно, точка для будущей допроверки, если станет актуальной.
- Полный код notebook'а (809 строк) не воспроизведён построчно — саммари получено через `WebFetch`-пересказ содержимого `misc/admin_api.ipynb`, а не построчным чтением JSON; факт добавления и список эндпоинтов дополнительно подтверждён напрямую списком файлов PR #881 (`misc/admin_api.ipynb`, `+809 −0`) и историей коммитов репозитория (коммит `6b671ef`, 2026-09-18).
