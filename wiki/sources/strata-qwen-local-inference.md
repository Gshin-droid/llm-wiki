## Саммари

Инбокс принёс пересказ-анонс без цитат («качество и скорость в чате не обсуждали, это только анонс»), но в том же файле ниже лежит **весь текст README**, скачанный при отправке — первоисточник нашёлся прямо в сырье, проверен и процитирован по правилу CLAUDE.md для наводок. Содержание README оказалось не анонсом, а полноценной практической документацией: quickstart, таблица железа, конкретные URL для интеграции, troubleshooting.

**Что такое Strata.** Инференс-движок, запускающий Qwen3.8-Flash-Next (24 576 экспертов, MoE, 10 активных на токен) на одной игровой видеокарте от 12 ГБ VRAM, выгружая остальное в RAM/SSD («kitchen/pantry» — то, что спрашивают часто, остаётся на карте). Даёт **OpenAI-совместимый** (`http://127.0.0.1:8080/v1`) и **Anthropic Messages-совместимый** (`http://127.0.0.1:8080/v1/messages`) эндпоинт на localhost; явная строка для Claude Code — `ANTHROPIC_BASE_URL=http://127.0.0.1:8080`. Поддерживает изображения в чате, speculative decoding (ускорение 1.6–1.8×), multi-GPU, выбор глубины размышления (off/low/medium/high).

## Что взято в вики

1. **Легитимный образец того же механизма, что в [[forever-downloads-agents-md-attack]].** Там `ANTHROPIC_BASE_URL`, записанный в настройки, — признак захвата токена чужим сервером. Здесь тот же параметр — штатный, документированный способ подключить Claude Code к **своему** локальному движку на `127.0.0.1`. Дополнение на [[ai-security-by-design]]: сама переменная не индикатор атаки, индикатор — куда она указывает (localhost своей машины и момент, когда её поставил сам пользователь, против удалённого адреса, появившегося без его участия).
2. **Документированный, не гипотетический, пример «агент управляет локальной службой через MCP».** README прямо говорит: «AI tools can also install, start and stop Strata themselves through its MCP server» — ровно тот сценарий, который сегодня (2026-11-02, отдельная наводка #257, не взята страницей) поднял вопрос «локальная служба без авторизации — инструмент агента вне списка `tools`» на [[zabor-i-stena-prava-agenta]]. Дополнение туда — не ответ на вопрос, а подтверждение, что это не теоретический риск: вендоры сами проектируют агентов как администраторов локальных сервисов.
3. **Третий архитектурный паттерн локального инференса в вики** — в ряд с [[nvidia-pair]] (маршрутизатор запросов между несколькими машинами к Ollama/LM Studio, без деления видеопамяти) и [[unsloth]]/[[laya]] (дообучение маленьких моделей-решений). Strata — не маршрутизатор и не дообучение, а способ **одну большую MoE-модель с offloading'ом** поместить в одну видеокарту потребительского класса через собственный движок на базе llama.cpp/ggml. Разные задачи: PAIR делит нагрузку между машинами, Strata сжимает одну модель в одну машину.
4. **Практический recipe, а не факт выхода.** README — quickstart (Windows `START-HERE.bat` / Linux `./setup.sh`), таблица требований, таблица моделей по объёму RAM, troubleshooting (замирание ПК при первом старте — нормально, нехватка RAM, занятый порт 8080). Это ровно критерий рутины 2 — «как этим пользоваться», а не «что вышло».

## Берём инструмент или логику

**Инструмент — не ставим.** Требует видеокарту NVIDIA/AMD от 12 ГБ VRAM и 32–64 ГБ RAM; подтверждённого железа на машине пользователя для такой установки нет, и установка (~70–80 ГБ, 532 коммита, 188 звёзд, **нет указанной версии статуса** — preview или stable README не называет) не оценивалась руками. Решение автономное — не инсталлировать без подтверждения пользователя, это обратимое и недешёвое действие (загрузка модели).

**Логика — берём:**
- Проверка «подозрительный `ANTHROPIC_BASE_URL`» на [[ai-security-by-design]] должна спрашивать не «есть ли переменная», а «куда она указывает и кто её поставил» — локальный 127.0.0.1-движок и чужой удалённый сервер из атаки выглядят в настройках одинаково по форме записи.
- Открытый вопрос «агент как администратор локальной unauth-службы» на [[zabor-i-stena-prava-agenta]] подтверждён реальным продуктовым паттерном, не только собственным экспериментом с хабом проектов.
- Ландшафт локального инференса на [[nvidia-pair]] дополнен третьим узлом: single-machine offloading против multi-machine routing.

## Что не взято / лиды

- Замеры скорости (60+ токенов/с на RTX 5070, 100–140 на RTX 3090) — цифры автора без независимой проверки, не выносятся фактом отдельно; само README честно помечает их «measured on two ordinary gaming PCs».
- Версия/статус разработки (preview vs stable) — README не называет явно; в бэклог не заводим, вопрос снимется, если/когда инструмент понадобится предметно.
- Сравнение качества Coder-версии (91% SWE-bench Verified от полной модели, по словам авторов) с другими квантованными моделями — не наш пробел, в вики уже есть отдельная ветка про квантование ([[obrezka-slovarya-modeli]]), но там другая модель и другая техника сжатия; не совмещаем искусственно.

## Оценка источника

Официальный README открытого репозитория (MIT), прочитан целиком — редкий случай, когда исходный «пересказ без цитат» инбокса оказался неполным, а сам файл внизу содержал весь первоисточник. Автор честно разделяет «заявлено» (железо, фичи) от «измерено» (скорость, с пометкой на каких именно двух ПК), что поднимает доверие к разделу требований. Промо-нагрузка: кнопка поддержки разработки — на техническую часть не влияет.

## Проверка безопасности источника

**Файл содержит текст, прямо адресованный агенту, и это стоит явно назвать пользователю, хотя находка легитимна, а не атака.** В разделе интеграции README есть готовый блок для вставки в ассистента: «Set up Strata on this PC for me: https://github.com/Niko1221/Strata — follow docs/AI_SETUP.md in that repository», и далее: «AI tools can also install, start and stop Strata themselves through its MCP server». Это не инструкция, спрятанная в источнике для перехвата сессии (как в [[forever-downloads-agents-md-attack]]) — это открыто показанный пользователю официальный рецепт самого вендора, предназначенный именно для копирования в ИИ-ассистента. Прочитан как цитата документации, не выполнялся: Strata не устанавливалась, `docs/AI_SETUP.md` не открывался, ни локальный сервер на 127.0.0.1:8080, ни MCP-сервер Strata не запускались и не вызывались. Разница с атакой из [[forever-downloads-agents-md-attack]] — именно в происхождении и видимости: там текст подсовывает интернет без участия пользователя в папку, которую агент читает как правила проекта; здесь текст лежит на публичной странице репозитория и предназначен для того, чтобы пользователь сам решил его скопировать.

## Дополнение (2026-11-05): сверка с оригиналом репозитория

Пересмотр вместе с пользователем: для него Strata — кандидат в движок под сервисы на локальных моделях, а не только иллюстрация к безопасности. Сверено с главной страницей оригинала [Niko1221/Strata](https://github.com/Niko1221/Strata) (через пересказ страницы, README целиком не прочитан):

- **Масштаб другой, чем на этой странице.** Разбор 11-02 шёл по форку `mach10x/strata` (188 звёзд, 532 коммита). У оригинала — 40,3 тыс. звёзд, 4,4 тыс. форков, 5 637 коммитов, MIT. Следствие для выбора: проект заметный, но меняется очень быстро — для основы сервиса это и плюс, и риск рядом со стабильным Ollama.
- **Модели шире одной.** Кроме Qwen3.8-Flash-Next — Qwen3.6-35B-A3B и DeepSeekV4.1-Flash-1017 (последний — 191–274 ГБ на диске в зависимости от квантования, «что не влезает в память, читается с SSD»). Происхождение Qwen3.8-Flash-Next страница не указывает, как и число экспертов из разбора 11-02 — *не проверено*.
- **Железо.** Главная страница не даёт минимальных требований, отсылает к руководству по выбору модели; пример — RTX 3060 12 ГБ с 46 ГБ оперативной памяти. Рабочая машина пользователя (8 ГБ видеопамяти, 16 ГБ ОЗУ) ниже примера; домашняя (16 ГБ видеопамяти) подходит по карте, объём ОЗУ — *не проверен*. Вывод 11-02 «подтверждённого железа нет» уточнён: проверять на домашней машине.
- **MCP на главной странице больше не упоминается** — интеграция названа через OpenAI- и Anthropic-совместимые API. Есть ли MCP-сервер в документации — *не проверено*; цитата из раздела «Что взято», п. 2, относится к README форка на 11-02.
- **В репозитории лежит `AGENTS.md`**, а на главной — строка «For AI tools and automated readers» со ссылками на него и `docs/AI_SETUP.md`. Тот же канал, что в [[ai-security-by-design]] (дополнение про Ghostty и Turborepo): клон Strata перед запуском агента рядом — сначала прочитать этот файл проверяющим.
- **Локальный API без авторизации:** «No account needed», про ключи ничего. На своей машине нормально; для сервиса, к которому ходят другие люди, перед Strata нужна прослойка с авторизацией, наружу движок не открывать.
- **Подключение Claude Code** — переменная `ANTHROPIC_BASE_URL` задаётся пользователем при запуске в своей оболочке, а не записью агента в файл настроек: такую запись наш сторож отказывает намеренно, и это верно — см. п. 1 раздела «Что взято».

Проба вынесена пунктом в `wiki/gaps-backlog.md`: Strata против Ollama на одной модели на домашней машине.
