## Саммари

Пост: Sonnet 5.5 решил больше всех задач (57 из 105), но «в три раза дороже Opus 5.5 и в четыре раза медленнее» из-за дорогих «мутационных тестов»; лучшие по цене и времени — Opus 5.5 и GPT-6 Astra.

**Проверка по сырым данным (2026-10-12) показала: верно, но только для уровня усилий max.** Пост выдаёт свойство одного уровня за свойство модели.

Бенчмарк: 105 подброшенных багов в двух рабочих репозиториях, каждая модель в своём агентном CLI (Claude — в [[claude-code]] на API Anthropic), одинаковый промпт, слепая проверка по ключу ответов моделью другого поставщика (Claude судит GPT-5.5). Стоимость — по публичным тарифам, посчитана по токенам. Средние по трём прогонам:

| Effort | Sonnet 5.5: баги / $ / мин | Opus 5.5: баги / $ | Haiku 5.5: баги / $ |
|---|---|---|---|
| low | 19 / 5,7 / — | 22,3 / 8,3 | 11 / 1,6 |
| medium | 23,3 / 11,1 / — | 30,3 / 15,7 | 12 / 2,7 |
| high | 34,3 / 19,9 / 28 | 31,7 / 22,2 | 16 / 3,6 |
| xhigh | 36 / 42,9 / 73 | 36 / 35,0 | 18,3 / 4,8 |
| max | 51,3 / **154,0** / **287** | 41,7 / 58,5 / 67 | 21,5 / 5,8 |

(Haiku 5.5 — среднее двух-трёх прогонов, у low и medium по одному; минуты есть не для всех строк.)

**Почему max так дорог** — из протокола прогона: на max Sonnet 5.5 после готового отчёта продолжает работать ещё 55–268 минут — к каждой починке пишет регрессионный тест и проверяет, что тот падает при откаченной починке (мутационная проверка). На xhigh хвост бывает (до 56 минут), на high его нет. Opus 5.5 на всех уровнях заканчивает в пределах минуты после отчёта.

**Разброс большой:** три одинаковых прогона Sonnet 5.5 max дали 57, 54 и 43 — разница 14 задач. Пост берёт лучший из трёх (57), автор бенчмарка публикует среднее (51,3).

## Берём инструмент или логику

**Инструмент** — бенчмарк не ставим и не гоняем: это чужой замер на чужих репозиториях. Берём как **данные** для выбора исполнителя.

**Логика — три вывода для нашей лестницы «Haiku → Sonnet → Opus»:**

1. **Sonnet 5.5 не запускать на max.** На high он не хуже Opus 5.5 и немного дешевле; на max платишь втрое за мутационные проверки, которые нужны только по прямому указанию.
2. **Opus 5.5 на low — сильная ступень.** 22 бага за $8 — больше, чем Sonnet 5.5 на low (19 за $5,7), и почти как Sonnet на medium (23 за $11). Ступень «Sonnet» не всегда дешевле ступени «Opus»: сравнивать надо пару «модель + уровень усилий», а не модели.
3. **Haiku 5.5 на починке сложных багов слаб** (11–22 из 105) — для неё задачи с проверяемым результатом попроще. Совпадает с правилом «проверяющие — не ниже Sonnet».

Оговорка про цену: бенчмарк считал чтение кэша Sonnet 5.5 по $0,20 за млн токенов; с 2026-10-10 оно стоит $0,10 ([[claude-api-cost-optimization]]), так что сегодня Sonnet немного дешевле, чем в таблице. Вывод про max от этого не меняется: там дорог не кэш, а лишние ходы.

Оговорка: один бенчмарк, два репозитория, один тип работы (поиск и починка багов). На текстовой работе и разведке картина может быть другой.
