## Саммари

Версия 1.30.0 `ant` CLI (Claude API CLI) добавила подкоманду `ant apply` — Terraform-style рабочий процесс для [[claude-managed-agents|Claude Managed Agents]]: агенты, environments, skills, memory stores и scheduled deployments описываются файлами (Markdown/YAML) в репозитории, `ant apply` печатает план изменений, применяет его после подтверждения и пишет lockfile `claude-lock.json`, который коммитится вместе с файлами. Это первый случай в этой вики, когда ресурсы Managed Agents создаются не программным вызовом SDK построчно (как во всех разобранных ранее cookbook'ах), а декларативно — файл описывает желаемое состояние, инструмент считает разницу.

**Механика:**
- Каждый файл описывает один ресурс: агент — Markdown с YAML frontmatter (конфигурация) + тело (system prompt); environment/memory store — YAML (тело запроса к create-эндпоинту); deployment — Markdown (frontmatter = тело запроса, проза = первое сообщение сессии); skill — директория с `SKILL.md` в корне, целиком грузится как один бандл.
- **Определение вида ресурса** — по приоритету: явное поле `type` в файле → директория (`agents/`, `environments/`, `memory_stores/`, `deployments/`) → префикс имени файла. Файлы без совпадения (README, CI-конфиги) пропускаются, если не названы явно в команде.
- **Ресурсы ссылаются друг на друга относительным путём к файлу**, а не ID — `ant apply` создаёт их в порядке зависимостей и сам подставляет реальные ID; ссылка на агент/skill фиксируется на версию, применённую в этом прогоне (правка `reviewer.md` обновит всё, что на него ссылается, в том же прогоне). Ссылка на ресурс не под управлением этих файлов — просто ID (`agent_...`) или произвольный объект API (`{type: anthropic, skill_id: xlsx}`). Skill можно сослаться и на GitHub URL вида `.../tree/<branch>/<dir>` — `ant apply` скачивает и грузит директорию, закрепляя коммит до `--upgrade`.
- **`claude-lock.json`** — коммитится в репозиторий, хранит `organization_id`/`workspace_id` и на каждый файл: `kind`, `id`, `version`, `hash` (что отправлено) и `remote_hash` (что вернул API) — расхождение хэшей ловит и правку файла, и правку ресурса «в обход», из Console. Именно отсюда приложение берёт ID агента для запуска сессии.
- **Конфликт с ручной правкой через Console — жёсткий отказ, не тихий перезапис.** Если ресурс изменён/архивирован/удалён вне этих файлов, план заканчивается `This plan cannot be applied:` с причиной и командой exit `refusing to apply`; `--force` — осознанный обход. Удаление файла не удаляет ресурс (только предупреждение), нужен явный `--prune`. `ant apply` не может «усыновить» ресурс, созданный вручную в Console или через `ant beta:agents create`, — управляется только то, что уже в lockfile'е.
- **В CI** — без терминала команда требует `--yes` (иначе печатает план и останавливается с инструкцией); `--dry-run` на pull request печатает план для ревьюеров без применения (exit 0 даже если план заблокирован); лок-файл коммитится в конце джобы даже при частичном падении; аутентификация — через Workload Identity Federation, а не хранимый API-ключ; команда отказывается работать, если credentials резолвятся не в ту организацию/воркспейс, что записаны в lockfile.
- Полный набор флагов: `--dry-run`, `--yes`, `--force`, `--prune`, `--upgrade` (переразрешить skill по GitHub URL), `--lock-file <path>` (свой lockfile на организацию/воркспейс), `--verbose`/`-v`.

## Что взято в вики
- Весь механизм — новый раздел на [[claude-managed-agents]] (после cookbook-серии, как отдельная линия развития продукта — не через `client.beta.*` SDK, а через файлы + CLI).
- Явное противопоставление с уже задокументированным на той же странице паттерном («Практический пример (Python SDK)») — `ant apply` не заменяет SDK-вызовы, а даёт альтернативный путь провижининга тех же ресурсов, ориентированный на git-review и CI, а не на рантайм-логику приложения.

## Что не взято / лиды
- Полный список ресурсов, поддерживаемых `ant beta:agents create` и другими подкомандами CLI, кроме `apply`, не разбирался — вне темы находки.
- Не проверено, доступен ли `ant apply` для self-hosted environments (в остальном продукте это отдельная опция, см. [[claude-managed-agents]], «Экосистема вокруг ядра») — документация страницы `apply` этого не уточняет, оставлено открытым вопросом.
- Утверждения сторонних агрегаторов (releasebot.io, threads-пост) о самом факте выхода 1.30.0 использованы только как наводка на тему; все технические детали страницы взяты из официальной документации напрямую, не из пересказов.
