## Саммари

Прогон новостного разведчика через три дня после предыдущего снапшота (2026-08-16, покрывал до 2.1.233). Вышли **2.1.234** и **2.1.235** — без крупного объявления, но с тремя пунктами, задевающими уже описанную в вики механику: (1) auto mode сам продолжает работу после сброса лимита использования, не дожидаясь ручного перезапуска; (2) продолжение серии bypass-фиксов permission-анализатора/сэндбокса, отслеживаемой в [[ai-security-by-design]] с 07-19, — на этот раз NT-namespace path rejection на Windows и утечка session-scoped ответов на разрешения в фоновых субагентах; (3) встроенный скилл `claude-api` (тот, что доступен в сессиях этой вики) сжат почти в десять раз — контекстная стоимость упала с ~200k+ до ~25k токенов. Официальные release notes Claude Platform проверены тем же прогоном: единственная запись после 08-16 — переименование Workbench в Playground (18.08), решено как не проходящее порог, см. ниже.

## Ключевая находка 1: auto mode продолжает работу сам после сброса лимита (2.1.234)

*"Claude Code continues automatically when usage limits reset; configure in `/config`"* — раньше исчерпание лимита использования останавливало сессию до ручного возобновления; теперь по умолчанию (настраивается в `/config`) сессия сама возобновляется, как только лимит обнулился по расписанию тарифа. Прямое расширение того, что уже описано в [[claude-code-auto-mode-default]] и в разделе "Модели и Effort" [[claude-code]] ("Max-плана усечение лимита" — автоматический откат на Sonnet при исчерпании лимита Opus): раньше автоматизация лимитов была односторонней (модель понижается сама), теперь симметрична и по времени (сессия возобновляется сама). Для автономных рутин этой вики практически значимо — прогон, упёршийся в лимит посреди работы, больше не должен полагаться на то, что кто-то придёт и перезапустит его вручную, если конфигурация `/config` это разрешает.

Тем же релизом — *"Fixed auto mode denying sandboxed commands after conversation compaction"*: баг, при котором `/compact` мог заставить auto mode неверно отказывать в командах, уже разрешённых до сжатия контекста.

## Ключевая находка 2: продолжение серии bypass-фиксов — NT-namespace paths, session-scoped permissions (2.1.234)

Та же категория, что уже отслеживается в [[ai-security-by-design]] с 07-19 (Bash-анализатор) и с 08-16 (Windows symlink/NTLM):

- *"Implemented Windows NT-namespace path rejection to harden against NTLM credential leaks"* — прямое продолжение находки предыдущего снапшота (*"Closed NTLM credential leak vector via Windows NT device paths"*, 2.1.233, 08-16): та находка закрыла один конкретный вектор через NT device path (`\\.\`-нотация); эта — вводит более общее правило, отклоняющее NT-namespace пути как класс, а не точечный фикс одного обхода. Возможно, первый фикс не закрыл проблему целиком — changelog не поясняет, оставлено как открытый вопрос без домысливания.
- *"Fixed session-scoped permission answers being dropped in background subagent prompts"* — ответ на разрешение, данный в рамках сессии, мог теряться в промптах фоновых субагентов; практический эффект бага в changelog не раскрыт (спрашивало ли заново после уже данного ответа, или наоборот — пропускало проверку), оставлено как есть.

Малый, но показательный пункт того же раздела Security Enhancements: *"Claude now uses your account email only for identification, not third-party services"* — сужение того, куда уходит email аккаунта; ближе к приватности, чем к permission-bypass, но в том же разделе changelog.

## Находка 3: встроенный скилл `claude-api` сжат с ~200k+ до ~25k токенов (2.1.234)

*"Reduced context cost of built-in `claude-api` skill from ~200k+ to ~25k tokens"* — почти десятикратное снижение контекстной стоимости именно того скилла, что упоминается в этой вики: `prompt-audit` (subcommand скилла, см. [[claude-code]], раздел "Обновление 2.1.220–2.1.221") и справочник по Claude API/SDK, доступный в сессиях этой вики (см. список доступных скиллов в системном контексте). Практический вывод для дорогих встроенных скиллов вообще: контекстная стоимость не константа продукта, а то, что Anthropic сама продолжает резать по ходу релизов — прямая параллель находке [[mattpocock-skills]] от 08-18 про завышенную "на глаз" стоимость чужого набора скиллов, только на этот раз пересчитывать не пришлось, цифру дал сам вендор.

## Проверено и не взято: переименование Workbench → Playground (18.08.2026, Claude Platform release notes)

Официальные `platform.claude.com/docs/en/release-notes/overview` прочитаны целиком за диапазон 08-16…08-19 тем же прогоном. Единственная запись: *"Workbench is now Playground in the Claude Console... shows the full SDK request and the API response for each run"* — переименование консольного инструмента с добавлением шаблонов (code execution, web search) и показом полного SDK-запроса/ответа. Не взято: это веб-консоль Claude, а не CLI/API-механика — у этой вики нет браузерного доступа к `platform.claude.com`, и функционально это ближе к "анонс продукта без практики, применимой из терминала", чем к материалу уровня порога Ingest (см. `references/source-evaluation.md`). Отдельно отмечено, что часть той же страницы (Compliance API для локальных Cowork/Claude Code сессий, 08-11) уже старше окна этого прогона — датирована раньше 08-16, оставлена не разобранной как out-of-scope для новостного разведчика этого дня.
