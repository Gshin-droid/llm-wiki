## Саммари

MCP-сервер с архивом реальных сайтов, которые агент изучает перед тем, как верстать интерфейс: «у агентов есть инструменты, но нет вкуса». Разобран вместе с пользователем. Решение — не подключать сейчас, попробовать при следующей работе над оформлением двух своих проектов. Главное для вики: Inspo — лучший источник **якоря стиля** из [[design-md-yakor-stilya]], чем подборка, на которую правило опирается сейчас.

## Что внутри (по README, 2026-10-19)

- **2 320 страниц с 832 сайтов**, сняты в версии для компьютера и телефона: палитра, настоящие шрифты, технологии, разбор страницы по экранам.
- **68 образцовых блоков** (шапки, цены, подвалы, меню) с кодом JSX.
- **DESIGN.md на каждый сайт, снятый с кода страницы**: роли цветов, шкала шрифтов, отступы, CSS-переменные, ширина контейнера.
- 15 инструментов; `recommend(brief)` собирает подборку под описание задачи одним вызовом.
- Сервер на TypeScript, два способа связи: локально через npm или по HTTP с их сайта. Поиск по смыслу — на эмбеддингах Together AI.

Пост верен по сути («800 сайтов» — 832); ссылку на репозиторий пришлось искать через npm.

## Берём инструмент или логику

- **Инструмент — да, позже, и только вручную в проект.** Не `npx inspo-mcp install`: установщик сам находит агентов на машине и правит их настройки — исполняется раньше, чем его прочитали. Вместо него — одна строка `claude mcp add --transport http inspo https://inspomcp.dev/api/mcp` в проекте с оформлением: код на машине не исполняется, выключается `claude mcp remove inspo`. Наружу уходит текст запроса о дизайне — зелёный материал.
- **Логика — якорь, снятый с кода, а не с картинки.** Правило фронтенда берёт DESIGN.md из подборки `awesome-design-md`, где цвета сняты со скриншотов и названы приближением. У Inspo те же поля сняты с кода страницы, и сайтов на порядок больше. Шаг правила не меняется — меняется источник.

## Где пробуем (решение пользователя 19.10)

На двух своих проектах, при следующей работе над оформлением: новый сайт без выбранного стиля и новая отдельная тема приложения, у которого уже есть свои темы. В обоих случаях решение об оформлении ещё не принято, поэтому внешний якорь уместен (правило фронтенда: своя дизайн-система важнее внешнего референса — там, где она уже есть). Схема одна: 2–3 варианта, якорь каждого — DESIGN.md из Inspo вместо подборки; сравнить, лучше ли якорь, снятый с кода.

Пробы записаны делами в хабе проектов; строка об Inspo — в правиле фронтенда, раздел «Внешние инструменты».

README конкретный: состав архива, технологии, путь самостоятельного развёртывания, раздел безопасности. Пример «с Inspo и без» — одна пара картинок, не замер. Авторы известные (Together AI), MIT, около 900 звёзд.

## Проверка безопасности источника

Пост и README — без инструкций, обращённых к агенту. Доверие двух уровней: к автору (известная компания, открытый код) и к контенту, который сервер приносит в контекст, — DESIGN.md чужих сайтов. Второй уровень правило фронтенда уже закрывает: чужой DESIGN.md прочитать перед подключением, нет ли в нём чего-то кроме стиля. Единственный инструмент, идущий в сеть (`get_design_system(live:true)`), по README защищён от запросов на внутренние адреса (только публичные хосты, порты 80 и 443) — не проверено.
