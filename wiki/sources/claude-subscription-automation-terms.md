## Саммари

Наводка из чата практиков: «вызов `claude -p` из крона приводит к бану аккаунта и нарушает лицензию» — одно утверждение без подтверждения. Сверено с тремя документами Anthropic. **Утверждение не подтверждено:** ни один документ не связывает запуск по расписанию на подписке с блокировкой, а документация сама показывает запланированную задачу как обычный сценарий `claude -p`. Граница проходит не по способу запуска, а по **объёму** («обычное, индивидуальное использование») и по тому, **кто пользуется** (своя подписка — только для себя). Первая часть той же наводки — Claude раздаёт задачи другим CLI-агентам — ушла в сводную страницу о связках моделей.

## Что взято в вики

**1. Consumer Terms, раздел 3, пункт 7** — запрещено обращаться к сервисам *"through automated or non-human means, whether through a bot, script, or otherwise"* («автоматическими или нечеловеческими средствами — ботом, скриптом или иначе»), *"except when you are accessing our Services via an Anthropic API Key or where we otherwise explicitly permit it"* — кроме доступа по ключу API и случаев, которые Anthropic явно разрешает. Там же, раздел 2: нельзя передавать учётные данные и *"make your Account available to anyone else"* — делать аккаунт доступным другим.

**2. Claude Code — «Legal and compliance».** Тарифы Free/Pro/Max/Ultra подчиняются Consumer Terms. Раздел «Acceptable use»: *"Advertised usage limits for Pro, Max, and Ultra plans assume ordinary, individual usage of Claude Code and the Agent SDK"* — заявленные лимиты рассчитаны на обычное индивидуальное использование Claude Code **и Agent SDK**. Раздел «Authentication and credential use»: вход по подписке (OAuth) — *"designed to support ordinary use of Claude Code and other native Anthropic applications"*. Прямой запрет — разработчикам сторонних продуктов: встраивать вход Claude.ai в свои приложения, пускать запросы своих пользователей через подписки Free/Pro/Max/Ultra, собирать или хранить чужие токены. Для продуктов на Agent SDK — ключ API. Anthropic *"may [enforce] without prior notice"* — может принимать меры без предупреждения.

**3. Claude Code — «Run Claude Code programmatically» (headless).** `claude -p` — штатный режим без интерфейса; раздел «Turn off permission prompts in unattended runs» прямо называет пример *"for example in a scheduled job"* (запланированная задача) и даёт флаг `--permission-prompts none`. Без `--bare` запуск `-p` использует вход по подписке; `--bare` вход по подписке не читает и требует `ANTHROPIC_API_KEY`. Документация предупреждает, что `--bare` станет поведением `-p` по умолчанию в будущей версии — тогда скрипты на подписке перестанут работать без ключа или явного выбора.

**Как это читать вместе.** Пункт 7 условий запрещает автоматизацию «кроме явно разрешённого»; собственная документация Claude Code описывает запуск по расписанию и включает Agent SDK в «обычное индивидуальное использование». Отсюда:

| Сценарий | Оценка |
|---|---|
| Своя задача по расписанию, `claude -p`, результат читает владелец подписки, объём небольшой | в зоне «обычного индивидуального» — документация показывает такой сценарий |
| Круглосуточные агенты на подписке, расход упирается в лимиты постоянно | серая зона: формально тот же способ, но под вопросом «обычное» |
| Бот или сервис отвечает **другим людям** через `claude -p` на своей подписке | прямо запрещено — подписка становится доступной другим, это посредничество |
| Свой продукт на Agent SDK для других | только ключ API |

## Берём инструмент или логику

**Инструмент** — не про установку. Свой действующий сценарий (ночная сводка чата через `claude -p` на Sonnet без инструментов, результат читает один человек) попадает в первую строку таблицы. Ничего не меняем.

**Логика:**

1. **Граница — объём и круг пользователей, а не способ запуска.** Правило для любой новой автоматизации на подписке: результат только для себя, объём — «обычный»; как только к автоматизации подключаются другие люди — ключ API.
2. **Будущий `--bare` по умолчанию сломает скрипты на подписке молча** — это повод при обновлениях Claude Code сверять поведение `-p` у своих задач по расписанию, а не ждать письма о сбое.
3. Урок о наводках прежний ([[claude-code-critical-path-rm-docs]], [[novosti-2026-10-30]]): уверенное «приводит к бану» без источника — повод для сверки, а не для правила.

## Оценка источника

Первоисточники — условия и документация самой Anthropic, высший уровень доверия для вопроса «что разрешено». Ограничение: «обычное использование» нигде не определено числом — это оценочная граница, и решает её Anthropic. Наводка — пересказ одного участника без деталей.
