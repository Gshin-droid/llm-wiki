## Саммари

Ярус 2 рутины 1 (новости), следом за сводкой [[novosti-2026-09-25]]. Одиннадцать дней с прошлого снапшота (09-14, версия 2.1.271), версий много (2.1.274–2.1.282, 2.1.272–2.1.273 в файле не встречаются) — это первое сплошное закрытие такого разрыва после того, как несколько версий из него (2.1.277, 2.1.280) уже попадали в вики точечно через другие источники ([[plugin4shell-vulnerability]], [[claude-opus-5-5-launch]]). Разбор ниже не покрывает весь диапазон построчно — версий десятки строк каждая, большинство рутинные UI/VSCode/Claude Tag фиксы; отобраны находки с весом для практики этой вики, полный текст — в raw-снапшоте.

## Находка 1: серия фиксов надёжности возобновления сессии — включая тихое обрезание прокси

Тем же релизом 2.1.281, что добавил AWS-функциональность, вышла плотная пачка независимых фиксов вокруг одной темы — потери или искажения данных при возобновлении/проксировании сессии:

- *"Fixed responses cut short by proxy shown as complete"* — ответ, обрезанный прокси на полпути, раньше показывался как завершённый без предупреждения; ровно тот класс тихого обрыва, ради которого в `CLAUDE.md` этой вики существует правило инкрементального коммита ("прогон обрывается без предупреждения").
- *"Fixed resumed sessions re-sending earlier turns in changed form"* и *"Fixed resuming very large session restoring only last messages"* — возобновлённая сессия могла тихо исказить прошлые ходы или восстановить только хвост длинной истории.
- *"Fixed session resumed after restart missing prompt cache"* и *"Fixed prompt cache lost when MCP server disconnects mid-conversation"* — два независимых пути потери прогретого кэша.
- *"Fixed tool calls running twice on duplicated stream events"* и *"Fixed responses failing with «Content block not found» when proxy drops event"* — дублирование и потеря событий стрима на стороне прокси/шлюза.

Версией позже (2.1.282) один и тот же баг переоткрылся под новой формулировкой — *"Fixed continued/resumed sessions re-sending earlier messages in changed form"*, почти дословное повторение фикса 2.1.281 про "re-sending earlier turns in changed form". Changelog не поясняет, регрессия это или отдельный случай того же класса; вывод по прошлым наблюдениям того же паттерна ([[claude-code-changelog-snapshot-2026-08-16]], откат Bash-фикса 2.1.233) — фикс одной версии не гарантирует, что соседний путь того же бага закрыт тоже.

**Практический вывод для автономных рутин этой вики:** обрезание ответа прокси, показанное как завершённое, — именно то, из-за чего 10.07.2026 весь ingest был потерян перед финальным пушем (см. `CLAUDE.md`, «Автономные рутины: инкрементальный коммит и пуш»). Фикс не отменяет дисциплину инкрементального коммита — она защищает и от других классов обрыва (лимит бюджета, сбой контейнера), но конкретно этот механизм тихого обрезания теперь чинится на стороне инструмента, а не только обходится дисциплиной снаружи.

## Находка 2: `"attribution": false` — штатный способ полностью скрыть атрибуцию коммитов/PR

*"Added `"attribution": false` in `settings.json` hiding all commit/PR attribution"* (2.1.281). Продолжение темы из снапшота 09-13 ([[claude-code-changelog-snapshot-2026-09-13]]), где 2.1.269 закрыл баг обратного направления — системное напоминание перебивало запрет атрибуции из `CLAUDE.md`. Здесь — не баг-фикс, а новый явный переключатель уровня `settings.json`, а не текстового правила: раньше запрет атрибуции жил только как инструкция в `CLAUDE.md`/системном промпте (не enforced-конфигурация, см. раздел про auto-memory выше в [[claude-code]]), теперь это булева настройка того же уровня, что `deny`-правила permissions.

Не применено к этой вики: `.claude/settings.json` репозитория `"attribution"` не задаёт, а атрибуция коммитов этой сессии определяется системным напоминанием сессии (`Co-Authored-By`/`Claude-Session`), не `CLAUDE.md` — отключать нечего, находка зафиксирована как доступный инструмент на будущее, не как рекомендация к действию.

## Находка 3: классификатор auto mode по умолчанию переехал на сторону сервера

Два релиза одной темы: *"Changed auto mode defaulting to server-side classifier not charging overhead"* (2.1.278, на API/Enterprise/Bedrock/Vertex/Foundry/шлюзах), затем *"Changed `CLAUDE_CODE_AUTO_MODE_SERVER` applying on direct API"* и *"Changed auto mode reviewing read-only/sandboxed commands"* (2.1.281). До этого changelog auto mode описывался только по сужению правил, что классификатор разрешает (серия bypass-фиксов, [[ai-security-by-design]]) — это первая находка про то, **где** сам классификатор исполняется. Дословных деталей "server-side" (что именно уходит на сервер — только решение allow/deny или контекст запроса) changelog не даёт; открытый вопрос, не проверялся отдельно первоисточником (документация auto mode/permission-modes не перечитывалась в рамках этого прогона — кандидат в `wiki/gaps-backlog.md`).

## Находка 4: продолжение серии bypass-фиксов — символьные ссылки CLAUDE.md и managed-настройки с некорректным значением

Три независимых пункта 2.1.282 того же класса, что уже отслеживается в [[ai-security-by-design]]:
- *"Fixed CLAUDE.md/rules read through symlinks reaching macOS `/Network` or `/home`"* — символьная ссылка внутри проекта могла увести чтение `CLAUDE.md`/rules за пределы ожидаемой директории на сетевой том или домашнюю папку.
- *"Fixed managed settings ignoring mistyped boolean lock key values"* и *"Fixed managed `permissions`, `autoMode`, `worktree`, `attribution` settings ignored when nested value invalid"* — опечатка или некорректное вложенное значение в managed-политике организации раньше тихо отключала весь блок политики вместо отказа или предупреждения (аналогично прошлой находке про `managed-mcp.json`, снапшот 09-14).
- *"Fixed repository/user skills pre-approving own tools under managed `allowManagedPermissionRulesOnly`"* — скилл мог самостоятельно разрешить себе инструменты в обход режима «только managed-правила».

## Малое

- **AGENTS.md вместо CLAUDE.md** (2.1.277) — *"Added AGENTS.md support reading instead of CLAUDE.md"*; для этой вики неприменимо (правила ведутся в `CLAUDE.md`, `AGENTS.md` в репозитории нет).
- **`maxProseWidth`** (2.1.282) — ограничение ширины прозы Claude в широких терминалах, таблицы/код остаются на полную ширину.
- **`400 … Input tag 'advisor_20260301'`** (2.1.276) — однострочный релиз, чинящий регрессию, уронившую каждый запрос; не датирован отдельно, судя по номеру — вышел и почти сразу заменён 2.1.277.
- Платформенные release notes за 09-15–09-25 отдельно не проверялись в рамках этого прогона (кандидат в `wiki/gaps-backlog.md`, если появится время у рутины хвостов).
