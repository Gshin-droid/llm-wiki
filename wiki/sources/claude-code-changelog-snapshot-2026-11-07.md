## Саммари

Единственная новая версия с прошлого снапшота [[claude-code-changelog-snapshot-2026-11-04]], который уже закрыл v2.1.314–2.1.318 — здесь только v2.1.319. Без headline-анонса модели, но с десятым узлом давно отслеживаемой в этой вики серии bypass-фиксов, новой настройкой жёсткого отказа вместо вопроса и ужесточением auto mode за корпоративными гейтвеями.

## Что взято в вики

1. **Три новых bypass-фикса (десятый узел серии).** *«Fixed a sandbox escape when creating a worktree»*; *«Fixed a Bash permission bypass where a crafted environment prefix could hide part of a command from permission checks»*; *«Fixed a case where a sed command could skip the permission check in accept-edits and auto mode»*. Как и у всех прежних узлов серии (см. [[ai-security-by-design]]), changelog называет факт и класс обхода, но не механизм. Перенесено в [[ai-security-by-design]] (раздел «Десятый узел») и [[claude-code]] (новая подсекция «Обновление 2.1.319»).
2. **`permissions.denyInsteadOfPrompting`** — новая настройка (по умолчанию выключена): вызов, который иначе ждал бы разрешения пользователя в терминальных сессиях, субагентах и teammates, сразу отказывается, а не блокирует ход ожиданием ответа. Перенесено в [[claude-code]].
3. **Auto mode за LLM-гейтвеями и на Bedrock/Vertex/Foundry без телеметрии/feature flags** — вызовы, которые сервер не может проверить, теперь по умолчанию спрашиваются у пользователя или отказываются вместо прежнего отката на встроенный классификатор (старое поведение возвращает `CLAUDE_CODE_AUTO_MODE_SERVER=0`); настройки проекта/плагин больше не могут снова включить server-side проверку, выключенную снаружи проекта. Перенесено в [[claude-code]].
4. Малое — перенесено в [[claude-code]] одной строкой без отдельного разбора: MCP-задачи в терминале теперь уходят в фон сразу по умолчанию; точное правило Bash/PowerShell `ask` отказывает без вопроса, если команду уже перекрывает более широкое правило `deny`; Bash-инструмент спрашивает разрешение перед `which` с флагами за пределами набора «посмотреть/показать».

## Берём инструмент или логику

Инструмент (сам Claude Code) в этой вики уже стоит и обновляется автоматически — вопрос «ставить или нет» здесь не возникает. Логика: `permissions.denyInsteadOfPrompting` и ужесточение auto mode за гейтвеями не действуют на эту вики напрямую (автономные рутины работают через `claude -p` без корпоративного гейтвея, на managed-инфраструктуре Anthropic), поэтому в `.claude/settings.json` этой вики ничего не меняется. Урок, переносимый без изменения кода: разбор каждого узла серии bypass-фиксов подряд не даёт считать класс закрытым — ровно та же формулировка повторяется с узла 4, подтверждена здесь десятый раз.
