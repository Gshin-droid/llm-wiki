## Саммари

Наводка инбокса — пересказ без цитат: «переслали мод, который показывает по ходам, что лежит в контекстном окне... команда установки дана с подменой части названия, точная версия неясна». Факт с проверяемым происхождением: сам мод существует, устанавливается как `npx claude-code-templates@latest --mod ui/turn-inspector` (подмены в названии не было, пересказ ошибся) в том же репозитории, что уже дважды разбирался в вики — [[prompt-cache-control-mod]] и [[jev-skill-suggestion-mod]], тот же автор и тот же каталог модов.

Боковая панель Claude Code показывает сессию по ходам (каждый запрос к модели — ход): вход (системный промпт, инструменты, предыдущие ходы, новое сообщение) и выход (thinking, текст, вызовы инструментов) выводятся стеком, полоска показывает долю окна контекста. Домен `aitmpl.com`, где у мода есть официальная карточка, недостижим из автономного прогона (`getaddrinfo ENOTFOUND www.aitmpl.com`) — новая запись в таблице недостижимости. Содержание восстановлено прямым чтением README и исходного кода мода в GitHub-репозитории (тот же приём обхода, что уже применялся для `prompt-cache-control`), и это полноценный первоисточник, не заменитель.

## Что взято в вики

- **Слушает пять событий мода**: `turn.start` (промпт + первое новое входное сообщение), `turn.step` (каждый запрос цикла — блоки ответа, `usage`, stop reason), `tool.call` (ответ инструмента, новый вход для следующего запроса), `turn.complete` (обновляет оценку системного блока), `session.measure` (размер окна контекста).
- **Два источника чисел, честно различённых интерфейсом.** Итоги хода (токены на входе/выходе) — из поля `usage` API, точные. Отдельные блоки внутри хода (сколько именно токенов в системном промпте против предыдущих ходов) — оценка «~4 символа на токен», помечена значком `~`; thinking получает остаток от точного общего числа. Разница между «точно знаю» и «прикинул» вынесена в саму панель, а не спрятана за одним числом.
- **Метка `compacted before this turn`** — явный сигнал, что вход уменьшился относительно предыдущего хода, то есть прошло сжатие. Полезно как внешний индикатор момента `/compact`/auto-compaction без похода в `/usage`.
- **Настройки** — `columns` (ширина панели, 36–120, по умолчанию 56), `maxTurns` (сколько ходов хранить, старые вытесняются, по умолчанию 200), `openOnStart` (открывать при старте, по умолчанию `false`) — задаются в `pluginConfigs["turn-inspector@skills-dir"].options`.
- **Версия.** Работает с Claude Code 2.1.287+ (моды включены по умолчанию с этой версии — подтверждено отдельно changelog'ом в [[claude-code-changelog-snapshot-2026-10-04]]); на 2.1.259–2.1.286 нужен `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.
- **Безопасность кода — прочитан, не пересказан.** `hooks/turns.ts` и `hooks/turn-inspector.tsx` прочитаны целиком напрямую: ни `fetch`/`http`/`axios`/`WebSocket`, ни чтения `process.env`, ни записи на диск (`fs` не импортируется). Состояние (`ledger`, `live`, `expanded`, `follow`) живёт только в памяти модуля и сбрасывается при старте сессии. Все внешние эффекты идут через объект `$`, предоставленный самим Claude Code (`$.session.usage()`, `$.session.messages()`, `$.ui.log(...)`) — то есть через платформенный API хоста, а не через код мода. Это сильнее, чем просто «не нашёл подозрительных строк»: в файле физически нет импортов, которые могли бы подключить сеть.

## Берём инструмент или логику

**Инструмент — можно ставить, низкий риск.** Дублирует часть встроенного `/usage`/`/cost` (см. [[prompt-cache-control-mod]], где этот же вопрос разбирался для другого мода того же автора), но даёт то, чего встроенные команды не дают: разбивку **внутри одного хода** на системный блок/предыдущие ходы/новое сообщение/thinking/текст/вызов инструмента, а не только итог по ходу. Прямо отвечает на вопрос из другой наводки того же инбокса того же дня (`ai-assistant #121`, «проверить стартовые траты токенов у агента») — вместо того чтобы гадать по пересказам чужих чатов, сколько токенов стоит системный промпт конкретного проекта, можно открыть панель и увидеть долю `system`-блока в первом же ходе. Установка — `npx ...@latest` (исполнение непрочитанного установщика, тот же класс риска, что у `prompt-cache-control-mod`); сам мод, который этот установщик кладёт на диск (`hooks.json`, `turn-inspector.tsx`, `turns.ts`), прочитан и проверен выше.

**Логика — берём одно.** Разделение чисел на «точное из API» и «оценка по эвристике символов на токен», видимое прямо в интерфейсе, — хороший паттерн для любого самодельного инструмента наблюдения: явно помечать прикидку, а не выдавать её за измерение. То же разделение уже встречалось в вики как принцип ([[invariant-vidno-znachit-zapisano]] — самоотчёт не заменяет факт), здесь оно реализовано в интерфейсе одной конкретной панели.

## Что не взято / лиды

- **Лицензия мода не указана** ни в README, ни на недостижимой странице `aitmpl.com` — проверять по корневому `LICENSE` репозитория `claude-code-templates`, если дойдёт до установки (не проверено в этом разборе, не было нужды для вопроса «можно ли ставить»).
- **Раздел с устройством полосы контекста на `aitmpl.com`** (пример «41,9k / 1,0M, 4%») восстановлен только через поисковую выдачу (снимок страницы), не прочитан напрямую — страница недостижима. Детали интерфейса (расположение полосы, цвета) не переносились в вики без прямого чтения.
- **Утверждение «встроен по умолчанию в 2.1.287+»** относится к механизму модов вообще (подтверждено changelog'ом), не к конкретно этому моду — сам `turn-inspector` всегда сторонний и ставится отдельно; формулировка со страницы `aitmpl.com`, где это можно было прочитать двояко, не переносилась без уточнения.
