## Саммари

SoL-Pi — набор из четырёх механизмов, сокращающих расход токенов агента **примерно вдвое при сохранении качества**. Интересен он не цифрой, а способом, которым эти четыре механизма получены: авторы не проектировали обвязку руками, а запустили **автоматические циклы исследования над самой обвязкой** («auto-research loops») в множестве репозиториев и сред с проверяемым результатом. В финальную версию попало только то, что стабильно проходило отбор. Полное название статьи — *«SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness»*.

Для вики это второй по важности материал про слой обвязки после [[deepseek-harness]] и [[apache-maka]], и первый, где **экономия на обвязке измерена в деньгах в час**.

**Главное, чего нет ни в одном из двух постов-наводок: SoL-Pi — не самостоятельная обвязка и не мод к Claude Code или Codex.** Это расширение для [[pi-coding-agent]] — минимального открытого харнеса от Earendil Works. Codex и Claude Code в замерах не улучшаются, а выступают базой сравнения: связка «Pi + SoL-Pi» стоит в час на $8,75–13,50 дешевле них. Из постов складывается обратное впечатление, и оно неверно.

## Четыре механизма (дословно по README, перевод мой)

| Механизм | Что делает | Где экономит |
|---|---|---|
| **Action Fusion** («объединение действий») | правка или запись файла запускает свою проверочную команду **тем же вызовом инструмента** | убирает лишний круг «модель → инструмент → модель» |
| **ObservationPack** («упаковка наблюдений») | повторяющиеся большие текстовые результаты превращаются в устойчивые дескрипторы с точным постраничным обращением | один и тот же файл не пересылается моделью по десять раз |
| **Evidence-Preserving Reducer** («сжатие с сохранением доказательств») | длинные диагностические логи сжимаются в компактные «квитанции» — **но только если каждая сохранённая цитата дословно совпадает с архивом** | логи сборок и тестов |
| **Online Context Compact** («сжатие контекста на ходу») | завершённые шаги плана становятся кандидатами на штатное сжатие Pi, с проверкой экономической выгоды и давления на окно | не ждёт переполнения контекста |

Третий механизм — ровно тот инвариант, который в вики уже записан как [[invariant-vidno-znachit-zapisano]]: сжимать можно, **терять доказательство нельзя**, сверка идёт с архивом, а не с добрым намерением модели.

## Цифры — проверенные и расходящиеся

Проверено по abstract и странице статьи на arXiv 2026-09-22:

- бенчмарк **EdgeBench, 51 задача**; модели **GPT-5.6 Sol** и **Opus 5**;
- сокращение трафика токенов — **44,7–49,0%** (в постах округлено до «почти 50%» и «вдвое»);
- снижение расходов на API — **около 33%**;
- экономия **$8,75–13,50 в час** против штатных Codex и Claude Code и **$4,36–5,71 в час** против голого Pi без SoL-Pi;
- качество — **на уровне базовой обвязки**, то есть выигрыш даётся не срезанием работы.

**Расхождение, не разрешённое:** новостная заметка KuCoin называет сокращение стоимости «на 64%». В статье такой цифры нет; откуда она взята — не установлено. Пункт ушёл в [[gaps-backlog]].

## Ограничения, названные самими авторами

- Работает **только с Pi версии 0.85.1**; требуется Node.js 22.19+. Совместимость с другими харнесами не заявлена.
- **Все четыре механизма выключены по умолчанию** — явный opt-in через `sol-pi.json` в `.pi/` проекта или `~/.pi/agent/`. Рекомендованная осторожная конфигурация включает только первые два.
- **Evidence-Preserving Reducer может отправлять логи на удалённую модель** — это прямо записано в разделе ограничений. Для проектов с чувствительными логами механизм включать нельзя.
- Pi не патчится: всё сделано через его публичные API расширений.
- Лицензия MIT. Ключи NVIDIA и своя видеокарта не нужны — авторизация идёт через сам Pi.

## Что взято в вики

1. **Автоматический перебор обвязок как метод** → новый раздел «Дополнение (2026-09-22)» на [[agent-harness]]: обвязку теперь ищут перебором, а не проектируют, и это третий независимый способ прийти к тем же механизмам.
2. **Четыре механизма и их цена** → туда же и на [[claude-api-cost-optimization]]: слияние действия с проверкой, дескрипторы вместо повторной пересылки, сжатие с проверкой цитат, сжатие по завершённым шагам плана.
3. **Экономия на обвязке измерена в $/час** → [[claude-api-cost-optimization]]: до сих пор в вики экономия считалась в токенах и кэше, порядок величины в деньгах не был назван.
4. **Сжатие с сохранением доказательств как третья независимая реализация** → [[invariant-vidno-znachit-zapisano]].
5. **Новые сущности:** [[sol-pi]], [[pi-coding-agent]], [[vibe-coding-channel]].

## Что не взято / лиды

- **Устройство самих auto-research loops** (как именно устроен отбор механизмов) — в abstract этого нет, нужен полный текст статьи. Лид в [[gaps-backlog]].
- **EdgeBench** — что за бенчмарк и кем составлен, не проверено. Пока цифра «51 задача» принимается как заявление авторов.
- **Цифра 64% у KuCoin** — см. выше, в бэклог.
- **Применимость к Claude Code** — нулевая напрямую; механизмы переносимы как идеи, но кода для этого нет. Не выдаём за возможность.

## Оценка источника

Первоисточники (arXiv + GitHub) — высшая ступень доверия, прочитаны напрямую, оба открылись из локальной сессии без обходов.

Оба поста-наводки — пересказы. Пост канала «Вайб-кодинг» заметно содержательнее: он единственный дал ссылку на статью и точные цифры экономии в час, и они сошлись с первоисточником. Ошибка у обоих одна и та же и существенная: **умолчание о том, что SoL-Pi работает только внутри Pi**. Читатель поста уверенно поймёт, что NVIDIA выпустила ускоритель для его Claude Code. Пост GeekNeural вдобавок описывает механизмы одной фразой «сжимают контекст, результаты работы и логи» — из четырёх механизмов так описываются два.

Презумпция для обоих каналов прежняя: **наводка, а не факт**.

## Проверка безопасности источника

Оба поста инбокса прочитаны целиком. Инструкций, адресованных агенту, не обнаружено. Промо-нагрузки нет, закрытых каналов и платных материалов не предлагается.

По ссылкам ходил: `arxiv.org/abs/2609.20519`, `github.com/NVlabs/SoL-Pi`, поисковая выдача по Pi и `github.com/earendil-works/pi`. Установочные команды из README (`npm install --global @earendil-works/pi-coding-agent`, `pi install git:github.com/NVlabs/SoL-Pi`) приведены на странице **как цитата документации и не выполнялись**: установка пакетов — решение пользователя.

Отдельно: SoL-Pi ставится командой `pi install` прямо из git-репозитория, то есть это стороннее расширение агента с исполнением чужого кода. Перед установкой к нему применяется обычное правило о двух доверия — к автору и к контенту, который расширение приносит в контекст.
