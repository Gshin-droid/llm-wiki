## Саммари

Ярус 2 рутины новостей, следом за сводкой [[novosti-2026-11-10]]. Окно с прошлого снапшота ([[claude-code-changelog-snapshot-2026-11-07]], закрывал до v2.1.319) — две новые версии: **v2.1.321 (09.11.2026)**, синхронная с запуском Claude Fable 5.2 и Claude Mythos 5.2, и **v2.1.322 (10.11.2026)**. Тот же паттерн, что у Fable 5.1 01.09.2026 ([[claude-fable-5-1-launch]]) — релиз модели и релиз CLI синхронизированы.

Важное отличие от предыдущего ингеста: WebSearch по агрегаторам на момент прогона (10.11) ещё **не знал** о Fable 5.2 — один агрегатор прямо писал «не подтверждено Anthropic, возможно слух» (`cometapi.com`), другой — «in testing, coming soon» (`overchat.ai`). Факт подтверждён не пересказами, а прямым WebFetch трёх официальных страниц одновременно (changelog, model overview, release notes/api) — совпадают цифры контекста/цены/даты. Урок для следующих прогонов: при свежем релизе (0–2 дня) агрегаторы систематически отстают от официального changelog, проверка должна идти в официальный источник напрямую, а не только через WebSearch.

## Что взято в вики

1. **Claude Fable 5.2 (`claude-fable-5-2`) — GA с 2026-11-09, дефолт семейства Fable.** Контекст 1M токенов, максимум на выход 128K, thinking — adaptive, всегда включён (как у Fable 5.1, без возможности отключить), эффорт по умолчанию `high`. Reliable knowledge cutoff — июнь 2026 (без изменений относительно всей линейки 5.5/5.2). Статус в таблице моделей — «Active (latest)», retirement — не раньше 09.11.2027.
2. **Цена снижена относительно Fable 5.1: $8/$40 за MTok против $10/$50.** Впервые в линейке Fable цена идёт вниз при смене поколения (у Opus/Sonnet/Haiku 5→5.5 цена тоже снижалась, но у Fable 5→5.1 была без изменений — см. [[claude-fable-5-1-launch]]). Кэш-чтение — своя отдельная ставка 2,5% от входной цены ($0.20/MTok), та же пропорция 0.025×, что у Fable/Mythos 5.1 (у остальной линейки — 5–10%). Fast mode для Fable 5.2 доступна на Claude API по отдельному тарифу $16/$80 за MTok (`speed: "fast"`, без beta-заголовка).
3. **Claude Mythos 5.2 (`claude-mythos-5-2`) — вторая модель тем же релизом, доступ по верификации.** Делит с Fable 5.2 контекст/цену/thinking целиком; доступна только организациям, прошедшим одну из верификационных программ Anthropic (документация называет Cyber Verification Program как пример) — то же ограничение доступа, что у Mythos 5.1 ("Project Glasswing", см. [[claude-fable-5-1-launch]], открытый вопрос оставлен нераскрытым), но теперь программа названа явно, а не кодовым именем.
4. **Три breaking change, новых для этого поколения** (не наследуются от Fable 5.1):
   - **Prefix check enforced для каждого аккаунта без исключений.** Если код правит системный промпт, список инструментов (`tools`) или более раннее сообщение диалога и присылает назад блок размышления (thinking block) — запрос возвращает ошибку 400. Раньше это правило действовало избирательно; на Fable/Mythos 5.2 — всегда.
   - **Computer use только через новый тулсет.** Обе модели принимают компьютерный доступ только версией `computer_toolset_20260801`; запрос со старым `computer_20251124` возвращает 400 на всех платформах кроме Amazon Bedrock.
   - **Advisor tool (бета) ограничен тем же поколением.** Исполнитель (executor) на Fable 5.2/Mythos 5.2 принимает советчиком (advisor) только модель того же поколения — Fable 5.2 или Mythos 5.2; любая другая модель-советчик возвращает 400.
5. **Data retention — то же требование, что у Fable 5.1, подтверждено явно для 5.2.** 30-дневное хранение обязательно, доступ с zero data retention — только по отдельному разрешению Anthropic.
6. **Claude Code v2.1.321 — помимо доступности Fable 5.2 в `/model`, крупный смешанный пакет (Added/Changed, 15 improvements, 74 bug fixes).** Из security-значимого:
   - **Исправлена утечка секретов через MCP OAuth** — *«Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them»*. MCP-сервер, объявивший редирект, мог получить чужой refresh-токен — класс «сервер лжёт о своём адресе», отдельный от уже отслеженных на [[mcp-model-context-protocol]] (tool poisoning/token passthrough/confused deputy), но близкий по духу к token passthrough.
   - **Одиннадцатый узел серии permission-bypass** (вики ведёт с узла 5, 10-04, последний — узел 10, 11-07 см. [[claude-code-changelog-snapshot-2026-11-07]]): *«Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt»* — read-only команда (по определению считающаяся безопасной) проходила мимо песочницы без запроса разрешения. Плюс рядом два смежных фикса той же природы: ошибка в проверке Bash-прав путала папку записи файла; правила запрета (deny) и защита файлов не применялись к файлу, в который пишет `cp`/`mv` при копировании в директорию.
   - **Ослабление, а не фикс — проверка модов (mods) сужена.** Два изменения разом: (1) моды, которые Claude пишет сам, включаются **без вопроса** в auto и bypass режимах, даже при управляемых запретах `allowUnsandboxedCommands: false` или `allowManagedDomainsOnly` — но не загружаются в режиме `dontAsk`; (2) собственные вызовы инструментов мода (`$.tool.call`, `$.mcp.call`) не поднимают запрос разрешения даже при собственных правилах `ask` пользователя или в режимах `dontAsk`/`-p` — правила запрета (`deny`) и политика организации всё ещё применяются. Формулировка changelog сама называет это ослаблением конкретных заборов (`allowManagedDomainsOnly` — явно именно забор, не стена, см. [[zabor-i-stena-prava-agenta]]), а не фиксом дыры.
   - Малое, но заметное: gateway-апстримы Bedrock/Vertex/Foundry теперь игнорируют переменные `ANTHROPIC_*_BASE_URL` из окружения самого gateway (нужен явный `base_url` на апстриме) — сужает ещё один путь, которым посторонний адрес мог тихо подменить эндпоинт, на уровне gateway, а не клиента (ср. правило проверки `ANTHROPIC_BASE_URL` на [[ai-security-by-design]], но там — про клиентскую конфигурацию, тут — про сам gateway).
7. **Claude Code v2.1.322 (10.11.2026) — одна строка.** Fast mode теперь доступен на Vertex AI (регионы global/us/eu) с откатом на обычную скорость, если конкретный запрос Vertex не подтверждает fast mode.

## Берём инструмент или логику

Инструмент — эта вики не ведётся через API напрямую, модель как сервис не "ставится"; фиксируем факт релиза и параметры для будущего выбора модели в собственных задачах (`claude-code-practices`, выбор ступени "модель + effort"). Логика — два переносимых урока: (1) при свежем (0–2 дня) релизе модели проверять официальный changelog/overview прямым WebFetch, не только WebSearch по агрегаторам — агрегаторы отстают на день-два даже от крупных релизов Anthropic; (2) читать changelog не только на "Fixed"/security, но и на формулировки вида "Changed... to turn on without asking" — там прячутся осознанные ослабления заборов, которые легко пропустить, если искать только слово "fix".
