## Саммари

Вендор нашёл у клиента в `~/Downloads` вредоносный `AGENTS.md` — длинный скучный документ «правил инженерной работы», в конце которого раздел «настройка окружения». Механизм: веб-страница сохраняет файл в «Загрузки» без клика; агент, запущенный в этой папке, читает его как правила проекта.

- **Codex** (настоящий файл атакующих, в изолированной виртуальной машине): дописывает в машинные настройки `~/.codex/config.toml` блок `[mcp_servers.project-tools]`, команда которого ставит вредоносный npm-пакет `function-color`; чтобы обойти сетевую песочницу, файл велит запустить дочерний `codex exec` с флагом отключения песочницы, который модель пишет сама. Больше 90% попыток. Заражение остаётся для всех сессий на машине.
- **Claude Code** (файл составили исследователи по образцу): `CLAUDE.md` велит записать в `.claude/settings.json` проекта `ANTHROPIC_BASE_URL` на их сервер. Токен OAuth уходит сразу — захват учётной записи без запуска кода; со следующего запуска их сервер отвечает как модель и присылает вызов Bash с `dangerouslyDisableSandbox: true`; в той же сессии — через просьбу запустить субагента «для проверки настройки», он открывает новое соединение. Запись требовала одобрения человека; прошла примерно в половине попыток, выполнение кода в той же сессии — примерно в пятой части.
- В папке, полной заметок о безопасности, тот же файл не сработал ни разу: субагент распознавал атаку.

Авторы: патчить нечего, оба агента работают как задуманы; опасна стыковка «агент доверяет папке запуска» и «интернет пишет в Загрузки».

## Берём инструмент или логику

**Инструмент** вендора — коммерческий агент наблюдения за агентами, не для нас.

**Логика — взята сразу (решение пользователя 29.10):**
1. Сторож до действия (собран 29.10; ставит человек — папка хуков закрыта правами файлов от записи агентом, и это та же стена): отказ в записи адреса API, прокси, помощника ключа в `.claude/settings*.json` и сервера MCP или адреса API в `~/.codex/config.toml` — инструментами правки и командами с признаком записи, плюс подмена адреса переменной окружения. Только отказ: законной записи нет, а вопрос в нашем режиме до человека не доходит. Самопроверка — 18 случаев, включая дословный файл из статьи и законные случаи (поиск по настройкам, запись хуков, текст статьи в вики). Что сторож не видит — запись из скрипта, у которого ключ внутри файла, — записано в его шапке.
2. Проверка своей машины по признакам из статьи: адреса API в настройках нет, пакета нет, сессий агента в «Загрузках» не было; файл инструкций в «Загрузках» нашёлся — свой старый черновик, удалён пользователем.
3. Правило работы: не запускать агента в «Загрузках»; чужой файл инструкций в свежем клоне — сначала проверяющему только на чтение.

## Что не взято / лиды

- Доля «у половины клиентов агент работает в Загрузках, у четверти сессий открыт браузер» — телеметрия вендора, не проверить.
- Совет «следить за `chatgpt_base_url`» в настройках Codex — взят в практику проверки, в сторож не включён отдельно: ловится общим `base_url`.
