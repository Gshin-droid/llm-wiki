## Саммари

Инбокс-пересказ (Telegram-форвард) заявил, что в Claude Code «добавили новую команду `/insights`», которая «анализирует историю сообщений за последний месяц» и «даёт советы по оптимизации рабочего процесса». Формулировка неточна в деталях и не проверяема как факт «новизны» — при сверке по официальной документации выяснилось, что `/insights` уже упоминалась в CHANGELOG на несколько версий раньше (см. ниже), а порог отбора — не календарный месяц, а количество сессий. Страница написана по официальному первоисточнику, инбокс-пост зафиксирован только как наводка на тему.

**Что делает `/insights` (дословно по официальной документации):**
- Анализирует **сессии Claude Code на этой машине**, а не диалоги на claude.ai/других устройствах.
- За один запуск разбирает **до 200 сессий**, которые ещё не видел, и пропускает совсем короткие; если часть сессий не попала в разбор, заголовок отчёта показывает оба числа — например, `200 sessions (412 total)`.
- Пишет HTML-отчёт в `~/.claude/usage-data/report.html`, каждый прогон сохраняет отдельную копию с таймстампом рядом (старые не перезатираются) — до плановой чистки: файлы старше `cleanupPeriodDays` (по умолчанию 30 дней) удаляются при старте, как и остальные данные сессий.
- Отчёт покрывает: над чем вы работали (кластеризация по темам), точки трения (недопонятые запросы, багованный код) и советы по более эффективному использованию Claude Code.
- Работает **на любом плане и с любым провайдером** (Bedrock/Vertex/Foundry — не проверено отдельно, но документация не делает исключений); прогон идёт через тот же провайдер/аккаунт, что обычные сессии, и токены считаются как обычный расход.

**Ключевое отличие от `/usage`**, прямо названное документацией: `/usage` считает **сколько потрачено токенов**, `/insights` — **как именно вы работаете** (что делали, где спотыкались, что улучшить в привычках). Разные оси одной и той же идеи «посмотреть на себя со стороны» — не конкурируют, а дополняют друг друга.

Более раннего анонса самой команды в файле не нашлось (виден диапазон примерно с 2.1.238 и новее — это могло быть ограничением инструмента чтения, а не доказательством отсутствия записи). **Итог: `/insights` существует минимум с 2.1.239, точная версия/дата первого появления не установлена** — оставлено открытым вопросом, не додумано.
- Утверждение стороннего блога (`vincentqiao.com`), что анализ ведётся «with Claude Opus» — не подтверждено официальной документацией, не взято на страницу.
