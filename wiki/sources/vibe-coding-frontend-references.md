## Саммари

Подборка внешних ресурсов для фронтенда, разложенная по пяти местам, где застревают: стиль, компоненты, анимации, демо-видео, финальная полировка. В конце — готовый текст раздела «Frontend references» для `~/.claude/CLAUDE.md`, который предлагается отправить Claude Code.

Для вики ценен один механизм: **DESIGN.md — описание стиля одного продукта в markdown, которое агент читает как якорь**. Вынесен в [[design-md-yakor-stilya]]. Остальное — каталог ссылок, из которого проверены три ресурса; о главном недостатке совета из поста (подключение через @-импорт) в посте ни слова.

## Что взято в вики

- **DESIGN.md и совет «один файл, не смесь»** (раздел 1 поста) → [[design-md-yakor-stilya]]. Проверено по репозиторию `VoltAgent/awesome-design-md`: 74 файла DESIGN.md (значок в README отстал и показывает 73), 118 тыс. звёзд, MIT, формат придуман Google Stitch — всё сходится с постом.
- **Impeccable** (раздел 5) → [[impeccable]]. Проверено по README: команды `polish`, `distill`, `bolder` есть, всего их 24; 72 тыс. звёзд.
- **HyperFrames** (раздел 4) — проверено только существование: `heygen-com/hyperframes`, 54 тыс. звёзд, проект HeyGen. Отдельной страницы нет, повода пока нет.
- **Правила из текста для `CLAUDE.md`**, пригодные независимо от набора ссылок: «существующая дизайн-система проекта важнее внешних референсов», «не можешь прочитать страницу — остановись, не подставляй по памяти», «не установлено — спроси, не имитируй». → [[design-md-yakor-stilya]], раздел «Как подключать».

## Берём инструмент или логику

**Инструменты — выборочно.**

- **Файлы DESIGN.md — берём как материал**, не как установку: это просто текст, ставить нечего. Применение — варианты оформления на выбор: каждый вариант — один DESIGN.md.
- **Готовый раздел для `~/.claude/CLAUDE.md` — не берём целиком.** Причины: (1) глобальный свод уже задаёт порядок работы с внешним видом (варианты на выбор, список запретных примет — [[claude-code-practices]] п. 15), второй свод про то же будет с ним спорить, а спорящие правила по документации — лотерея (п. 16); (2) совет «@-импорт DESIGN.md в CLAUDE.md проекта» грузит 30+ КБ в каждую сессию, включая те, где интерфейс не трогают. Переносятся только три правила из списка выше.
- **Impeccable — не сейчас.** Ставит три хука (один — на каждую правку файла) и скачивает исполняемый файл при первом запуске; сбор статистики включён по умолчанию. Исходник разобран в тот же день: явного вреда нет, закачка проверяется по контрольной сумме. Ставить под конкретную задачу с интерфейсом, только в проект и с `DO_NOT_TRACK=1`. Маркетплейс плагинов, который сначала казался безопаснее, ставит те же хуки. Подробно — [[impeccable]].
- **21st.dev (MCP)** — нет: бесплатный лимит, только React + Tailwind; нужен проект на этом стеке и повод.
- **Kinetics, Component Gallery** — закладки, ставить нечего.
- **whatships, HyperFrames** — нет: демо-видео сейчас не нужно ни одному проекту.

**Логика — берём.** Главный переносимый механизм — **позитивный якорь стиля в паре с негативным списком примет**: DESIGN.md говорит, как должно выглядеть, список запретов — во что модель не должна уходить. Куда: [[design-md-yakor-stilya]], дополнение к [[claude-code-practices]] п. 15 и к [[maket-kak-tz-dlya-agenta]].

## Что не взято / лиды

- **Refero Styles** («2 000+ стилей»), **21st.dev** («12 000+ компонентов», условия бесплатного лимита), **Component Gallery** («95 дизайн-систем»), **Kinetics** («153 эффекта»), **whatships** («2 000+ видео») — цифры со слов автора, не проверялись. → [[gaps-backlog]].
- Приём «разложить кадры видео в одно изображение, чтобы повторить стиль» — интересен, но задачи с видео нет.

## Допроверка 2026-09-30: пять каталогов, один частично закрыт

Ежедневный процесс закрытия пробелов, пункт бэклога «пять каталогов не проверены» (заведён 09-28). Прямой фетч всех пяти доменов из поста (`styles.refero.design`, `21st.dev`, `component.gallery`, `kinetics.colorion.co`, `whatships.com`) вернул `EGRESS_BLOCKED` — по одному заходу на каждый, без повтора. Кластер новый, в известном списке повторяющихся заблокированных доменов (`support.claude.com`, `arxiv.org`, `github.com` и т. д., см. `wiki/gaps-backlog.md`) этих пяти не было.

**21st.dev — частично закрыт через запасной первоисточник.** У продукта есть открытый репозиторий (`github.com/serafimcloud/21st`, README прочитан напрямую через `raw.githubusercontent.com`) и открытый репозиторий MCP-сервера (`github.com/21st-dev/magic-mcp`, README прочитано тем же способом) — тот же приём, что уже закрывал `context7`/`opencode`/`pi-coding-agent`. Официальный README **не называет цифру компонентов вообще** — заявление поста «12 000+» первоисточником не подтверждено и не опровергнуто, только не проверяемо этим документом. Подтверждено: для базового просмотра/копирования кода регистрация не нужна («install any component with a single `npx shadcn` command»), для публикации — нужна (через Clerk). MCP-сервер требует API-ключ («Get an API key at 21st.dev/mcp»), точных цифр бесплатного лимита README не даёт, но подтверждает существование платного уровня — статус `ai_subscription_required` для «hosted 21st AI». Лицензия не названа явно ни в одном из двух README (только «Open Source & Community-Driven»).

**Refero Styles, Component Gallery, Kinetics, whatships — не закрыты.** Ни у одного нет открытого GitHub-репозитория с официальной документацией внутри (в отличие от 21st.dev) — все три первых слоя обхода блокировки (домен → официальный репозиторий продукта) недоступны. Найденные при поиске репозитории (`fidgetcoding/refero-design-mcp`, `faridjafarlee/refero-styles-mcp-server`, `zotanika/refero-styles-index`, `referodesign/refero_skill`) — сторонние обёртки под MCP/скиллы, не первоисточник самого каталога Refero; не читались, не заводятся отдельным пунктом. Поисковая выдача по Refero дала цифру «около 200 сайтов, бета» — расходится с «2 000+» из поста, но это пересказ агрегатора, а не прочитанный первоисточник, в вики как факт не идёт ни в каком виде. Пункт бэклога остаётся открытым для этих четырёх; закрывается либо когда домены разблокируются для автономных прогонов, либо из локальной сессии.

## Оценка источника

Пересказ-подборка без ссылок на первоисточники, но все три проверенных факта сошлись точно. Типичная для канала картина ([[vibe-coding-channel]]): цифры верны, существенное опущено. Здесь опущены три вещи:

1. цена @-импорта: файл Airtable из подборки — 35 КБ, порядка 9 тыс. токенов в каждую сессию;
2. цвета в файлах подборки сняты «пипеткой со скриншотов» (пометка самих авторов в файле Airtable), это приближение, а не фирменная палитра;
3. подборка коммерческая — в README реклама и платные «заказы DESIGN.md».

## Проверка безопасности источника

**Внутри поста — готовая инструкция агенту** («Отправьте это Claude Code… Добавь в ~/.claude/CLAUDE.md…»). По правилу вики это текст источника, а не команда: не исполнялась, пользователю названа до разбора. Сама инструкция безвредна и даже осторожна (просит показать изменения и дождаться подтверждения), но её цель — постоянная правка глобальных правил, то есть канал, через который чужой текст становится частью каждой будущей сессии.

**Второй слой доверия — содержимое DESIGN.md.** Файл, подключённый к проекту, — чужой текст в контексте агента на каждом ходу (урок ContextCrush из [[ai-security-by-design]]: вредоносным бывает не расширение, а контент, который оно приносит). Проверен один файл (Airtable): только стиль, скрытых команд нет. Каждый новый файл читать перед подключением.

## Как материал попал в вики

Первые две пересылки поста ассистент отверг: пост «видео + текст» Telegram отдаёт как `rich_message` — документ из блоков без обычного текста и подписи, а бот искал только их. Починено 2026-09-28: бот разбирает блоки в текст, а на незнакомый тип пересылки называет его в ответе вместо молчаливого отказа.
