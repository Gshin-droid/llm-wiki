## Саммари

Плановый прогон разведчика новостей, ярус 2 следом за сводкой [[novosti-2026-10-10]]. С предыдущего снапшота ([[claude-code-changelog-snapshot-2026-10-07]], покрывал до v2.1.292) вышло главное событие окна — **7 октября 2026 Anthropic выпустила Claude Haiku 5.5**, новую дефолтную модель линейки Haiku, одновременно с Claude Code v2.1.293, сделавшей её дефолтом Haiku в самом инструменте. Тот же паттерн синхронного релиза модели и релиза CLI, что уже был у Opus 5 ([[claude-opus-5-launch]]) и Fable 5.1 ([[claude-fable-5-1-launch]]) — но на этот раз на нижней ступени линейки, а не на верхней.

Отдельно от модели — в версиях 2.1.294–2.1.296 найдены: security-фикс нового для этой вики класса (обход судейства инструкционных хуков, а не permission-анализатора путей) и снижение цены чтения кэша Sonnet 5.5 вдвое.

## Что взято в вики

1. **Claude Haiku 5.5 (`claude-haiku-5-5`) — GA с 2026-10-07.** Контекст вырос до 1M токенов — впервые для модели линейки Haiku в этой вики (прежде длинный контекст был только у Sonnet/Opus/Fable). Claude Code 2.1.293 сделала её дефолтной моделью Haiku внутри `/model`-picker синхронно с релизом.
2. **Claude Code 2.1.294 — фикс обхода блокирующих инструкционных хуков.** Дословно из официального `CHANGELOG.md`: *"Fixed `prompt` and `agent` hooks written as instructions allowing actions they should block"*, плюс отдельное улучшение судейства тех же хуков на `Stop`/`SubagentStop`: *"Improved how `prompt` hooks on Stop and SubagentStop written as instructions are judged, so Claude is less likely to stop early"*. Класс отличается от всех шести предыдущих узлов серии bypass-находок в [[ai-security-by-design]] — там дыра была в permission-анализаторе и форме записи файлового пути; здесь хук не код, а текстовое правило, которое отдельная модель-судья интерпретирует заново на каждом срабатывании, и эта интерпретация могла расходиться с тем, что правило должно было запретить.
3. **Claude Code 2.1.296 — цена чтения кэша Sonnet 5.5 снижена с $0.20 до $0.10 за млн токенов.** Базовая цена входа/выхода модели не изменилась. Прямое дополнение к чеклисту [[claude-api-cost-optimization]] — не новый шаг, а пересчёт отдачи уже применённого шага 2 (prompt caching) для конкретной модели.
4. **Claude Code 2.1.295 — `onFailure: "block"` для command/HTTP-хуков.** Хук, который не запустился, завис по таймауту или завершился неожиданным кодом, теперь блокирует действие, а не пропускает его молча — страхует именно тот класс отказа, который делает хуки ненадёжным механизмом контроля (см. находку 2 выше и общий вывод в [[ai-security-by-design]] про код vs текстовое правило).
5. **Claude Code 2.1.295 — Program Status Protocol (OSC 7501).** Терминал может показать статус Claude Code (работает/ждёт/закончил) без постоянного опроса — мелкая, но практическая эргономика для тех, кто держит несколько сессий параллельно (тема раздела «Контекстное окно и сессии» на [[claude-code]]).

## Что не взято / лиды

- **2.1.293 — остальные пункты** (`agentType` в `subagentStatusLine`, `isDeferred` в `$.tool.register` для модов, интервал проверки обновлений скиллов claude.ai 10→40 минут, фиксы Claude Tag/Code Review) — API для разработчиков модов и косметика, без прямого веса для практики этой вики.
- **2.1.295 — остальные пункты** (`CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS`, преload до 32 скиллов на субагента, предел описаний MCP-тулов 16384 символов, разные фиксы MCP/plugins/Bash/UI/фоновых сессий) — рутинные ограничения и багфиксы, не меняющие практику использования.
- **2.1.296 — остальные пункты** (`code`-ключ в `managed.policies[]` gateway, `autoCompactWindow` в frontmatter субагента, `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`, предел описаний MCP 2048→4096 символов, фикс managed-settings-хуков) — организационные/инфраструктурные, без веса для соло-использования, которым ведётся эта вики.
- **Полный текст официального анонса Claude Haiku 5.5** (цена, ограничения, сравнение с Haiku 5) — страница `anthropic.com/news` при WebFetch отдала только заголовок в общем списке новостей, не полный текст анонса; цена явно не подтверждена этим прогоном — кандидат в `wiki/gaps-backlog.md`, если понадобится точная цифра.

## Берём инструмент или логику

**Инструмент.** Claude Code уже стоит и ведёт эту вику — Haiku 5.5 доступна автоматически как дефолт линейки Haiku, отдельного решения "ставить/не ставить" не требуется.

**Логика.** Два переносимых урока: (1) фикс 2.1.294 — инструкционные хуки (текстовое правило + модель-судья) не эквивалентны по надёжности коду (`settings.json` allow/deny) для блокирующей логики; там, где нужна гарантия, а не вероятность, правило стоит держать в коде, а не в тексте хука — прямое применение принципа «Доменные примитивы»/«Эшелонированная защита» из [[ai-security-by-design]], подтверждённое теперь конкретным багом, не только общим рассуждением; (2) снижение цены кэша Sonnet 5.5 — чисто арифметический эффект, применимый сразу и без действий тому, кто уже использует кэш по чеклисту [[claude-api-cost-optimization]].
