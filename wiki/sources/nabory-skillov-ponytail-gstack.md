## Саммари

Практики советовали четыре набора скиллов: mattpocock — планирование и ревью, superpowers — автономность агента, gstack — «похож, с упором на размышление над продуктом», ponytail — «чтобы модель меньше думала и экономила токены». Совместимость наборов друг с другом в обсуждении названа неизвестной. README приложены только для ponytail и gstack; о mattpocock и superpowers в материале одна фраза пересказа.

Разобран вместе с пользователем. Чтение 90 тыс. знаков отдано агенту-проверяющему (Haiku, только чтение), ключевые утверждения сверены по строкам файла. Главная ценность материала оказалась не в обзоре наборов, а в сверке **собственной установки**: два из четырёх наборов стоят на машине пользователя, и сверка нашла устаревшую версию одного и мёртвую копию другого.

## Пересказ против первоисточника

Пересказ обсуждения расходится с README в главном пункте про ponytail. Пересказ: набор, чтобы модель «меньше думала и экономила токены». README: «правило никогда не было "меньше токенов"… экономия и скорость — побочный эффект»; цель — писать только нужное и никогда не урезать проверку входных данных, обработку ошибок, безопасность и доступность. Пример правила вики для сводок обсуждений: факт берётся из первоисточника, пересказ — только наводка.

Совет «режим размышлений low ради экономии» — мнение участника, в README обоих наборов его нет. У вики на этот счёт есть замер: [[bughunt-bench-sonnet-5-5]] (ступень — пара «модель + уровень усилий», а не модель).

## Берём инструмент или логику

- **ponytail — инструмент, уже стоит; обновлён 4.8.4 → 5.3.2** (решение пользователя 19.10). Перед первым запуском новый код прочитан агентом-проверяющим (Sonnet, только чтение): сетевой вызов один — вебхук доски задач, при пустом адресе (по умолчанию) не срабатывает; ключей из окружения не читает; `eval` нет. Правило «объяснение не больше трёх строк» из 4.8.4 в 5.3.2 убрано — вместо него «закончить ответ одной-двумя строками о пропущенном и рисках». Это снимает прежний спор плагина с правилом пользователя «объяснения запрошены раз и навсегда» и совпадает с его же правилом «неподтверждённое помечать».
- **gstack — инструмент не ставим** (решение пользователя 19.10): дублирует уже стоящие superpowers и mattpocock, дорог в обслуживании (Bun, Node, Chromium, глобальные хуки, правка `CLAUDE.md`), внешние проверки кода второй моделью включены по умолчанию — код уходит наружу без отдельного решения, что противоречит правилу о жёлтом материале.
- **gstack — логика: журнал исходящих отправок** (`egress.jsonl` — строка на каждую отправку кода или текста наружу). Переносится в шлюз дешёвых моделей как часть дела о маскировке: журнал проверяет, что наружу ничего не ушло без маски. Это то же правило, что [[invariant-vidno-znachit-zapisano]], применённое к утечке.

## Что нашла сверка установки (19.10)

- ponytail стоял версии 4.8.4 при актуальной 5.3.2 (16.10) — отставание на крупную версию, обновлено.
- superpowers был установлен дважды: рабочая копия на всю машину и вторая, привязанная к папке проекта, которой больше нет. Мёртвая копия удалена штатной командой `claude plugin uninstall --scope project`.

## Что не взято / лиды

- Заявленные цифры ponytail (−53% кода, −45% токенов, 98% рискованной логики с тестом) и gstack («810× темпа 2013 года») — замеры авторов, не проверены. Методика ponytail лежит в его репозитории (`benchmarks/results/2026-10-07-agentic.md`), не открывалась.
- Скиллы gstack `/careful`, `/freeze`, `/guard` (режимы «осторожно» и «заморозить файлы») — не разобраны; у вики похожую роль играют сторожа.

## Оценка источника

Пересказ — наводка невысокой точности: в части про ponytail противоречит первоисточнику. README — первоисточники авторов, с маркетингом («zero bugs, zero CVEs») и непроверенными цифрами, но с подробным и честным описанием установки, удаления, телеметрии и сетевых отправок (gstack).

## Проверка безопасности источника

В README есть тексты, обращённые к агенту: «вставь это в Claude, он сделает остальное», «добавь раздел gstack в CLAUDE.md и запрети другие браузерные инструменты», «закоммить `.claude/` и `CLAUDE.md`» (gstack); «попроси агента установить SKILL.md как навык» (ponytail). Ничего не выполнено: это данные, а не команды. Код ponytail 5.3.2 перед включением прочитан отдельно (выше).
