## Саммари

Инбокс — пересказ видео канала GeekNeural без единой ссылки: «клонирование голоса, озвучка, перевод и дубляж видео, расшифровка, многоголосые аудиокниги из EPUB/PDF; 16 моделей генерации, 11 моделей распознавания, 646 языков». Имя без ссылки оказалось неоднозначным — поиск нашёл два разных репозитория с похожим названием (`msrbuilds/voice-studio` и `debpalash/VoiceStudio`); по набору функций (клонирование, дизайн голоса, дубляж, транскрибация, аудиокниги, AGPL-3.0, локальный API) совпадает именно `debpalash/VoiceStudio` — он и есть первоисточник наводки.

Проект крупный: около 98.8k звёзд на GitHub, кроссплатформенный (stable: macOS Apple Silicon, Windows 10/11 x64, Linux x64, Docker; preview: Android/iOS; experimental: Windows ARM). Движок по умолчанию — на базе `k2-fsa/OmniVoice`, плюс десятки дополнительных engine в Model Manager (whisper.cpp для ASR, CosyVoice GGUF для TTS и другие), каждый со своей лицензией, которую показывает сам Model Manager.

## Что взято в вики

1. **Большинство возможностей наводки подтвердилось первоисточником**: клонирование голоса по короткой записи, дизайн голоса по текстовому описанию, озвучка и дубляж видео с таймингом, диктовка и транскрибация (включая плавающий виджет), аудиокниги и пакетная генерация с очередями, автоматизация через локальный API/MCP/рецепты/отслеживание папок. 646 языков — подтверждено README.
2. **Счёт моделей (16 генерации, 11 распознавания) первоисточником не подтверждён — третий случай неточности у GeekNeural.** README называет только «dozens» дополнительных движков без точного числа ни для генерации, ни для распознавания; официальная `docs/speech-platform.md` тоже не называет этих цифр. Дополнение на [[geekneural]]: третий зафиксированный случай, когда канал подаёт цифру увереннее, чем позволяет первоисточник (после подмены метрики на [[sepia]] и неполного описания механизма на [[sol-pi]]) — числа каналa не переносятся в вики без первоисточника, независимо от того, насколько уверенно они звучат.
3. **MCP-сервер со явно суженным объёмом прав — контрастный пример к [[strata]].** `docs/speech-platform.md`: MCP-транспорты (Streamable HTTP на `:3900/mcp/`, stdio) дают агенту «file transcription or speech tools», но текст прямо отрицает удалённое управление главной функцией десктоп-приложения — «No interface can turn on the desktop app's microphone remotely», команды `start`/`stop`/`toggle` устарели и только печатают объяснение. Та же архитектурная развилка «агент как администратор локальной службы», что в [[strata]] (установка/старт/стоп движка целиком через MCP) — но VoiceStudio выбрала узкий список инструментов там, где Strata дала широкий. Дополнение на [[zabor-i-stena-prava-agenta]]: не все вендоры одинаково решают этот открытый вопрос — есть и осознанно суженный вариант.
4. **Локальный API — OpenAI-совместимый эндпоинт распознавания**, не весь набор функций: `POST 127.0.0.1:3900/v1/audio/transcriptions` (порт — переменная `OMNIVOICE_PORT`), WebSocket для потокового текста на том же порту. Не Anthropic-совместимый, в отличие от Strata.

## Берём инструмент или логику

**Инструмент — не ставим этим прогоном.** Нет собственной задачи локальной озвучки/дубляжа/аудиокниг сейчас; AGPL-3.0 (а не MIT/Apache, как у большинства уже стоящих инструментов) требует внимания при встраивании в чужой код — решение откладывается до появления конкретной задачи, не автономно.

**Логика — берём:**
- Третья точка данных о надёжности GeekNeural как канала-наводки — см. п. 2 выше, дополнение на [[geekneural]].
- Контраст объёма MCP-прав (широкий у Strata, узкий у VoiceStudio) — конкретный пример того, что ширина доступа агента к локальной службе — решение каждого вендора отдельно, не технологическая неизбежность; дополнение на [[zabor-i-stena-prava-agenta]].
- Связь с доменом ASR вики: VoiceStudio использует `whisper.cpp` как один из опциональных движков распознавания, то есть Whisper, а не специализированный под русский [[gigaam]] — та же развилка качества/языка, что уже разобрана на [[gigaam-whisperx-repo-review]], если понадобится озвучка на русском.

## Что не взято / лиды

- Точное число встроенных моделей генерации/распознавания — не подтверждено ни README, ни `docs/speech-platform.md`; в бэклог не заводим, вопрос не критичен без собственной задачи.
- Расхождение числа звёзд между источниками поисковой выдачи (18 697 против «более 50 000») не разрешено прямым просмотром GitHub (сетевой первоисточник недостижим в этом прогоне) — цифра 98.8k взята из сводки поиска как наиболее вероятная, с пометкой неопределённости.
- Полный список MCP-инструментов и их параметров — `docs/speech-platform.md` не приводит; если понадобится предметно, читать исходники MCP-сервера отдельно.

## Оценка источника

README и официальная страница `docs/speech-platform.md` — верх иерархии доверия, но доступ к ним в этом прогоне был не прямым просмотром репозитория, а через WebFetch; числа звёзд и часть деталей восстановлены по совпадению нескольких независимых вторичных упоминаний (поисковая выдача), с явной пометкой неопределённости там, где источники расходятся. Канал-наводка (GeekNeural) — уже с историей неточностей на двух предыдущих материалах, подход «проверять каждую цифру» подтвердил себя снова.
