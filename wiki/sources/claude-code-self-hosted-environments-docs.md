## Саммари
Self-hosted environment — способ прогонять облачные сессии Claude Code (те, что стартуют не с машины разработчика: claude.ai, мобильное/десктоп-приложение, `claude --cloud`, scheduled routines) на инфраструктуре организации вместо managed-инфраструктуры Anthropic. Публичная бета Team/Enterprise, выключено по умолчанию.

**Три сущности:** **Environment** — именованное назначение, создаётся в admin settings, группирует раннеров. **Runner** — процесс на хосте организации, аналог self-hosted CI-раннера: регистрируется в environment по общему секрету ("environment key", разово показывается при создании, живёт 365 дней), опрашивает очередь, клонирует репозиторий, поднимает дочерний процесс Claude Code. **Session** — одна задача разработчика.

**Путь сессии:** пользователь выбирает environment в пикере на старте облачной сессии → control plane Anthropic кладёт сессию в очередь environment → свободный раннер забирает лизом, клонирует репозиторий (git-креды раннера, не Anthropic), поднимает дочерний процесс → тот стримит события по HTTPS, опрос раннера параллельно служит heartbeat → если раннер не опрашивал ~60 сек, сессия переоткладывается другому раннеру.

**Раннер обслуживает одного пользователя за раз** — первая забранная сессия "запирает" раннера на аккаунт этого пользователя до исчерпания активных сессий; так исключается смешивание чужого чекаута кода между пользователями без необходимости чистить диск между сессиями. По умолчанию (`--drain-grace-sec 0`) раннер завершается сразу после исчерпания активных сессий — оркестратор (Kubernetes и т.п.) поднимает его заново с чистым диском для любого следующего пользователя. `--retire-at <epoch>` — для инфраструктуры, убивающей хост без сигнала в известное время (spot-инстансы, sandbox lifetime cap): раннер сам освобождает активные сессии до убийства вместо тихой потери работы.

**Сеть — только исходящие соединения, ни одного входящего от Anthropic**: control-plane опрос и стрим событий → `api.anthropic.com`; git → git-хост организации (креды раннера, либо опциональный Anthropic git proxy через `api.anthropic.com`); инференс модели — тоже `api.anthropic.com`, аутентификация session-scoped OAuth-токеном, из-за чего инференс **нельзя** прогнать через Bedrock/GCP Agent Platform/Microsoft Foundry/LLM gateway даже в self-hosted окружении (это отдельная от исполнения сессии часть архитектуры). Корпоративные egress-прокси поддержаны через стандартные `HTTPS_PROXY`/`NO_PROXY`.

**Что остаётся на инфраструктуре организации:** чекаут репозитория, build-артефакты, секреты, файлы, созданные/изменённые сессией. **Что уходит к Anthropic в любом случае:** сам диалог — промпты, ответы, результаты инструментов — для инференса; транскрипт хранится Anthropic, чтобы сессию можно было продолжить с другой поверхности.

**Ограничения:** недоступно с Zero Data Retention; Claude Tag/Claude Security/Code Review-сессии пока не маршрутизируются в self-hosted; репозитории — только GitHub; биллинг — как у обычных облачных сессий, отдельного тарифа нет.

**Быстрый старт (quickstart):** guided setup одной командой (`claude self-hosted-runner setup`, интерактивная сессия сама создаёт environment и пишет cheat sheet) либо вручную: создать environment → скопировать секрет → записать в файл с `umask 077` → `claude self-hosted-runner --environment-secret-file ... --base-dir ...` → проверить статус "Healthy" в admin UI → выбрать environment в пикере при старте сессии. Требования к хосту: Linux/macOS (не Windows — через Linux-контейнер), Claude Code v2.1.224+, git 2.24+, синхронизированные часы (расхождение >5 мин ломает аутентификацию). Слать сообщение уже идущей сессии с любой другой авторизованной машины: `claude -p "текст" --cloud <session-id>`.

## Ключевые тезисы (для быстрого сканирования)
- Три сущности: environment (группа раннеров) / runner (процесс на инфраструктуре организации) / session (задача).
- Раннер запирается на одного пользователя до исчерпания его активных сессий — изоляция чекаутов без очистки диска между сессиями вручную.
- Сеть только исходящая: ни одного входящего соединения от Anthropic в сеть организации.
- Инференс модели остаётся на `api.anthropic.com` даже в self-hosted — нельзя завести через Bedrock/GCP/Foundry/LLM gateway; self-hosting меняет только *где исполняется сессия*, не архитектуру инференса.
- Бета Team/Enterprise, выключено по умолчанию, несовместимо с Zero Data Retention.
