## Саммари

Плановый прогон разведчика новостей. С предыдущего снапшота ([[claude-code-changelog-snapshot-2026-08-31]], покрывал до v2.1.251, и [[mcp-roadmap-2026-08-22]] от 09-01) вышло главное событие окна — **1 сентября 2026 Anthropic выпустила Claude Fable 5.1**, преемника Claude Fable 5, одновременно с Claude Code v2.1.257, сделавшей её доступной как модель по умолчанию внутри семейства Fable. Тот же паттерн, что и с Opus 5 24.07.2026 ([[claude-opus-5-launch]]) — релиз модели и релиз CLI синхронизированы, но масштаб меньше: не смена дефолтной модели инструмента (им остаётся Opus 5), а обновление верхней ступени — модели для "самых тяжёлых/длинных автономных задач", уже описанной на [[claude-code]] без версии.

**Независимое подтверждение из системного промпта самой этой сессии** — список актуальных моделей автономного прогона называет `claude-fable-5-1` ("Fable 5.1: 'claude-fable-5-1'") как самую свежую в семействе Fable, до этого прогона в вики не зафиксированную под этим именем. Тот же приём сверки, что уже использовался для дефолта Dynamic Workflows medium/<15 ([[claude-opus-5-launch]]) — редкий случай, когда факт из документации проверяется напрямую поведением/конфигурацией собственной сессии, а не только внешним источником.

## Что взято в вики

1. **Claude Fable 5.1 (`claude-fable-5-1`) — GA с 2026-09-01.** Цена не изменилась относительно Fable 5: $10/$50 за MTok. Контекст 1M токенов, максимум на выход 128k, thinking — **adaptive и всегда включён** (Fable — уже вторая модель после Opus 5 с этим свойством, но у Fable 5.1, в отличие от Opus 5, `effort`-параметр не позволяет полностью выключить thinking вообще — только Opus 5 разрешал отключение до `high` включительно). Reliable knowledge cutoff — июнь 2026, самый свежий из всей линейки (Opus 5 — май, Sonnet 5 — январь).
2. **Claude Mythos 5.1 (`claude-mythos-5-1`) — новая модель, впервые в вики.** Вышла тем же анонсом, "for Project Glasswing participants" — первоисточник не раскрывает, что такое Project Glasswing (ограниченный доступ/программа партнёров/внутреннее кодовое имя — не уточнено доступным текстом release notes). Разделяет с Fable 5.1 контекст/выход/thinking/цену/сниженную стоимость кэша. Открытый вопрос, не первоисточник не даёт больше деталей — не углубляюсь дальше по порогу материала этого прогона.
3. **Кэш-цена Fable 5.1/Mythos 5.1 — отдельная, более низкая ставка.** 0.025× от базовой input-цены ($0.25/MTok) вместо стандартных 0.1× у остальных моделей линейки — впервые в вики модель с собственным, а не общим коэффициентом кэш-чтения. Прямое дополнение к чеклисту [[claude-api-cost-optimization]].
4. **`tool_choice: "any"`/`"tool"` не поддерживаются на Fable 5.1/Mythos 5.1**, возвращают 400 — `auto`/`none` работают как раньше. Практическое ограничение при переносе промптов/интеграций со старых моделей на новую, тем же классом, что уже отмеченные breaking changes Opus 5 (см. [[claude-opus-5-launch]]).
5. **Fable-семейство требует 30-дневного data retention** — как и у Fable 5, недоступна с zero data retention без отдельного разрешения Anthropic; факт, унаследованный от предыдущего поколения, не новый для Fable 5.1 конкретно, но впервые зафиксированный в вики явно.
6. **Claude Code v2.1.257** — помимо доступности Fable 5.1 в `/model`-picker, **новый security-фикс того же семейства, что уже отслеживает [[ai-security-by-design]]**: Containment Escape rule для auto mode — облачные запросы metadata-credential, обход egress, cross-tenant доступ больше не auto-approve по умолчанию, если среда явно не пометила их ожидаемыми. Продолжение серии точечных сужений auto mode, начатой ещё в 07-2026.
7. **Claude Code v2.1.259 — `managedMcpServers`.** Новая managed-настройка: организация раздаёт HTTP/SSE MCP-серверы всем пользователям тем же форматом записи, что `.mcp.json`; записи, которые называют команду для запуска (а не HTTP/SSE endpoint), **пропускаются** — точечное ограничение, закрывающее очевидный вектор (управляемый конфиг не может тихо подсунуть пользователю выполнение произвольной локальной команды). Дополняет разбор MCP-каналов на [[mcp-model-context-protocol]] — способ подключения "сверху" от организации, отдельный от пользовательской лестницы подключения ("Как подключить новый сервис").
8. **Нумерация версий 2.1.253–2.1.256 отсутствует в публичном CHANGELOG.md** — переход 2.1.252 → 2.1.257 напрямую, зафиксировано как факт наблюдения, не ошибка чтения.

## Оценка источника

Первый ряд доверия по таблице скилла: официальные `platform.claude.com/docs` (models overview, release notes) и официальный `CHANGELOG.md` репозитория `anthropics/claude-code` через `raw.githubusercontent.com`. Прямых цитат добыто больше, чем в прошлом прогоне разведчика новостей (09-01, [[mcp-roadmap-2026-08-22]]) — WebFetch на этот раз не отказывал в коротких (≤30 слов) дословных цитатах при точечных, а не общих запросах; общий запрос "процитируй весь changelog дословно" был отклонён как избыточный объём — использованы узкие запросы на конкретную версию/фразу вместо одного широкого. Ретроспективно замечено расхождение между двумя последовательными фетчами одного и того же файла: один ошибочно приписал правило Containment Escape версии 2.1.259 вместо 2.1.257, а `managedMcpServers` — версии, отличной от подтверждённой позже точечным запросом; расхождение разрешено повторным точечным запросом на каждую спорную атрибуцию, но напоминание держать презумпцию перепроверки для атрибуции конкретной строки к конкретной версии при широких/суммаризирующих запросах к длинным файлам через WebFetch — сам инструмент иногда путает соседние версии при пересказе большого куска.
