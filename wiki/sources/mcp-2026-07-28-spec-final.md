# MCP 2026-07-28 Specification (финальный релиз)

**Дата загрузки:** 2026-07-31
**Опубликовано:** 2026-07-28
**Тип:** официальный блог Model Context Protocol
**Ссылка:** https://blog.modelcontextprotocol.io/posts/2026-07-28/
**Raw:** `raw/sources/mcp-2026-07-28-spec-final.md`

## Саммари

Финальный релиз спецификации MCP `2026-07-28` — той самой, что в вики с 2026-07-09 числилась как release candidate ([[mcp-2026-07-28-spec-release-candidate]]) с пометкой «финальная версия ещё не вышла». Теперь вышла, точно в заявленную дату. Это закрывает открытый статус на странице [[mcp-model-context-protocol]] — она была «Актуально на 2026-07-10» и содержала формулировку «финальная версия... на момент обновления страницы ещё не вышла», что с 28.07 стало неверным.

Расхождений с содержанием RC не нашлось — все ключевые изменения, описанные в RC-источнике (stateless core, MCP Apps, Tasks-расширение, ужесточённая авторизация, политика депрекации), подтвердились в финале без переработки. Разница — в деталях, которых RC не описывал явно: конкретные новые механизмы (Multi Round-Trip Requests, header-based routing, кэшируемые list-ответы), точный список stable-фич против deprecated, состав SDK-поддержки по языкам.

## Что взято в вики

- **Stateless core подтверждён финальным релизом** — обновлена формулировка на [[mcp-model-context-protocol]], снят статус «ещё не вышло».
- **Multi Round-Trip Requests (MRTR)** — новый механизм, которого не было в RC-саммари: инструмент может запросить у пользователя ввод посреди выполнения (`resultType: "input_required"`), клиент повторяет вызов с ответами в `inputResponses`. Заменяет прежний паттерн server-initiated запросов через открытый стрим.
- **Header-based routing** (`Mcp-Method`, `Mcp-Name`) — гейтвеи и rate limiter'ы маршрутизируют трафик без парсинга JSON-тела.
- **Кэшируемые list-ответы** (`tools/list`, `prompts/list`, `resources/list`, `resources/read`) — параметры `ttlMs`/`cacheScope`.
- **CIMD (Client ID Metadata Documents)** — формально заменяет Dynamic Client Registration, которая теперь в списке deprecated.
- **Точный список stable vs deprecated** — RC-источник называл депрекацию Roots/Sampling/Logging, финал добавляет к списку deprecated ещё legacy HTTP+SSE transport и саму Dynamic Client Registration.
- **SDK-поддержка по языкам**: TypeScript/Python/Go/C# — tier 1 (полная поддержка), Rust — beta.
- **Индустриальное принятие**: AWS, Cloudflare, Google Cloud, Microsoft, Anthropic и другие подтвердили поддержку спецификации.

## Что не взято / лиды

- **Анонс Anthropic** (`claude.com/blog/bringing-mcp-2026-07-28-to-claude`) — сама страница не прочитана целиком (403 на прямой фетч, зеркало для этой конкретной статьи не найдено). По поисковым сниппетам восстановлены: раскатка stateless core/OAuth-OIDC/Apps-Tasks по продуктам Claude, новые коннектор-фичи (embedded UI, enterprise-managed auth, observability, приватные **MCP tunnels** — research preview, доступ к внутренним MCP-серверам без публичного интернета). Зафиксировано как факт с оговоркой на странице [[mcp-model-context-protocol]], не проверено первоисточником — кандидат на допроверку через `wiki/gaps-backlog.md`, если понадобятся детали (например, точный список продуктов и сроки раскатки, или устройство MCP tunnels).
- Смежные заголовки блога Anthropic из той же поисковой выдачи (**"Interactive connectors and MCP Apps"**, **"New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels"**, **"Remote MCP support in Claude Code"**) — не открывались, потенциальные источники для будущего ingest, если тема MCP tunnels/Managed Agents станет актуальна.
- `server/discover` RPC (опциональный, для проактивного опроса капабилити) упомянут в источнике одной строкой без примера — не разворачивается отдельно, ниже порога детализации для этой правки.

## Оценка источника

Официальный блог протокола (`blog.modelcontextprotocol.io`) — первоисточник максимального доверия для содержания самой спецификации, тот же источник, что и у RC-версии в мае. Прочитан напрямую и полностью через WebFetch. Фактических ошибок или противоречий с RC-содержанием не найдено — финал строго расширяет RC, не переписывает. Часть страницы (анонс Anthropic) недоступна напрямую — оговорено отдельно, не смешано с первоисточником.

## Проверка безопасности источника

Прочитано целиком. Инструкций, адресованных агенту («игнорируй предыдущие правила» и т.п.), не обнаружено — обычный технический анонс спецификации. По внешним ссылкам из текста не переходил, кроме заявленных выше (сам URL источника и попытка зеркала/анонса Anthropic).
