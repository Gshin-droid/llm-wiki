## Ключевой тезис: фоновые сессии — draft PR только когда задача этого требует, а не всегда

Раньше (запись от 2026-07-09, см. [[claude-code]]) вики фиксировала: фоновые агенты, закончив работу в worktree, сами коммитят, пушат и **открывают draft PR** — как замену прежнему поведению "остановиться и спросить подтверждение". Формулировка звучала так, будто draft PR открывается всегда. Официальный changelog 2.1.221 уточняет это точнее: *"commit and push to preserve work, open a draft PR only when the task calls for one, follow your CLAUDE.md git instructions, and always end by reporting where the work lives"*. То есть:

- PR — не автоматический побочный эффект, а решение по существу задачи;
- фоновая сессия обязана следовать git-инструкциям конкретного `CLAUDE.md`, а не общему дефолту поверх них;
- отчёт "где лежит результат" — обязательная часть завершения хода, а не опция.

Это прямая официальная параллель дисциплине, которую эта вики уже практикует вручную (раздел CLAUDE.md «Автономные рутины: инкрементальный коммит и пуш» — коммит/пуш каждой законченной находки, а не одним PR в конце прогона). Официальное поведение теперь формально ближе к этому паттерну, чем раньше казалось из записи 07-09.

## Остальные два пункта

- **`mode: "mask"` для sandbox credential files (Linux/WSL)** — новый режим рядом с уже описанным в [[claude-code]] `sandbox.credentials`: сэндбоксированная команда видит файл-сентинел (весь файл или только фрагменты, пойманные regex-параметром `extract`), а прокси сэндбокса на выходе (egress) подменяет реальное значение. На macOS маскирование недоступно — там `mask` откатывается на `deny`. Точечное развитие принципа минимальных привилегий из [[ai-security-by-design]]: инструменту не нужно видеть секрет целиком, чтобы им пользоваться.
- **`prompt-audit` subcommand скилла `claude-api`** — команда для аудита промптов и описаний инструментов на паттерны, написанные под старые модели (актуально после смены поведения Opus 5, см. [[claude-opus-5-launch]] — вроде инструкций "добавь шаг верификации", которые пятое поколение уже делает само).
