## Находка 1: `deniedModels` и `availableModelsMatch: "exact"` — более жёсткий контроль версий моделей для организаций

Два новых managed-переключателя одного назначения:

- *"Added `availableModelsMatch` managed setting with `"exact"` option for model version control"* — раньше запись модели в `availableModels` матчилась широким префиксом (одна запись разрешала семейство версий), теперь можно потребовать точное совпадение версии.
- *"Added `deniedModels` managed setting to block specific models"* — отдельный чёрный список, действующий даже когда `availableModels` модель разрешает: удобно, когда нужно выключить одну конкретную версию, не переписывая весь белый список.

**Связь с уже описанным в этой вике.** [[claude-code]] уже фиксирует (раздел «Смена модели при пометке сообщения и `/fast`», дополнение 2026-09-28 по [[opus-5-5-rukovodstvo-claude-code]]), что сообщение, помеченное защитным классификатором, автоматически уходит более старой модели — и что менеджерам организаций до сих пор не хватало точечного инструмента управлять этим на уровне версий. `deniedModels`/`availableModelsMatch` — ровно такой инструмент, только с другой стороны: не про автоматическую подмену модели классификатором, а про то, какие версии организация вообще разрешает запрашивать. Не решает нюанс «какая модель подменяет Opus 5.5» (он остался неотвеченным в допроверке 09-28), но сужает круг: managed-политика теперь может явно исключить конкретную версию из списка кандидатов на подмену.

## Находка 2: `/doctor prompt-audit` — аудит `CLAUDE.md`/скиллов на приёмы под устаревшие модели

*"Added `/doctor prompt-audit` command to audit CLAUDE.md files and prompting patterns"*. Раздел Improved того же релиза уточняет: *"Improved `prompt-audit` output organization and thinking keyword handling"* — команда явно ищет в том числе приёмы вида «подумай внимательно» / инструкции выписывать рассуждения, то есть пересекается с находками [[opus-5-5-rukovodstvo-claude-code]] и [[claude-opus-5-5-launch]] про то, что такие формулировки для новых моделей не нейтральны, а местами вредны.

**Практическое значение для этой вики.** `CLAUDE.md` этого репозитория и оба скилла (`wiki-ingest`, `wiki-lint`) — ровно тот материал, который эта команда проверяет. Инструмент не запускался в рамках этого прогона (аудит собственных правил — не задача разведчика новостей, а кандидат для рутины хвостов); заведено в `wiki/gaps-backlog.md`.

## Малое

- **`mantle` — новый upstream-провайдер шлюза Claude apps для Amazon Bedrock** — ещё один путь доступа к Bedrock рядом с `assume_role`/`guardrail`, описанными в прошлом снапшоте ([[claude-code-changelog-snapshot-2026-09-25]]); что именно `mantle` меняет по сравнению с прямым Bedrock-апстримом, changelog не раскрывает.
- **`x-claude-code-prompt-id` в gateway hint headers** — группировка запросов одного пользовательского промпта на стороне LLM-шлюзов; для self-hosted/gateway-инфраструктуры, неприменимо к этой вики напрямую.
- **`/model` picker убрал пометку "(1M context)" у Opus** — косметика UI, не изменение самого контекстного окна.
- Остальные пункты версии — рутинные UI/MCP/vim-mode фиксы без веса для практики, полный список в raw-снапшоте.
