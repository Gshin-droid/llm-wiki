## Саммари

Программа для терминала превращает изменение в git (ветку, коммит, диапазон) в пошаговую «экскурсию»: зачем изменение, где тратить время, какие файлы читать (в том числе неизменённые), что спросил бы ревьюер (держит ли старые обещания, что при сбое или повторном запуске, можно ли откатить, кто и с каким вводом вызывает, что при 100-кратных данных, упали бы тесты, если код сломать), что обязательно исправить, а что мелочь. Перед ответом — вопрос, чтобы читатель успел подумать. Экскурсию пишет модель, которой человек уже пользуется (Claude Code, Codex, Gemini, OpenCode, Copilot); 2–5 минут, около $1–1,5 в пересчёте на цены API за изменение в ~250 строк.

Устройство, ради которого источник взят:

- **Модели — выгрузка, а не рабочая папка.** `git archive` двух коммитов, дифф и журнал — во временную папку; файлы из `.gitignore` не выгружаются никогда; после записи папка удаляется.
- **Только чтение держат флаги, а не промпт.** Для Claude Code: `claude -p --restricted --strict-mcp-config --tools Read,Grep,Glob --permission-mode dontAsk --permission-prompts none --no-session-persistence`; для каждого агента — свой набор, с указанием файла исходника.
- **Ссылки модели проверяет программа.** Ответ — JSON с указанием файлов и строк; каждая ссылка сверяется с репозиторием, ошибки возвращаются модели не больше двух раз.
- **Код на экране — из git, не из ответа модели.** Чего нет в репозитории (наивный вариант, возможная починка), помечено «Пример».
- **Каждое объяснение помечено, откуда известно:** «Проверено» (код, тесты, сообщения коммитов этого репозитория), «Из кода» (выведено из устройства кода), «Взгляд старшего» (общее суждение, по репозиторию не проверено).

## Что взято в вики

- Три механизма — метки «как известно», проверка ссылок модели программой, показ из источника вместо пересказа → [[verification-three-levels]] (связь), требования к скиллам нарядов проверяющего (дело о нарядах по ролям, вместе с [[anthropic-fold-subagents-into-main-loop]]).
- Набор флагов изолированного запуска; в нём нашлось, что `--restricted` **не отключает серверы MCP** (подтверждено справкой Claude Code 2.1.306) — в метод своего агента добавлены `--strict-mcp-config` и `--no-session-persistence` → [[habr-agent-po-specifikacii]], [[zabor-i-stena-prava-agenta]].

## Берём инструмент или логику

**Логику — да, сразу:** три механизма и флаги, см. выше.

**Инструмент — на пробу (решение пользователя 29.10).** Довод против: инструмент учит читать код, а код пользователь не читает; русского языка нет (английский, японский, китайский, испанский); на Windows не проверялся. Довод за, от пользователя: навык чтения кода полезен сам по себе, экскурсия может сделать код понятнее. Проба заведена делом: поставить, посмотреть на своей ветке, не подошло — удалить и остаться на механизмах. Перед установкой — проверка цепочки поставок: установщик для macOS/Linux — `curl | sh` (сверяет контрольные суммы), путь для Windows в README — скачивание архива из релиза **без** сверки сумм; есть сборка из исходников через `go install`.

Ближайший аналог в вики — [[whiteboard-devfast]] (схемы и журнал решений агента); его проба тоже не проведена.

## Что не взято / лиды

- Встроенные «уроки старших разработчиков» (`internal/generate/lessons`), которые модель читает перед каждой экскурсией, — на японском; посмотреть при пробе.
- Схемы базы до и после изменения через применение миграций к SQLite в памяти — только для SQLite; для Postgres не годится.

## Оценка источника

README подробный и честный: перечислено, что не проверено (Windows, macOS для Codex, полная экскурсия на Gemini и Copilot), что уходит провайдеру модели и что программа сама в сеть не ходит. Ранний выпуск, формат может меняться. Ценность для нас прежде всего в устройстве изоляции и проверки ответа модели.

## Проверка безопасности источника

Инструкций модели-читателю нет. Команды установки (`curl | sh`, PowerShell) не выполнялись. Сам README отмечает, что текст в коде может пытаться управлять моделью и что права это гасят, но «экскурсия — объяснение, а не гарантия».
