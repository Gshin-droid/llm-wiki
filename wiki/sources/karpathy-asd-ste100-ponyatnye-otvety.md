## Саммари

Карпати: людям придётся всё больше времени тратить на то, чтобы **понять** вывод языковых моделей. Четыре ступени, каждая «ещё лучше» предыдущей:

1. **Текст по ASD-STE100** — контролируемый английский из документации по техобслуживанию самолётов. Создан в 1980-х для механиков, для которых английский не родной. Издание января 2025: 53 правила и словарь около 900 разрешённых слов; предложение-инструкция не длиннее 20 слов, описательное — 25; одна инструкция в предложении; абзац до шести предложений; у слова одно значение. Модели стандарт знают; если строго — «на 80% к ASD-STE100».
2. **Схема.**
3. **Интерактивная HTML-страница** с анимацией.
4. **Объясняющее видео** в стиле 3Blue1Brown с озвучкой — самое медленное в изготовлении и, по мнению Карпати, самое перспективное.

**Что не проверено:** сам пост Карпати не прочитан — описание сведено из нескольких независимых пересказов, которые сходятся. Проверка фактов (Max Nardit) нашла в шпаргалке из поста Карпати три неточности против самого стандарта; FAQ стандарта говорит, что для общего письма он не предназначен, но короткие предложения, одна мысль на предложение и активный залог переносимы.

## Берём инструмент или логику

**Инструмент — английские навыки не ставим.** На GitHub их больше десятка (самые заметные — `danyuchn/asd-ste100-skill`, `AminBlg/SimpleEnglish`, у `0xpili/simplified-technical-english` есть проверочный скрипт), но все пишут по-английски, а ответы нам нужны по-русски. Русского аналога на 2026-10-12 не нашлось.

**Логика — переносима, и уже показано, как.** Китайские `dualface/ste-zh` и `lemonhall/asd-ste100-skill-zh` переносят принципы стандарта на свой язык; первый применяет их только к **отчёту агента пользователю** (код, комментарии и файлы не трогает) и задаёт форму: итог первым → причина → доказательство (`файл:строка`) → изменения → проверено / не проверено с причиной. Второй добавляет детерминированную проверку текста скриптом без зависимостей.

Что из этого у нас уже есть в общих правилах пользователя: «нужное от меня — первым», «неподтверждённое помечать», «англицизмы пояснять при первом упоминании», «успех только с доказательством». Чего нет:

- **одно слово — одно значение** во всём ответе (не «проверка», «ревью», «аудит» про одно и то же);
- **короткие предложения, одна мысль в каждом**, активный залог;
- **термин определяется при первом употреблении** — шире, чем «англицизм»: любой профессиональный термин.

Кандидат — «контролируемый русский» как правило оформления ответов. Решение за пользователем: правило касается того, как ему пишут.

**Ступени 2–4** у нас частично стоят: схемы (Mermaid) и HTML-страницы (артефакты) уже используются для объяснений; видео — нет, и не планируется: долго, нужна озвучка, а польза для одного читателя не доказана.
