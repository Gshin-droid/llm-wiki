# Черновик: делегирование рутины бесплатным моделям

**Статус:** обсуждение, решений нет. Записано 2026-08-10 вечером, разбирать 11.08 в рабочее время.
**Это не страница вики** — сырой конспект диалога, лежит вне `wiki/`, чтобы не публиковать полусырое.

## Исходная идея пользователя

Давать Claude задание, он передаёт его бесплатной модели (Gemini, Qwen и т.п.), получает результат,
возвращает ответ. Цель шире одного проекта: постоянно сгружать рутину, не требующую «много мозгов»,
во всех текущих и будущих проектах.

## К чему пришли

### Где делегирование окупается

Не на «напиши функцию», а на **большой вход → маленький выход**. Правило: делегировать, когда
отношение вход:выход больше ~10:1. 50k сырья → 2k тезисов — выигрыш. 3k контекста → 1k кода —
накладные расходы больше выгоды, потому что контекст всё равно собирает Claude, ответ всё равно
читает целиком и всё равно проверяет.

Второй фильтр — **дешевизна проверки**. Проверка тестами/схемой/грепом — годится. Проверка
перечитыванием исходника — не годится, это и есть делегированная работа.

Универсальный стоп-критерий: **если проверка стоит как исполнение — не делегируем**.

### Две цели разгрузки, вторая важнее

1. Деньги/лимиты — обычно мелочь, рутина по определению дешёвая.
2. **Контекст и внимание** — главное. 40k токенов логов в окне портят качество всей оставшейся
   сессии. Задача, экономящая копейки, но не заносящая мусор в контекст, уже выгодна.

### Лестница исполнителей (перебор сверху вниз, до первой справившейся)

0. **Детерминированный скрипт** (`jq`, `ast-grep`, codemod, линтер, `ffmpeg`) — всё, где есть правило.
   Самая частая ошибка — отдавать языковой модели работу регулярки.
1. **Локальная модель** (Ollama 8–30B) — приватное, объёмы, без лимитов.
2. **Бесплатный API** (Gemini Flash, Cerebras, Groq) — много входа → мало выхода, параллельно.
3. **Haiku в субагенте** — когда нужны файлы, инструменты, многошаговость (бесплатная модель по HTTP
   этого не может в принципе — у неё нет доступа к ФС).
4. **Claude** — решения, спорное, необратимое.

### Сильнейший приём: делегировать ДО сессии, а не внутри

- Внутри сессии — экономия частичная (постановка + чтение результата всё равно оплачены).
- **Вне сессии** (cron/CI/хук готовит результат до старта агента) — расход нулевой и по бюджету,
  и по контексту. У каждого проекта — «предбанник», который к моменту старта уже собрал и сжал.

### Инфраструктура: один шлюз на все проекты

`~/bin/llm`, вызов по имени задачи (`llm summarize`, `llm classify`), модель — параметр в конфиге.
Обязательно: цепочка фолбэков с последним звеном «делаю сам»; строгий JSON и отказ при невалидном;
чёрный список путей (`private/`, `.env`, ключи) в самом шлюзе; лог вызовов для последующей оценки
окупаемости; вывод под-модели — **черновик с пометкой происхождения**, никогда не прямая запись в репозиторий.

### Ограничение, определяющее потолок схемы

Узкое место со временем — не бюджет, а **внимание пользователя**. Каждый черновик требует взгляда;
десять посредственных черновиков утомительнее трёх хороших результатов. Поэтому делегировать стоит
то, что проверяется механически или выборочно.

## Факты по бесплатным тарифам на 2026-08-10 (проверено поиском)

| Провайдер | Что даёт |
|---|---|
| Google AI Studio (API-ключ) | Gemini 3 Flash / Flash-Lite, ~1500 запросов/день, контекст 1M. Pro с апреля 2026 только платно. Данные free-тарифа используются для обучения |
| Cerebras | ~1M токенов/день, но контекст обрезан 8k |
| Groq | 30 rpm, ~1000 запросов/день на модель, малый контекст |
| OpenRouter `:free` | 50 запросов/день; 1000/день после разовой покупки $10. Эндпоинты могут переезжать и отключаться |

**Что уже умерло (половина туториалов в сети об этом молчит):**
- Gemini CLI, бесплатный вход по Google-аккаунту — **18.06.2026** (анонс 20.05 на I/O). Замена — Antigravity CLI (`agy`).
- Qwen Code CLI, бесплатная OAuth-квота — срезана с 2000 до 100 запросов/день, закрыта **15.04.2026**.
- Qwen `:free` на OpenRouter (`qwen3-coder:free`, `qwen3-next-80b`) — убраны на рубеже июля–августа 2026.

Вывод: бесплатные тарифы отзывают без предупреждения — три случая за полгода. Поэтому модель обязана
быть параметром, а не константой, и обязателен фолбэк.

**Про Qwen отдельно:** чат открыт, API открыт но платный (Alibaba ModelStudio), закрылся именно
бесплатный вход. MCP тут ни при чём — это протокол подключения инструментов к агенту, а не канал
доступа к модели. Веса открытые → локальный запуск остаётся честно бесплатным путём.

## Разобранный тупик: гонять чат через браузер

Рассматривали автоматизацию `chat.qwen.ai` через Playwright (техника известная, есть готовые проекты
класса CLIProxyAPI). Итог — не годится:

- если кликает сам Claude, он платит токенами за скриншоты и DOM — экономика переворачивается в минус;
- если кликает скрипт, то умирает параллелизм (30 задач веером → полчаса подряд вместо 30 секунд),
  нет JSON-режима, system prompt, контроля контекста;
- селекторы ломаются при каждом редизайне, сверху Cloudflare и детект автоматизации;
- автоматизированный доступ к веб-интерфейсу запрещён условиями — риск на личном аккаунте с историей.

Оправдано ровно в одном случае: модель доступна только через чат и незаменима. Qwen под это не подходит —
у него открытые веса.
