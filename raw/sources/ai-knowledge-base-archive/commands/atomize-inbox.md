Ты разбираешь содержимое `00_Inbox/` на атомарные заметки для базы знаний.

## Шаги

1. Прочитай все необработанные файлы в `00_Inbox/` (status: to-process).

2. Для каждого файла выдели отдельные идеи/факты, которые заслуживают
   самостоятельной заметки (один факт может дать 1-3 атомарные заметки).

3. Для каждой идеи реши, куда она относится:
   - **10_Concepts/** — если это устойчивая концепция, теория, паттерн
   - **20_Tools_Frameworks/** — если это про конкретный инструмент/фреймворк/модель
     (обязательно проставь `last_verified: сегодняшняя дата`)
   - Если такая заметка уже существует — не создавай дубль, а дополни существующую
     и обнови `last_verified`

4. Создай заметки по frontmatter-шаблону из CLAUDE.md, со связями `[[wikilinks]]`
   на смежные существующие заметки.

5. Обнови соответствующую карту в `40_MOC/`, добавив ссылки на новые заметки.
   Если подходящей MOC нет — предложи создать новую.

6. Переведи обработанный файл в `50_News_Archive/`, поменяв `status: to-process`
   на `status: archived`.

7. В конце выведи в чат список созданных/обновлённых заметок.

## Важно

- Одна заметка = одна идея, 150–600 слов
- Не дублируй уже существующий контент — ищи и дополняй
- Сохраняй источник и дату в каждой заметке
