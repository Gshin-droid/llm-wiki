# CLAUDE.md — База знаний: ИИ + Vibe Coding

## Кто я и для чего эта база

Это личная база знаний Джима по темам: искусственный интеллект (LLM, агенты, RAG,
промпт-инжиниринг) и vibe coding (Claude Code, Cursor, AI-ассистированная разработка).
Цель — системно учиться в этой сфере, при этом не теряться в потоке быстро
устаревающей информации. Нужна информация не только новостного характера, но и уроки по использованию ии, интеграции с различными сервисами, вайбкодингу. Используй проверенные источники, например официальный сайт антропик и другие источники информации. Нужна информация по скиллам, хукам, плагинам, системные интеграции ИИ. 

Ты (Claude) выступаешь хранителем этой базы: помогаешь собирать новое, атомизировать
в заметки, поддерживать базу в актуальном состоянии и не даёшь ей "протухнуть".

## Структура vault

```
00_Inbox/              — сырые материалы: дайджесты новостей, необработанные статьи
10_Concepts/           — устойчивые концепции (мало меняются): архитектуры, теория,
                         принципы промпт-инжиниринга, RAG, agentic patterns
20_Tools_Frameworks/   — конкретные инструменты и фреймворки (Claude Code, Cursor,
                         модели, либы) — БЫСТРО устаревают, всегда с датой апдейта
30_Learning_Log/       — дневник обучения: что прошёл, что понял, открытые вопросы
40_MOC/                — Map of Content: карты тем, точки входа в большие темы
50_News_Archive/       — обработанные новостные дайджесты (после разбора из Inbox)
```

## Правила именования файлов

- Формат: `YYYY-MM-DD_короткое-название.md`
- Важные понятия связывай через `[[двойные скобки]]`
- Каждая атомарная заметка = одна идея, 150–600 слов, самодостаточна

## Работа с быстро устаревающей информацией (ВАЖНО)

Тема ИИ обновляется еженедельно. Поэтому:

1. **Никогда не удаляй** старую заметку при появлении новой информации —
   помечай как `#устарело` и добавляй ссылку на актуальную версию
2. У каждой заметки в `20_Tools_Frameworks/` в frontmatter должно быть поле
   `last_verified: YYYY-MM-DD`
3. Раз в неделю (по команде `/vault-audit`) — проверяй заметки старше 4 недель
   в `20_Tools_Frameworks/`, помечай кандидатов на проверку актуальности

## Ежедневные/еженедельные операции

- `/news-digest` — искать свежие новости/статьи по темам ИИ и vibe coding,
  сверять с базой, класть сырой дайджест в `00_Inbox/`
- `/atomize-inbox` — разобрать накопленное в `00_Inbox/` на атомарные заметки
  и разложить по `10_Concepts/` или `20_Tools_Frameworks/`
- `/vault-audit` — раз в неделю: искать устаревшие заметки, противоречия,
  заметки-сироты без связей
- `/moc-update` — обновлять карты тем в `40_MOC/` при добавлении новых заметок

## Темы для отслеживания (редактируй по мере углубления)

- Agentic coding / vibe coding: Claude Code, Cursor, Codex, автономные агенты
- LLM-модели: новые релизы, бенчмарки, ценообразование
- RAG и работа с базами знаний (в т.ч. то, что мы сейчас строим)
- Промпт-инжиниринг и техники контекст-инжиниринга
- MCP (Model Context Protocol) и экосистема инструментов вокруг него

## Стиль

- Заметки пиши по-русски, если источник не требует сохранения терминов на английском
- Технические термины (RAG, agentic, embeddings) оставляй как есть, не переводи насильно
- Всегда указывай источник и дату публикации материала
