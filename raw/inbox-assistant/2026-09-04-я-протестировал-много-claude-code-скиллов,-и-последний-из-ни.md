# Я протестировал много Claude Code скиллов, и последний из ни

Я протестировал много Claude Code скиллов, и последний из них: Planning with files.

Эта имба почти всегда (в 99% случаев) идеально закрывает все фичи, даже сложные.

Если ты ее не юзаешь, ты многое теряешь

Начать просто:

Bash
npx skills add https://github.com/othmanadi/planning-with-files --skill planning-with-files

Дальше, когда пишешь любой промпт, просто добавь фразу: “Plan with files”.

Claude сам подхватит скилл и создаст 3 файла: task_plan.md, findings.md, progress.md.

И в отличие от обычного plan mode, он будет возвращаться к этим файлам на протяжении всего планирования и выполнения, постоянно держа перед глазами что надо сделать и как.

Из-за этого “дрейф” почти пропадает, и план чётко выполняется по шагам.

Да, токенов съедает больше, но зато с первого раза и стабильно. Попробуй 👏
