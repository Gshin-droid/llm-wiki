# Pythia: опенсорсный API для агентов

Pythia: опенсорсный API для агентов

Pythia объединяет оператор агентов MiroFish и OSINT-дашборд Osiris. Система собирает данные о происходящем в мире в реальном времени и строит прогнозы на завтра, неделю, месяц или год.

Она отслеживает более 40 открытых лент событий, формирует сводки и показывает модель планеты с отмеченными событиями и прогнозами. Pythia работает через Ollama, поэтому не требует облачной инфраструктуры или платных подписок.
