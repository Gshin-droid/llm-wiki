# Вайб-кодинг: Плагин для DSH, который лично рекомендует руководитель DeepS

Плагин для DSH, который лично рекомендует руководитель DeepSeek Harness Цуй Тяньи. Его начали разрабатывать ещё во время закрытого тестирования и с тех пор постоянно дорабатывают.

https://github.com/ccch1mneyyy/dsh-TUI

dsh-TUI добавляет в DeepSeek Harness полноэкранный терминальный интерфейс в стиле Claude Code:

Потоковый вывод рассуждений, статус работы агента, шкала заполнения контекста и скорость генерации. Двойное нажатие Esc возвращает сессию к предыдущему шагу. Есть просмотр изображений и Mermaid-диаграмм, возобновление и экспорт сессий, переключение модели и фоновые задачи. 

Установка одной командой:

npm i -g @deepseek-ai/dsh @deepseek-harness-tui/dsh-tui

После этого запуск:

dsh-tui
