# Появлися мод для Claude Code, который экономит токены. 🦀

Появлися мод для Claude Code, который экономит токены. 🦀

Вместо загрузки всех навыков в окно контекста они остаются вне него до момента, когда действительно становятся нужны.

Jev анализирует доступные навыки и для каждого запроса выбирает подходящий, добавляя в контекст Claude только необходимый.

Решение работает с API от TypeSafe и AI Gateway от Vercel.

Установить мод можно одной командой:

npx claude-code-templates@latest --mod productivity/jev-skill-suggestion
