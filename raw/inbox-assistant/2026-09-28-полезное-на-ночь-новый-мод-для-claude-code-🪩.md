# Полезное на ночь: новый мод для Claude Code 🪩

Полезное на ночь: новый мод для Claude Code 🪩

Этот мод более настраиваемый и показывает всех субагентов, которые сейчас работают в вашей сессии.

Теперь их не нужно держать в голове, ведь каждый субагент остаётся виден в боковой панели, где можно посмотреть, что он уже сделал и сколько контекста использовал.

Установка одной командой:

npx claude-code-templates@latest --mod ui/agent-flow

Ссылка: https://aitmpl.com/component/mod/

p.s. Claude Code и без мода показывает субагентов. Тут просто всё вынесли в удобный сайдбар.
